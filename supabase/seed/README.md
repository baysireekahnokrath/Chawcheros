# ข้อมูลนำเข้า (seed) — ไม่ใช่ migration

`import_batch_1..6.sql` = ข้อมูล 751 แถวจากไฟล์ราคา Standard Price 2026
แปลงเป็น SQL ไว้แล้ว โหลดเข้า `catalog.import_variants` (พื้นที่พัก ยังไม่ใช่สินค้าจริง)

## ⚠️ ทำไมไฟล์พวกนี้ไม่ใช่ migration

**ข้อมูลไม่ควรอยู่ใน migration** — migration คือ "โครงสร้าง" ข้อมูลคือ "เนื้อหา"

ถ้าฝังข้อมูลลง migration จะเกิดปัญหา 3 อย่าง:

1. **ไฟล์ราคาอัปเดตทุกปี** — ฝังไว้แล้วจะแก้ไม่ได้ ต้องเขียน migration ใหม่ทุกครั้ง
2. **สร้างฐานใหม่จะได้ข้อมูลเก่าติดมาด้วยเสมอ** แม้ตอนนั้นข้อมูลจะเปลี่ยนไปแล้ว
3. **Bay อัปโหลดเองไม่ได้** ต้องเรียกโปรแกรมเมอร์ทุกครั้งที่ราคาเปลี่ยน

**ทางที่ถูกคือ: หน้าอัปโหลดในเว็บแอป** — Bay ลากไฟล์ CSV ใส่เอง ระบบแปลงให้
ไฟล์ในโฟลเดอร์นี้เก็บไว้เป็น 2 อย่างเท่านั้น: ข้อมูลตั้งต้นตอนทดสอบ และหลักฐานว่าแปลงมายังไง

## วิธีใช้ตอนทดสอบในเครื่อง

```bash
for i in 1 2 3 4 5 6; do
  psql "$DB" -1 -v ON_ERROR_STOP=1 -f supabase/seed/import_batch_$i.sql
done
```
