## `APPLY-0047-phoenix.sql` · ตั้ง PIN หลังรัน

ไฟล์ไม่ต้องแก้อะไร รันทั้งไฟล์ได้เลย · แล้วตั้ง PIN ด้วยคำสั่งบรรทัดเดียว

```sql
select pricing.set_phx_pin('รหัสที่อยากใช้');
```

- อย่างน้อย 6 ตัว · ตัวเลขล้วนก็ได้ พิมพ์ในมือถือง่ายกว่า
- **ยังไม่ตั้ง PIN = ยังไม่มีใครเข้าหน้า `/phoenix` ได้** ปิดไว้ก่อน ปลอดภัย
  (ไฟล์จะขึ้น notice เตือนให้ตอนรันเสร็จ)
- PIN ไม่อยู่ในไฟล์และไม่อยู่ใน git · ฐานข้อมูลเก็บเป็น hash
  ผมอ่านไม่ได้ พี่คนเดียวที่รู้
- เปลี่ยนทีหลังใช้คำสั่งเดิม · คนละตัวกับ PIN ของ `/pos`
- คำสั่งนี้เรียกได้เฉพาะเจ้าของฐานข้อมูล คือที่หน้า SQL Editor นี้
  คนที่ล็อกอินเข้าแอปเปลี่ยน PIN ไม่ได้

### คนที่ยังไม่ล็อกอิน เห็นอะไรได้บ้าง

หน้า `/phoenix` ไม่ต้องล็อกอิน (ตามที่พี่ขอ "ใช้กันแค่ Bay กับ Book สองคน")
แต่ข้อมูลยังกันอยู่ที่ฐานข้อมูลเหมือนเดิม

| | |
|---|---|
| ตาราง `pricing.*` ตรง ๆ | เข้าไม่ได้ · RLS ปิดเหมือนเดิม ไม่ได้เปิดอะไรเพิ่ม |
| `pricing.phoenix_sheet(pin)` | เรียกได้ แต่ PIN ผิดคืน `pin_invalid` ไม่คืนข้อมูลสักแถว |
| PIN ถูก | ได้เฉพาะแถวของ **ฟีนิกซ์** · มีขนาดกับราคาขาย **ไม่มีต้นทุนสักช่อง** |
| รุ่นอื่น ต้นทุน ลูกค้า ออเดอร์ | ฟังก์ชันนี้ไม่คืนให้ ไม่ว่าจะใส่อะไร |

ใช้ประตูเดียวกับที่หน้า POS ใช้อยู่แล้ว (`pos.check_pin` / `pos.record_sale`)
ไม่ได้เปิดช่องทางใหม่

## ไม่ใช่ SQL แต่ต้องตั้งใน Supabase เหมือนกัน

### ปุ่ม "ลืมรหัสผ่าน" ในหน้า login

**https://supabase.com/dashboard/project/iblnlzttabwuydgcmqts/auth/url-configuration**

| ช่อง | ใส่ว่า |
|---|---|
| Site URL | `https://chawcher-os.vercel.app` |
| Redirect URLs | เพิ่ม `https://chawcher-os.vercel.app/reset` |

ถ้าไม่เพิ่ม Redirect URL · Supabase จะไม่สนใจปลายทางที่แอปขอ แล้วส่งกลับมาที่ Site URL แทน
แอปดักไว้ให้แล้ว (เจอโค้ดกู้รหัสที่หน้าไหนก็พามาที่ `/reset`) ลิงก์จึงยังใช้ได้
แต่ใส่ให้ถูกดีกว่า จะได้ไม่ต้องเด้งสองทอด

**ข้อจำกัดที่แก้ไม่ได้** · ลิงก์ในอีเมลต้องเปิดใน**เครื่องเดียวกับที่กดขอ**
Supabase ใช้ PKCE · ตอนกดขอ เบราว์เซอร์เก็บกุญแจครึ่งหนึ่งไว้ในเครื่องนั้น
กดขอในมือถือแล้วไปเปิดลิงก์ในคอม จะต่อกุญแจไม่ติด · หน้าเว็บเขียนเตือนไว้ทั้งสองจุดแล้ว

**เมลไม่มา** · โปรเจกต์ที่ยังใช้เมลของ Supabase เอง ส่งได้ไม่กี่ฉบับต่อชั่วโมง
ถ้าจะใช้จริงจังค่อยต่อ SMTP ของตัวเองทีหลังได้

เข้าไม่ได้จริง ๆ ตั้งรหัสใหม่จากหลังบ้านได้เสมอที่
**https://supabase.com/dashboard/project/iblnlzttabwuydgcmqts/auth/users**
