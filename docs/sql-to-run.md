## `APPLY-0047-phoenix.sql` · ต้องแก้ก่อนรัน

**บรรทัดสุดท้ายของไฟล์**

```sql
select pricing.set_phx_pin('ใส่PINของคุณที่นี่');
```

แก้คำว่า `ใส่PINของคุณที่นี่` ให้เป็น PIN ที่พี่อยากใช้ แล้วค่อยกด Run

- อย่างน้อย 6 ตัว · ตัวเลขล้วนก็ได้ พิมพ์ในมือถือง่ายกว่า
- **ถ้าลืมแก้ ไฟล์จะหยุดและไม่ติดตั้งอะไรเลย** ตั้งใจให้เป็นอย่างนั้น
  เพราะไฟล์นี้อยู่ใน git ถ้าปล่อยให้ตั้งด้วยคำในไฟล์ ใครอ่าน git ก็เข้าหน้าได้
- ฐานข้อมูลเก็บเป็น hash ไม่ได้เก็บตัว PIN · ผมอ่านไม่ได้ พี่คนเดียวที่รู้

เปลี่ยน PIN ทีหลัง · รันบรรทัดเดียวนี้ ไม่ต้องรันทั้งไฟล์ใหม่

```sql
select pricing.set_phx_pin('รหัสใหม่');
```

PIN ของ `/phoenix` คนละตัวกับ PIN ของ `/pos` เปลี่ยนอันหนึ่งไม่กระทบอีกอัน

### คนที่ยังไม่ล็อกอิน เห็นอะไรได้บ้าง

หน้า `/phoenix` ไม่ต้องล็อกอิน (ตามที่พี่ขอ "ใช้กันแค่ Bay กับ Book สองคน")
แต่ข้อมูลยังกันอยู่ที่ฐานข้อมูลเหมือนเดิม

| | |
|---|---|
| ตาราง `pricing.*` ตรง ๆ | เข้าไม่ได้ · RLS ปิดเหมือนเดิม ไม่ได้เปิดอะไรเพิ่ม |
| `pricing.phoenix_sheet(pin)` | เรียกได้ แต่ PIN ผิดคืน `pin_invalid` ไม่คืนข้อมูลสักแถว |
| PIN ถูก | ได้เฉพาะแถวของ **ฟีนิกซ์** · มีขนาดกับราคาขาย **ไม่มีต้นทุนสักช่อง** |
| รุ่นอื่น ต้นทุน ลูกค้า ออเดอร์ | ฟังก์ชันนี้ไม่คืนให้ ไม่ว่าจะใส่อะไร |

ใช้ประตูเดียวกับที่หน้า POS ใช้อยู่แล้ว (`pos.check_pin` / `pos.record_sale`)
ไม่ได้เปิดช่องทางใหม่
