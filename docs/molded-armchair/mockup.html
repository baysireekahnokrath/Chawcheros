CHAW CHER · Production concept

Armchair โฟมหล่อหุ้มโครงไม้ หุ้มผ้าเสร็จใน 5 นาที

โครงไม้ CNC วางในแม่พิมพ์ เทโฟม PU ให้ฟูหุ้มโครงเป็นรูปตามแบบ แล้วสวมผ้าหุ้มชิ้นเดียวที่ยึดด้วยร่องตีนตุ๊กแกและซิป 2 เส้น ไม่ต้องตัดแปะฟองน้ำ ไม่ต้องยิงแม็ก

Mockup แนวคิด · ตัวเลขทั้งหมดเป็นค่าเริ่มต้น ยังไม่ได้ทดลองจริง

ลำดับงาน 7 ขั้น

ต่างจากลำดับเดิมหนึ่งจุด: ออกแบบวิธีหุ้ม (ขั้น 2) ก่อนทำแม่พิมพ์ เพราะร่องยึดผ้าต้องหล่อติดมากับโฟม

  1. 1

    Technical drawing → โมเดล 3D ตัวเดียว

    ใช้เป็นต้นทางของโครง แม่พิมพ์ และ pattern ทุกอย่างอ้างไฟล์เดียวกัน

    ฝ่ายออกแบบ

  2. 2

    วางแนวตะเข็บ ร่องดึงผ้า ซิป ในโมเดล ทำก่อนแม่พิมพ์

    กำหนดว่าผ้าแบ่งกี่แผ่น ตะเข็บไหนกดลงร่อง ซิปอยู่ตรงไหน ชายล่างเกี่ยวกับอะไร

    ฝ่ายออกแบบ + ช่างเย็บ + ช่างหุ้ม

  3. 3

    CNC โครงไม้

    ไม้อัดเข้าลิ่ม ฝัง T-nut ยึดขา เซาะร่องรอบฐานไว้เกี่ยวชายผ้า ไม้ต้องแห้ง

    แผนกโครงไม้

  4. 4

    ทำแม่พิมพ์

    3D print ตัวต้นแบบ แล้วหล่อแม่พิมพ์ไฟเบอร์กลาสจากตัวต้นแบบ มีหมุดล็อกโครง รูระบายอากาศ และสันสำหรับร่องดึงผ้า

    3D print + ร้านไฟเบอร์กลาส

  5. 5

    เลือกและปรับสูตรโฟม แล้วเท

    ซื้อระบบ polyol + MDI จาก system house วิศวกรกำหนดความแน่น ความแข็ง น้ำหนักเท อุณหภูมิพิมพ์ เวลาถอด

    วิศวกรพอลิเมอร์/เคมี + แผนกฟองน้ำ

  6. 6

    คลี่ผิว 3D เป็น pattern 2D แล้วพิมพ์

    คลี่ด้วยซอฟต์แวร์จากโมเดลเดิม ย่อ 2–4% ให้ผ้าตึง พิมพ์ด้วย plotter หรือตัดด้วยเครื่อง

    แผนกวางแบบ

  7. 7

    เย็บ → หุ้ม → ปิดใต้ฐาน → ใส่ขา

    เย็บเป็นถุงชิ้นเดียว สวม กดร่อง รูดซิป เกี่ยวชาย

    แผนกเย็บ + หุ้ม + QC

ภาพตัดด้านข้างของแม่พิมพ์

  1. 1แม่พิมพ์ ไฟเบอร์กลาสหล่อจากตัวต้นแบบ 3D print เสริมโครงด้านหลังรับแรงดัน เคลือบผิวและทาน้ำยาถอดแบบ
  2. 2โฟม PU หล่อเย็น ความแน่นราว 40–60 kg/m³
  3. 3โครงไม้ CNC ลอยอยู่กลางโฟม ความชื้นไม้ไม่เกินราว 10–12%
  4. 4หมุดล็อกโครง ตรงตำแหน่ง T-nut ของขา ถอดแบบแล้วรูหมุดคือรูขันขา
  5. 5รูระบายอากาศ ที่จุดสูงสุดของพิมพ์ กันโพรงอากาศ
  6. 6สันสำหรับร่องดึงผ้า ได้ร่องลึกในโฟมตรงรอยต่อที่นั่ง–พนัก ก้นร่องฝังแถบตีนตุ๊กแกด้านหนาม
  7. 7โฟมหุ้มโครง หนาอย่างน้อย 3–4 ซม. ทุกด้านที่คนสัมผัส

ผ้าหุ้ม: 1 ชิ้น ซิป 2 เส้น

มองจากด้านหลังเก้าอี้

  1. 1ซิปแนวตั้ง 2 เส้น ที่มุมหลังซ้ายและขวา เปิดแล้วปากถุงกว้างพอผ่านส่วนที่กว้างที่สุดของตัวเก้าอี้ ซ่อนในตะเข็บ
  2. 2ชายล่าง เย็บแถบพลาสติกรูปตัว J เกี่ยวเข้าร่องที่ CNC ไว้รอบฐานโครง
  3. 3แผ่นปิดใต้ฐาน + ขา ขันทับชายผ้า ปิดงานทั้งหมด
  4. 4ตะเข็บด้านใน (ที่นั่ง–พนัก–แขน) เย็บแถบตีนตุ๊กแกด้านขนไว้ กดลงร่องในโฟมก็ยึด
แผ่นผ้าจำนวนยึดกับตัวเก้าอี้ด้วย
พนักใน + แขนใน (ต่อเนื่อง)1ร่องตีนตุ๊กแกรอบที่นั่ง
ที่นั่ง1ร่องตีนตุ๊กแก 3 ด้าน
ขอบหน้า1แถบ J ใต้ฐาน
หน้าแขน ซ้าย/ขวา2เย็บติดแผ่นข้างเคียง
พนักนอก + แขนนอก (ต่อเนื่อง)1ซิป 2 เส้น + แถบ J ใต้ฐาน
รวม เย็บเป็นถุง 1 ชิ้น6

ถ้ามีเบาะนั่งลอย นับเป็นชิ้นที่ 2 มีซิปของตัวเองด้านหลังเบาะ · จำนวนแผ่นจริงขึ้นกับทรงของรุ่น

เป้าเวลาหุ้ม 5 นาที

  1. 1:00สวมถุงผ้าจากบนลงล่าง จัดมุม
  2. 1:30กดตะเข็บลงร่องตีนตุ๊กแกรอบที่นั่ง
  3. 0:30รูดซิปหลัง 2 เส้น
  4. 1:00เกี่ยวแถบ J รอบฐาน
  5. 1:00ปิดแผ่นใต้ฐาน ขันขา 4 ตัว

เป็นเป้าหมายสำหรับช่าง 1 คน ยังไม่ได้จับเวลาจริง · ผ้ายืดจะถึงเป้าง่ายกว่าผ้าทอแน่นหรือหนัง

3 เรื่องที่ต้องรู้ก่อนลงทุน

แม่พิมพ์ 3D print ล้วนรับแรงไม่ไหว

โฟมฟูดันราว 0.5–1 bar บนพื้นที่ 1 ตร.ม. คือแรงหลายตัน และ PLA นิ่มที่ราว 55–60°C จึงใช้ 3D print ทำตัวต้นแบบ แล้วหล่อแม่พิมพ์ไฟเบอร์กลาส

สูตรโฟมไม่ต้องคิดจากศูนย์

ซื้อระบบสำเร็จ 2 ส่วนจาก system house วิศวกรทำหน้าที่กำหนดสเปกและปรับค่าการเท โฟมหล่อแน่นกว่าฟองน้ำแผ่นที่ใช้อยู่ (20–37 kg/m³)

ความชื้นไม้และความปลอดภัย

ไม้ชื้นทำให้เกิดโพรงรอบโครง · isocyanate เป็นสารก่อภูมิแพ้ทางเดินหายใจ ต้องมีระบบดูดอากาศและ PPE

ก้าวถัดไปที่แนะนำ

เริ่มจากชิ้นเล็ก เช่น สตูลหรือที่นั่งเก้าอี้ เพื่อทดลองสูตรโฟม แม่พิมพ์ และร่องดึงผ้า ด้วยต้นทุนแม่พิมพ์ที่ต่ำ แล้วค่อยขึ้น armchair

วิธีนี้คุ้มกับทรงโค้งที่ตัดแปะฟองน้ำยากและขายได้หลายตัวต่อแบบ ทรงเหลี่ยมใช้วิธีเดิมถูกกว่า
