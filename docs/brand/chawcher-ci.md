## ⚠️ เว็บตอนนี้ไม่ตรง CI

| เรื่อง | CI ทางการ | เว็บตอนนี้ |
|---|---|---|
| สีหลัก | Navy `#2B4368` · Teal · Taupe | Slate/Ink `#2B2E3A` · Cream · **Terracotta** |
| ฟอนต์อังกฤษ | Gotham | Marcellus (serif) + Jost |
| ฟอนต์ไทย | Sukhumvit Set | Kanit |

**Terracotta (CI2 ที่ Bay ok) ไม่อยู่ใน CI** → ใช้เป็น **สีปุ่ม/สีเน้น** (accent) ตัวเดียวได้ เหมือนสีแคมเปญ
ส่วนพื้น หัวข้อ ตัวหนังสือ กลับไปใช้ชุดสี CI

## Token สำหรับหน้าเว็บที่เราจะทำ (ตาม CI + CI2)

```css
--cc-navy:#2B4368; --cc-slate:#2F4554; --cc-teal:#83B7BF; --cc-taupe:#958C7B;
--cc-bg:#F7F8F8; --cc-text:#212121; --cc-muted:#6B6F7D;
--cc-accent:#C1622E;   /* ปุ่มหลักเท่านั้น (CI2) */
--cc-font-en:'Montserrat',sans-serif;   /* แทน Gotham */
--cc-font-th:'Anuphan',sans-serif;      /* แทน Sukhumvit Set */
```

## ภาพถ่าย

## น้ำเสียง (จากข้อความบนเว็บ)
