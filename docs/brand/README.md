# CI ของ CHAW CHER (ฌ เฌอ)

ที่มา: `CC_Ci.pdf` ใน Google Drive ของ Bay (โฟลเดอร์ CI) · หน้าในโฟลเดอร์ `ci/` คือภาพของ PDF นั้นทีละหน้า (23 หน้า)
**ทุกงานที่ออกในชื่อ CHAW CHER (สไลด์ โพสต์ ใบรับรอง หน้าเว็บ ป้ายบูธ) ต้องใช้ตามหน้านี้**

## ⛔ เช็กลิสต์ก่อนส่งงานทุกชิ้น (ห้ามข้าม)

บทเรียน 2026-11-11: สไลด์ Marketing Plan รอบแรกผิด CI — ใช้สีนอกชุด 14 สี · ฟอนต์น้ำหนัก 300/600 · ปกไม่ตรงหน้า CI

1. **สีมีแค่ 5 ตัวในตารางข้างล่าง** — ห้ามสร้างเฉดใหม่ (เทาอ่อน ฟ้าอ่อน ขาวล้วน `#FFFFFF` ดำ ฯลฯ) แม้แต่ข้อความรอง เส้น หรือพื้นการ์ด · ก่อนส่งให้ grep หา hex ทุกตัวในงาน ต้องเจอแค่ 5 ตัวนี้
2. **น้ำหนักฟอนต์มีแค่ 400 (Book/Text) กับ 500 (Medium)** — ห้าม 300 · 600 · 700 · ห้าม `<b>` ที่ทำให้หนาเกิน 500 · หัวตาราง (th) ต้องตั้ง 500 เอง
3. **ปก/หน้าปิด ยึดหน้า 1 ของ CI** — พื้นเข้ม · โลโก้เล็กกลางหน้า · ตัวอักษรเล็ก ตัวพิมพ์ใหญ่ เว้นระยะ · ไม่มีหัวเรื่องตัวใหญ่ ไม่มีเส้นแบ่งตกแต่ง
4. **คู่สีที่อ่านออก:** Navy/Slate บน Off-white · Off-white/Aqua บน Navy/Slate · Navy บน Aqua · Taupe ใช้เป็นเส้นหรือพื้นตกแต่ง **ห้ามใช้เป็นสีตัวอักษรขนาดเล็ก** (คอนทราสต์ 3.2:1)
5. เปิดภาพ `ci/CC_Ci_Page_01.jpg` และ `_02.jpg` ดูเทียบทุกครั้งก่อนเริ่มงาน ไม่ใช่อ่านแค่ไฟล์นี้

## โลโก้
- สัญลักษณ์เส้นบาง (โค้งประตู + ตัว ฌ) อยู่เหนือคำว่า `CHAW` / `CHER` ตัวพิมพ์ใหญ่ เว้นระยะห่างตัวอักษรกว้าง สองบรรทัด
- ชื่อแบรนด์แนวนอน: `CHAW CHER HOME` · `CHAWCHER LIV` · `CHAWCHER TEEN` — **คำว่า CHER ตัวหนา** ส่วนที่เหลือตัวบาง
- สีโลโก้: ขาวบนพื้นเข้ม / กรมท่าบนพื้นสว่าง · ไม่ใส่เงา ไม่ใส่กรอบ ไม่บิดสัดส่วน
- **ไฟล์ต้นฉบับ:** `logo-master.ai` (Illustrator) · `logo.svg` (เวกเตอร์ พื้นใส ใช้ currentColor เปลี่ยนสีได้) · `logo-white.png` `logo-dark.png` (สูง 800px พื้นใส) · `logo-on-dark-1920.png`
- สีพื้นเข้มในไฟล์ต้นฉบับคือ `#3F4753` · `logo-navy.png` `logo-slate.png` เป็นไฟล์เก่าความละเอียดต่ำ ไม่ต้องใช้แล้ว
