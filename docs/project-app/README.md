## ปัญหาที่แอปต้องแก้

| ที่เจอ | ผลเสีย |
|---|---|
| โจทย์มาเป็น PDF หลายสิบหน้า | แกะมือ · สถานะอยู่ในสีแถว |
| ของมาจาก 4 แหล่ง (ฌ เฌอ · แบบเอเซ่ · supplier · ร้านข้างนอก) | สูตรราคาคนละแบบ · VAT ปนกัน |
| แบบของเอเซ่ไม่อยู่ในระบบ | จับคู่ผิด · หาขนาดไม่เจอ |
| ทำไฟล์ใหม่ทุกรอบ สั่งงานผ่านคอลัมน์ | ไม่รู้ว่ารอบไหนเปลี่ยนอะไร |
| ไฟล์ภายในกับไฟล์ลูกค้าทำแยก | เสี่ยงหลุดชื่อแหล่งหรือต้นทุน |
| คำถามถึงผู้ผลิตส่งทางแชท | คำตอบไม่กลับเข้ารายการ |

## ขั้นตอน 8 ขั้น

1. รับโจทย์ (อัปโหลด → ระบบแตกรายการ → คนตรวจ)
2. คัดขอบเขต (เสนอ / ไม่เสนอ / มีคนทำแล้ว)
3. จับคู่ (รุ่นหลัก + ตัวเลือกที่ 2 จาก 4 แหล่ง)
4. ระบุการปรับแบบ
5. คำถามค้าง (รวมเป็นข้อความชุดเดียวต่อผู้รับ · ตามคำตอบ)
6. ตั้งราคา (สูตรตามแหล่ง · แปลงเป็นรวม VAT · ปัดเศษ · กำไรเห็นเฉพาะภายใน)
7. ออกใบเสนอเป็นฉบับ (ของเก่าไม่ถูกแก้ · บอกว่าต่างจากฉบับก่อนตรงไหน)
8. ลูกค้ายืนยัน → ออเดอร์ในระบบเดิม

สูตรราคาที่ Bay ให้ไว้ (2026-11-21): รุ่น ฌ เฌอ ใช้ใบราคา · แบบเอเซ่ = ราคาซื้อ × 1.5 ปัดหลักร้อย · supplier = ราคาหลังลด × 1.3 · ของ curator บวกค่าบริการ 10%

## คลังสินค้าอ้างอิง

หลัก: ไม่ต้องกรอกเพิ่ม · ของที่แนบเข้ารายการในขั้น 3 ถูกเก็บเข้าคลังเอง · 4 ชั้นค้นรวมกัน

แต่ละชิ้นเก็บ: ชื่อ ประเภท ขนาด วัสดุ รูป ลิงก์/ไฟล์ spec · ประวัติราคาแยกแถว (ราคา · ชนิดราคา · รวม VAT ไหม · วันที่ · เอกสารต้นทาง) ·
ปรับแบบอะไรได้ · ระยะเวลาผลิต · ป้ายสไตล์ · เคยใช้ในงานไหนและผล · ตรวจแล้วหรือยัง · ป้ายสิทธิ์ (โชว์ลูกค้าได้ไหม · ซ่อนชื่อแหล่ง)

ต้นทุนและชื่อแหล่งเห็นเฉพาะมุมมองภายใน · ไม่เข้าบอท ไม่เข้า LINE (กฎ AI 4-5)
