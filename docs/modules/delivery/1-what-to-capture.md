### 6 · เก็บ "ใบเสนอราคาทุกใบ" ไม่ใช่แค่เจ้าที่เลือก

หลักเดียวกับที่เสนอไว้เรื่องฟองน้ำ (B4 ชั้น 2)

ทุกครั้งที่ถามราคา 2-3 เจ้าแล้วเลือกเจ้าหนึ่ง — **อีกสองใบคือข้อมูลราคาตลาดที่ทิ้งไปฟรีๆ**
เก็บไว้ 6-12 เดือนจะมีเส้นราคาตลาดจริงของเราเอง ที่ไม่มีใครมี

| ตอบได้ว่า |
|---|
| เจ้าไหนขึ้นราคาบ่อย ขึ้นกี่ % |
| ที่เราจ่ายอยู่ แพงหรือถูกกว่าตลาดเท่าไหร่ |
| **มีไพ่ในมือตอนต่อรองสัญญาปีหน้า** |

เก็บ **เหตุผลที่เลือกเจ้านี้** ด้วยหนึ่งช่อง (ถูกสุด / ว่างพอดี / เคยส่งโซนนี้) —
ไม่งั้นย้อนไปดูจะไม่รู้ว่าตัดสินใจถูกหรือผิด

## สิ่งที่ต้องมีเพื่อไม่ให้เกิดซ้ำ · เรียงตามความง่าย

### 1 · ค่าส่งต้องเป็นคำถามที่ต้องตอบตอนรับออเดอร์

**ยืนยันออเดอร์ไม่ได้ถ้ายังไม่ตอบ** · มี 3 คำตอบที่ถูกต้อง

| ตอบว่า | หมายความว่า |
|---|---|
| ส่งฟรี (เข้าเกณฑ์) | ระบบเช็คเกณฑ์ให้เอง |
| เก็บลูกค้า ___ บาท | ตกลงกันแล้ว |
| **ยังไม่สรุป ต้องถามลูกค้าก่อน** | เป็นคำตอบที่ถูกต้อง **แต่จะค้างอยู่ให้เห็น ไม่หายเงียบ** |

ข้อสามสำคัญที่สุด — ปัญหาไม่ใช่ว่าตอบไม่ได้ ปัญหาคือ**ไม่ตอบแล้วไม่มีใครรู้**

### 2 · ให้ระบบรู้กฎ แล้วเตือนเอง

| เงื่อนไข | ระบบทำอะไร |
|---|---|
| ที่อยู่อยู่นอก กทม./ปริมณฑล | 🔴 เตือนทันที *"ไม่เข้าเกณฑ์ส่งฟรี — ต้องตกลงค่าส่งกับลูกค้าก่อน"* |
| ยอดไม่ถึง 25,000 | เตือนว่าไม่เข้าเกณฑ์ส่งฟรี |
| ประมาณต้นทุนเกิน 2,000 | 🔴 เตือนว่าเกินเพดาน |

> ทำได้เพราะ **เรามีคิวของสินค้าทุกตัวอยู่แล้ว (743/751)** → ประมาณต้นทุนได้ตั้งแต่ตอนรับออเดอร์
> **เงื่อนไขคือต้องเก็บ "จังหวัด" แยกช่อง** ไม่ใช่ที่อยู่เป็นข้อความก้อนเดียวแบบในชีต

### 3 · เก็บ "ตกลงอะไรไว้" ไม่ใช่แค่ "ขายอะไรเท่าไหร่"

*"sales จำไม่ได้ว่าคุยกับลูกค้าไว้อย่างไร"* — เพราะบทสนทนาอยู่ใน LINE OA และ**ไม่ได้ผูกกับออเดอร์เลย**

ต้องมีที่แปะในออเดอร์: **สรุปสิ่งที่ตกลง + ภาพแชท + ใครคุย เมื่อไหร่**
ตรงกับวัฒนธรรม memo base ของโรงงานพอดี — และระบบทำได้ดีกว่ากระดาษ

## เกณฑ์ส่งฟรี 25,000 · ตรวจด้วยตัวเลขจริง 2026-11-02

> Bay: *"ถ้าซื้อ 25,000 แล้วเป็นชิ้นเล็กๆ ในกรุงเทพฯ มันก็มีค่าขนส่งที่เราต้อง subsidise อยู่ดี"*

**หลักคิดถูก — เกณฑ์เป็นบาท แต่ต้นทุนเป็นคิว สองอย่างนี้ไม่ได้สัมพันธ์กัน**
แต่พอเอาตัวเลขสินค้าของเราใส่เข้าไป **มันชี้ไปคนละทางกับที่กังวล**

### บาทต่อคิว แยกตามหมวด (743 ตัว)

| หมวด | บาท/คิว (กลาง) | คิวกลาง |
|---|---|---|
| ที่พักหัว | **163,083** | 0.10 |
| ชั้นวางทีวี | 138,438 | 0.35 |
| เลาจ์แชร์ | 124,753 | 0.37 |
| สตูล | 111,667 | 0.20 |
| โต๊ะกลาง | 108,796 | 0.22 |
| ตู้เก็บของ | 93,664 | 0.47 |
| อาร์มแชร์ | 76,440 | 0.61 |
| โต๊ะทานข้าว | 65,000 | 1.08 |
| โซฟา | 62,759 | 1.49 |
| **เตียง** | **20,390** ← ต่ำสุดห่างทุกตัว | **3.89** |

**สูง = ชิ้นเล็กแต่แพง ส่งถูกเมื่อเทียบกับยอด** · **ต่ำ = ใหญ่แต่ถูก ส่งแพงเมื่อเทียบกับยอด**

### ออเดอร์ 25,000 บาท = กี่คิว (ใช้ตัวที่แย่สุดในหมวด)

| ถ้าซื้อ 25,000 บาทเป็น | ได้กี่ชิ้น | รวมกี่คิว |
|---|---|---|
| ชั้นวางทีวี | 0.7 | **0.22 คิว** |
| ที่พักหัว | 3.8 | **0.31 คิว** |
| โต๊ะกลาง | 1.9 | **0.43 คิว** |
| สตูล | 3.7 | **0.52 คิว** |
| เก้าอี้ | 2.7 | 0.59 คิว |

> **ออเดอร์ของชิ้นเล็ก 25,000 บาท = 0.2–0.6 คิว เท่านั้น**
> ขนาดนี้ Lalamove เอาอยู่สบาย — ของจริงในชีตอยู่ที่ **359–1,293 บาท** ต่ำกว่าเพดาน 2,000 เยอะ
>
> **เพราะของชิ้นเล็กของเราไม่ใช่ของถูก** สตูลตัวละ 18,000–56,000 ไม่ใช่หมอนใบละ 500

### 🔴 ตัวที่ subsidise หนักจริงคือ "เตียง"

| | |
|---|---|
| เตียงถูกที่สุด | **51,600 บาท** → เข้าเกณฑ์ส่งฟรีอัตโนมัติทุกตัว |
| ขนาด | **3.80–5.55 คิว** ใหญ่ที่สุดในแคตตาล็อก |
| บาท/คิว | 11,398–20,390 · **ต่ำกว่าหมวดอื่นทั้งหมดราว 3–8 เท่า** |

เทียบกัน: ลูกค้าซื้อสตูล 25,000 = **0.52 คิว** · ลูกค้าซื้อเตียง 51,600 = **3.80 คิว**
**ยอด 2 เท่า แต่ของใหญ่กว่า 7 เท่า และได้ส่งฟรีทั้งคู่**

ของจริงในชีตที่แพงเกินเพดาน 2,000 มี 10 จาก 40 รายการ (2,500–4,500 บาท) — น่าจะเป็นกลุ่มนี้

## สิ่งที่ผมแนะนำ · ไม่ต้องเพิ่มกฎใหม่ แค่ทำให้เพดานที่มีอยู่ "เช็คได้"

Bay มีเพดานต้นทุน **2,000 บาท** อยู่แล้ว ปัญหาคือ**ไม่มีใครเช็คได้ตอนรับออเดอร์**

> **ส่งฟรีเมื่อ: ยอด ≥ 25,000 · อยู่ใน กทม./ปริมณฑล · และ ต้นทุนประมาณ ≤ 2,000**
> เกินข้อใดข้อหนึ่ง = ต้องคุยกับลูกค้าก่อนยืนยันออเดอร์

| | |
|---|---|
| ทำได้เพราะ | มีคิวของสินค้าทุกตัวแล้ว (743/751) → รวมคิวทั้งออเดอร์ได้ตั้งแต่ตอนรับ |
| ข้อดี | ไม่ต้องอธิบายกฎใหม่ให้ทีม · เป็นกฎเดิมที่เพิ่งบังคับใช้ได้จริง |
| ยังไม่รู้ | เส้นว่า "กี่คิว = 2,000 บาท" ยังไม่แม่น ต้องบันทึก **ค่าส่งจริง + คิว** คู่กันสักพักถึงจะได้เส้นจริง |

> ประมาณจากชีต: Lalamove 359–1,293 รับของเล็ก · ที่ 2,500–4,500 คือของที่ต้องใช้รถใหญ่
> **เส้นน่าจะอยู่ราว 1.5–2 คิว** แต่นี่เป็นการเดาจากตัวเลขที่ยังไม่ได้จับคู่กับออเดอร์

## ⚠️ เมื่อไหร่ที่ความกังวลของ Bay จะกลายเป็นจริง

วันนี้ไม่จริงเพราะของชิ้นเล็กของเราแพง · **แต่จะจริงทันทีถ้าขายของชิ้นเล็กที่ถูกจริง**
เช่น ของแต่งบ้าน หมอน หรือของกลุ่ม OCT. 26

ถ้าวันหนึ่งมีของราคาหลักร้อย–พันต้น **ต้องกลับมาทบทวนเกณฑ์นี้ทันที** เพราะ 25,000 บาทของถูกจะกลายเป็นของกองใหญ่
