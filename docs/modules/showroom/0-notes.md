## ไอเดียต่อยอด (2026-10-13) · ตะกร้าสินค้า → ใบเสนอราคา → ส่งทาง LINE OA

> Bay: ลูกค้าดูสินค้าแล้วถามราคา → add product ที่สนใจไว้เรื่อยๆ → ตอนจบ generate PO หรือ Quotation ส่งให้ลูกค้าผ่าน LINE OA

### ของที่ OS มีอยู่แล้ว ใช้ต่อได้

- สินค้าโชว์ทุกตัวเป็น `stock.units` ที่มีสติกเกอร์ QR → **สแกนสติกเกอร์ = เพิ่มเข้าตะกร้า** (มือเดียว ไม่ต้องพิมพ์)
- ราคา · ส่วนลดปกติ · ส่วนลดขั้นบันได · VAT อยู่ในโมดูลราคาแล้ว → ใบเสนอราคา **ต้องถามราคาจากโมดูลราคา** ห้ามคำนวณเอง
- ผังใน `chawcher-os-design.md` วาง "ลองนั่ง → ใบเสนอราคา" ไว้ในโมดูล **ขาย** อยู่แล้ว

### ชนกับกฎเดิม · ต้องให้ Bay ยืนยัน

1. กฎเดิม "ห้ามแตะฐานข้อมูลสินค้าหรือราคา" → เสนอแก้เป็น **อ่านได้ แก้ไม่ได้**
2. ข้อ B4 ราคาเทรด → ราคาบนจอซ่อนไว้ก่อน กดถึงเห็น · เส้นทาง B ที่มากับลูกค้าของเขา **ห้ามส่งใบเสนอราคาเข้า LINE ลูกค้าของดีไซเนอร์** ระบบต้องบล็อก ไม่ใช่แค่เตือน
3. LINE user ID = ข้อมูลลูกค้าเพิ่มจาก SOP → ต้องอนุมัติ
4. PO (เลข BLS) = ออเดอร์จริง เป็นของโมดูลขาย/ออเดอร์ที่ยังไม่มี → เสนอรอบแรกทำแค่ **ใบเสนอราคา**

### LINE OA ทำงานยังไง

ส่งข้อความหาลูกค้าได้ต่อเมื่อรู้ LINE user ID ของเขา ซึ่งได้มาตอนลูกค้าแอดเพื่อน OA แล้วเราผูกกับการเข้าชม
ทางที่เสนอ: จบการคุย → จอพนักงานโชว์ QR → ลูกค้าสแกน → เปิดในแอป LINE (LIFF) → แอดเพื่อน → ระบบส่งใบเสนอราคาเข้าแชตเอง
ต้องการจาก Bay: สิทธิ์แอดมิน LINE OA · เปิด Messaging API · สร้าง LIFF
