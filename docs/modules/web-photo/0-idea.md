## หน้าตาที่คิดไว้ (ทาง B)

เปิดบนมือถือ → `os.chawcher.com/web-photo` (ใช้ล็อกอินเดิม)

```
┌──────────────────────────────┐
│ 1. สินค้าไหน   [ค้นชื่อ/รหัส ▾] │  ← ค้นจากสินค้าในระบบเรา
│ 2. รูป        [📷 ถ่าย / เลือก] │  ← ได้หลายรูปพร้อมกัน
│ 3. ใส่ตรงไหน   ○ แกลเลอรี      │
│              ○ บ้านลูกค้าจริง    │
│ 4. ที่มารูป    [ถ่ายเอง/ลูกค้า/…] │
│          [ บันทึก ]             │
└──────────────────────────────┘
```

กดบันทึก แล้วระบบทำ

| # | ขั้น | หมายเหตุ |
|---|---|---|
| 1 | ย่อรูปในมือถือก่อนส่ง (เช่น ด้านยาว 2000px · ~300-500KB) | รูปมือถือ 5-10MB จะทำเว็บช้า และส่งผ่านเน็ตมือถือนาน |
| 2 | เก็บรูป + บันทึกในระบบเรา ใครอัป · เมื่อไหร่ · สินค้าไหน · ที่มา | ตามกฎ A7 ตามรอยได้ |
| 3 | ~~รอ Bay อนุมัติ~~ ไม่มีขั้นนี้ (WP3) · คนอัปคือคนกดขึ้นเว็บ | ยังตรงกฎ "ขึ้นเว็บ = คนทำ" |
| 4 | ส่งรูปเข้า WordPress Media (`/wp-json/wp/v2/media`) | |
| 5 | ผูกรูปเข้าสินค้า (`/wp-json/wc/v3/products/{id}`) | ⚠️ ต้องส่ง**รูปเดิมทั้งหมด + รูปใหม่** ไม่งั้นรูปเดิมหาย — จุดที่พังง่ายที่สุด |
| 6 | แสดงผล ✅ ขึ้นแล้ว + ลิงก์ไปหน้าสินค้า · หรือ ❌ พร้อมปุ่มลองใหม่ | error แล้วรูปไม่หาย เพราะเก็บไว้ในขั้น 2 แล้ว |

### ของที่ใช้

| | |
|---|---|
| ล็อกอิน · ค้นสินค้า · สิทธิ์ตามตำแหน่ง | มีแล้วใน ChawCher OS |
| ที่เก็บรูป | Supabase Storage (มีอยู่ในโปรเจกต์เดิม) |
| กุญแจเข้า WordPress | **Application Password** ของ user WordPress 1 ตัว (Bay สร้างเองใน 1 นาที · เก็บไว้ฝั่ง server เท่านั้น ทีมไม่เห็น) |
| ตารางใหม่ | 1 ตาราง บันทึกรูปที่อัป + สถานะ (รอตรวจ / ขึ้นแล้ว / ไม่ผ่าน / error) |
| ช่องใหม่ในสินค้า | `woo_product_id` — สินค้าตัวนี้คือสินค้าไหนบนเว็บ (**ใช้ร่วมกับ B2 ได้เลย**) |

## ⚠️ 2 เรื่องที่ Bay ควรรู้ก่อนตัดสินใจ

### 1. "เจอรูปที่ไหนมาก็แล้วแต่" — ลิขสิทธิ์รูป

| รูปแบบไหน | ขึ้นเว็บได้ไหม |
|---|---|
| ทีมถ่ายเอง (โชว์รูม · โรงงาน · บ้านลูกค้า) | ✅ ได้ (บ้านลูกค้าควรขออนุญาตก่อน) |
| ลูกค้าส่งรูปมาเอง | ✅ ได้ ถ้าลูกค้ายินยอม — ควรขอเป็นข้อความใน LINE ไว้ |
| รูปจากเน็ต / IG คนอื่น / Pinterest | ❌ **เสี่ยงโดนฟ้องหรือโดนแจ้งลบ** และขัดกับการเป็นแบรนด์ที่ขายของจริง |

นี่คือเหตุผลที่ใส่ช่อง "ที่มารูป" ไว้ในฟอร์ม — ถ้าเลือก "เจอจากเน็ต" ระบบไม่ส่งขึ้นเว็บ
(แต่เก็บไว้เป็นรูปอ้างอิงภายในได้)

### 2. สินค้าในระบบเรา ↔ สินค้าบนเว็บ ยังไม่ได้จับคู่

ระบบเรามี 751 ตัว (ระดับรุ่น+ขนาด+เกรดผ้า) แต่บนเว็บน่าจะเป็นระดับรุ่น
ต้องจับคู่ก่อนครั้งเดียว ซึ่งเป็นงานเดียวกับ **B2 Q1** — ทำครั้งเดียวได้ทั้งสองเรื่อง
