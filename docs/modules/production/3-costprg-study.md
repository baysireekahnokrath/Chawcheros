**บันทึก 2026-11-16 · Bay สั่ง "อย่าเพิ่งไปยุ่ง คุณแค่ศึกษาก่อน แล้วเดี๋ยวเราวางแผนและออกแบบ"**

ศึกษาจากไฟล์ `CostPrg2.mdb` (สำเนาเก่า ข้อมูลถึงปี 2019) ที่พี่หนิงส่งมา

## 1 · หัวใจมี 3 ตาราง ต่อกันเป็นชั้น

```
MainCost   5,654 แถว   หัวใบ: เลขที่ Cost + ส่วนประกอบ + รุ่น + ขนาด + CBM + ตู้ 40/40HQ
   └─ Cost        273,959 แถว   สูตรวัสดุ · เฉลี่ย 49 บรรทัดต่อสูตร
        └─ CostDetial  45,887 แถว   กระจาย 1 บรรทัดออกเป็นชิ้นส่วน
```

| | |
|---|---|
| สูตรทั้งหมด (`CostNo` + `PartId`) | **5,543** |
| รุ่น (`ModelID`) ไม่ซ้ำ | **1,731** |
| ชื่อวัตถุดิบที่โผล่ในสูตร | 14,904 (ดูข้อ 6) |

`CostDetial` คือหน้า P-3 / P-4 บนกระดาษพอดี — ผ้าหนึ่งบรรทัดถูกแตกเป็น
`PVC-เบาะนั่ง · PVC-เบาะพิง · PVC-ใต้เบาะพิงล่าง+ข้าง · PVC-ตัวถัง · PVC-หมอนแขน`
**แต่มีแค่ 1,106 สูตรที่แตกไว้ (20%)** · อีก 80% มีแต่ยอดรวม

## 2 · ★ สูตรคำนวณที่ถอดได้ · และตรวจกับใบจริงแล้วว่าถูก

```
จำนวนที่ต้องเบิก  =  จำนวนที่ใช้  ÷  Rec_  ÷  ตัวหาร#2
   (หน่วยเบิก)         (หน่วย Cost)
```

**ตรวจกับใบขอเบิกจริงของ SE-04 ที่พี่หนิงถ่ายมา**

| | |
|---|---|
| ใบ cost กระดาษ P-6 บอก | ใย 200 กรัม (3S) = 94.9 ตร.ฟุต |
| `Rec_` ของใย | 0.9 |
| `ตัวหาร#2` ของใย 200g 70″ | 17.5 ตร.ฟุต/หลา |
| คำนวณ | 94.9 ÷ 0.9 ÷ 17.5 = **6.03** |
| ใบขอเบิกที่ระบบปรินต์ออกมา | **6 หลา** ✅ |

→ **กระดาษกับฐานข้อมูลเป็นของเดียวกัน ตรวจย้อนได้ทุกตัวเลข**

### `Rec_` คือค่าได้เนื้อ · เผื่อของเสียตอนตัด

| ค่า | สัดส่วนแถว | ใช้กับ |
|---|---|---|
| 1.00 | 57% | สกรู แม็ก ของที่ไม่ต้องตัด |
| 0.90 | 31% | ฟองน้ำ ไม้ |
| 0.80 | 9% | ไม้อัด MDF |
| 0.85 · 0.75 · 0.73 · 0.70 · 0.65 · 0.63 · 0.60 | ที่เหลือ | ผ้าและหนัง |

→ ตอบ `PRQ11` ที่ค้างมาตั้งแต่ 2026-10-31 (*"ของเสียระหว่างตัดคิดเผื่อกี่ %"*)
**คำตอบ: เผื่อไว้แล้ว รายวัสดุ รายสูตร** หนังเผื่อหนักสุดถึง 40%

### `ตัวหาร#2` คือตัวแปลงหน่วย · ตรงกับคอลัมน์ `AREA` ของพี่หนิงเป๊ะ

ฟองน้ำ **27.8** ตร.ฟุต/แผ่น · ผ้า **10.75** ตร.ฟุต/หลา · ซิป **100** ซม./เมตร
ตารางราคาวัตถุดิบใน Excel ใช้ตัวเลขชุดเดียวกัน → สองระบบนี้ออกแบบมาคู่กัน

| 5 หุ้ม | 27,637 |

หมวดวัสดุ (`GroupID`): C=หุ้ม 124,008 · W=โครงไม้ 85,419 · S=ฟองน้ำ 40,941 ·
F=ใย 12,763 · L=หนัง 4,511 · P=PVC 2,644 · CT=ผ้า 1,572 · I=โครงเหล็ก 1,546

## 6 · 🔴 สี่เรื่องที่ต้องแก้ก่อนเอาไปต่อกับอะไรก็ตาม

### 6.1 ชื่อวัสดุเป็นข้อความอิสระ ไม่มีรหัสเลย

`MaterialID` **ว่างทั้ง 273,959 แถว** · ของถูกอ้างด้วย `Description` ล้วน ๆ

| | |
|---|---|
| ชื่อไม่ซ้ำในฐาน | **14,904** |
| แค่บีบช่องว่างซ้ำให้เหลือช่องเดียว | เหลือ 12,444 — **หายไป 2,460 ชื่อ (17%) โดยไม่ต้องตัดสินใจอะไรเลย** |
| ตัดหมายเหตุท้ายชื่อออกด้วย | เหลือ 11,793 |
| ชื่อที่ถูกใช้ครั้งเดียวในทั้งฐาน | **4,706 ชื่อ** |

ตัวอย่างของเดียวกันที่นับเป็นคนละอย่าง (ต่างกันแค่จำนวนช่องว่าง):
`ฟองน้ำสีชมพูเข้ม HR-3  1"` ใช้ 311 ครั้ง · `ฟองน้ำสีชมพูเข้ม HR-3   1"` ใช้ 3 ครั้ง

→ ของจริงมีไม่กี่ร้อยอย่าง (ตารางราคาวัตถุดิบมี 429 รายการ)
→ **นี่คือกำแพงที่ขวางการต่อสูตรเข้ากับราคา** ไม่ใช่เรื่องจำนวนข้อมูล

### 6.2 `StockIssu` และ `Purchase` ว่าง 0 แถว
ช่องมีครบ (`IssuAmount` `DepID` `WO` `IssuDate`) แต่ไม่เคยถูกใช้ใน 24 ปี
→ ระบบรู้แต่ **ควรใช้เท่าไหร่** ไม่เคยรู้ **ใช้จริงเท่าไหร่**

### 6.3 ของกำพร้า
111 หัวใบไม่มีสูตร · 124 สูตรที่ใบสั่งอ้างถึงแต่หาไม่เจอในฐาน

### 6.4 ไม่มีราคาในไฟล์นี้
`PRICE` ว่างทุกแถว · ราคาน่าจะคูณตอนออกรายงานจากตารางราคาวัตถุดิบที่อยู่คนละที่
