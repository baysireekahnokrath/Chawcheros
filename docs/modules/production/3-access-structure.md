ความสัมพันธ์ที่ประกาศไว้ในไฟล์ (`MSysRelationships`):

```
SpecPack (CostNo)
  └─ MainCost (CostNo, PartID)            ← ModelID อยู่ตรงนี้
       └─ Cost (CostNo, PartId, Item)     ← + GroupID → Group · DepID → Department
            └─ CostDetial (CostNo, PartId, Item, No)
BackupPI (CustomerID, No, Rev) ─ BackupSubPI
SubPI.TypeC1 → TypeColorCOST
```

`PI` ↔ `SubPI` ↔ `MainCost` **ไม่ได้ประกาศ** ความสัมพันธ์ไว้ (ผูกกันใน query เท่านั้น) → มีแถวกำพร้า ดูข้อ 6

## 8 · วิธีอ่านไฟล์ซ้ำ

ไฟล์เป็นของนอก → วางในโฟลเดอร์ของมันเอง · สคริปต์อยู่อีกโฟลเดอร์ · ไม่ `cd` เข้าไป · Python ใช้ `-I` · **ทุกอย่างอยู่นอก repo**

```bash
apt-get update && apt-get install -y mdbtools
F=<ที่วางไฟล์>/CostPrg2.mdb

mdb-ver "$F"                               # JET4
mdb-tables -1 "$F"                         # ตาราง local
mdb-tables -1 -t linkedtable "$F"          # ตาราง linked
mdb-export "$F" MSysObjects                # Type 6 = linked · ดูคอลัมน์ Database / ForeignName
                                           # Type 5 = query · -32768 form · -32764 report · -32766 macro
mdb-export "$F" MSysRelationships          # ความสัมพันธ์
mdb-schema "$F"                            # คอลัมน์ + ชนิด
mdb-schema --indexes "$F" postgres         # คีย์หลัก + index
mdb-count "$F" Cost                        # จำนวนแถว
mdb-queries "$F" IssuLeather               # ดู SQL ของ query (ได้แค่ SELECT/FROM/WHERE คร่าว ๆ ไม่มี JOIN)
mdb-export -D '%Y-%m-%d' -T '%Y-%m-%d %H:%M:%S' "$F" Cost > <นอก repo>/Cost.csv
```

- ต้องใส่ทั้ง `-D` และ `-T` ไม่งั้นวันที่ออกเป็น `MM/DD/YY` ปีสองหลัก
- ไม่ต้องตั้ง `MDB_JET3_CHARSET` (ไฟล์เป็น Jet 4)
- sha256 ของไฟล์ที่วิเคราะห์: `5ebdebc0…4d714d1f`
