## ไฟล์ฐานข้อมูล

- ตัวจริง `D:\Cost\CostPrg.mdb` — **ยังไม่ได้** รอพี่หนิง
- ที่ได้มา `CostPrg2.mdb` = สำเนาเก่า **ข้อมูลหยุดปี 2019** ไม่มีฟีนิกซ์ ทากะ ขุนทอง → ตัวเลขแถวทุกที่ในเอกสารมาจากไฟล์นี้
- `INVOICE.mdb` = ราคาขาย ข้อมูลหยุดปี 2003 · ไม่มีประโยชน์กับต้นทุน
- อ่านด้วย `mdbtools` (`apt-get install -y mdbtools` → `mdb-tables -1` · `mdb-schema -T` · `mdb-export`) ทดสอบแล้วใช้ได้ อ่านภาษาไทยถูก

## ค้างอยู่กับโรงงาน

1. ไฟล์ `CostPrg.mdb` ตัวปัจจุบัน
2. แบบฟอร์ม COSTING ตัวจริง (ที่ได้มาเป็น Excel ที่ทำขึ้นให้ดูเฉพาะกิจ — เคยสรุปผิดเพราะเรื่องนี้ ดู CLAUDE.md "กันพลาดซ้ำ")
3. ราคาวัสดุอยู่ตารางไหน · คุณมาลิปรับที่ไหน
4. ปัดเศษบนใบเบิกเป็นปัดขึ้นจริงมั้ย
5. ทำไมหนังมีรายงานใบเบิกแยกจาก 6 แผนก · ใครเป็น Admin ของโปรแกรม
