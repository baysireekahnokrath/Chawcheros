## 2 · 🔴 ค้นพบที่ใหญ่ที่สุด · โรงงานมีระบบคอมพิวเตอร์อยู่แล้ว

ใบขอเบิกวัตถุดิบ **ไม่ใช่กระดาษเขียนมือ** — เป็นใบปรินต์จากระบบลงกระดาษต่อเนื่อง (dot matrix)
หัวใบมี `PRINT :12/11/2026 10:53:42` · มีเลขอ้างอิงครบ

```
PI No    : EGG  EGG 45-26
W/O NO   : 45/26
MODEL    : SE-04(MO)
ลูกค้า    : E.G.G. Enterprise Co.,Ltd
รายการ   : 3-SEATER , IN131031-02 GREY = 1     ← รุ่น + รหัสผ้า + จำนวน
แผนก     : โครงไม้ · ฟองน้ำ · วางแบบ · เย็บ · หุ้ม · QC     ← 1 ใบต่อ 1 แผนก
```

ตารางในใบ: `NO · PRODUCT · หน่วย · ` **`จำนวนตาม STD`** ` · ` **`จำนวนที่เบิกจริง`** ` · ` **`ผลต่าง`** ` · @ · ฿`
ท้ายใบ: `รายการข้อมูลที่ไม่คิด COST:` · `หมายเหตุ` · `ผู้ออกเอกสาร` · `ผู้อนุมัติ (หัวหน้าแผนก)` · `ผู้จ่าย (สโตร์)`

### ทำไมเรื่องนี้เปลี่ยนแผนทั้งหมด

ระบบจะปรินต์คำว่า **“จำนวนตาม STD”** ได้ แปลว่า **สูตรวัสดุ (BOM) อยู่ในฐานข้อมูลอยู่แล้ว**
ไม่ได้อยู่แค่บนกระดาษ 13 แผ่น และไม่ได้อยู่ในหัวช่าง

| เดิมคิดว่า | ความจริง |
|---|---|
| ต้องถอดสูตรจากกระดาษหลายร้อยใบ กรอกเข้าชีต | **ขอ export จากระบบที่มีอยู่** |
| ของเสียยังไม่มีใครเก็บ | มีช่อง `จำนวนที่เบิกจริง` + `ผลต่าง` พิมพ์มาให้แล้ว |
| ไม่มีใบสั่งผลิต | มี `W/O NO` + `PI No` + แยกตามแผนก |

→ งานของเราเปลี่ยนจาก *“สร้างฐานข้อมูลสูตร”* เป็น *“ต่อกับของที่มี และปิดช่องที่ยังรั่ว”*
→ ช่องที่รั่วชัดที่สุด: **`ผลต่าง` กรอกด้วยมือบนกระดาษ แล้วไม่มีทางกลับเข้าระบบ**

## 4 · โครงของตาราง "ราคาวัตถุดิบ" · ตรงกับที่ออกแบบไว้เกือบทุกช่อง

| คอลัมน์ในตารางจริง | คืออะไร |
|---|---|
| `GROUP` | เลขลำดับ 1-429 (ไม่ใช่รหัสวัสดุ) |
| `DESCRIPTION` | ชื่อวัสดุ + สเปค + ขนาดบรรจุ |
| `UNIT` | หน่วยซื้อ (เมตร · หลา · กล่อง · ม้วน · รีม · แผ่น · ขา · ตัว) |
| `PURCHASE UNIT PRICE` | ราคาซื้อจริงต่อหน่วยซื้อ |
| **`AREA`** | **ตัวหาร = จำนวน “หน่วยคิดต้นทุน” ต่อ 1 หน่วยซื้อ** |
| `PRICE AS PER UNIT` | = PURCHASE ÷ AREA · **คำนวณได้ ไม่ต้องเก็บ** |
| **`STD. COSTING UNIT PRICE`** | **ราคาที่ใช้ตั้งต้นทุน (ปัดขึ้นจากราคาซื้อ)** |
| `ผลต่าง` | = STD − PER UNIT · คำนวณได้ |
| `SUPPLIER` · `CREDIT` | ผู้ขาย · เครดิตกี่วัน |

ตรงกับ *ชีตที่ 1* ใน [`costing/2-design.md` §6](../costing/2-design.md) แทบทุกช่อง
(`AREA` = ช่อง “ได้เนื้อ” ที่ตั้งชื่อไว้) → **ไม่ต้องทำชีตใหม่ให้คุณหนิง · ของมีอยู่แล้ว**

### 4.1 `AREA` คืออะไรในแต่ละหมวด · ตรวจแล้วเข้าสูตรทุกหมวด

| หมวด | `AREA` คือ | พิสูจน์ |
|---|---|---|
| **ผ้า · ใย** | **ตารางฟุตต่อ 1 หลา/เมตร** | ใย 70″ ต่อหลา = 36×70 นิ้ว = 17.5 ตร.ฟุต → ตรงกับ AREA 17.5 เป๊ะ · ผ้า 47″ ต่อหลา = 11.75 → ตรง · MALIMO 58″ ต่อเมตร ≈ 15.9 → ตาราง 15 |
| **ฟองน้ำ** | **ตารางฟุตต่อแผ่น** | แผ่น 50×80 → AREA 27.8 · 60×80 → 33.3 · 40×80 → 22.2 · อัตราส่วนตรง 5:6:4 เป๊ะ |
| ลวดยิง · สกรู | แผง/ตัว ต่อกล่อง | 1006 = 50 แผง/กล่อง → AREA 50 |
| เชือก · ริบบิ้น | เมตร/หลา ต่อม้วนหรือกิโล | เชือกกุ้น 4 มม 143 ม/กก → AREA 143 |
| ใยปั่น · ขนเป็ด | **ขีด ต่อ กิโล** | AREA 10 |

> 🔴 **ขนาดแผ่นฟองน้ำ “50×80” เป็นนิ้ว ไม่ใช่เซนติเมตร** — 50×80 นิ้ว = 27.78 ตร.ฟุต ตรงกับ AREA พอดี
> (ถ้าเป็น ซม. จะได้แค่ 4.3 ตร.ฟุต) · สูตรใน [`foam/0-data.md`](../foam/0-data.md) คิดถูกอยู่แล้ว แต่หน่วยในตารางนั้นเขียนกำกวม

### 4.2 `STD. COSTING` = ส่วนบวกที่ตั้งใจใส่ในทุกวัสดุ

ราคาที่ใช้ตั้งต้นทุน **สูงกว่าราคาซื้อจริงแทบทุกแถว** และมีคอลัมน์ `ผลต่าง` ไว้ดูส่วนต่าง
บางรายการส่วนต่างสูงมาก (หลายเท่าของราคาซื้อ)

→ ตรงกับข้อ [`costing/2-design.md` §3.1](../costing/2-design.md) ที่เตือนว่า `MARK UP` ในใบเดิมไม่ใช่กำไรขั้นต้นจริง
→ ระบบต้องเก็บ **ทั้งสองราคา** และบอกได้ว่าใบไหนใช้ราคาไหน

## 5 · 🔴 สามเรื่องในใบ costing ที่ตัวเลขยังไม่ครบ

> ตัวเลขจริงอยู่ในแชทกับ Bay · ที่นี่บันทึกแต่กลไก

### 5.1 หน่วยของ "จำนวน" กับหน่วยของ "ราคา" ไม่ตรงกัน 7 บรรทัด

ชีต SE-04 ใส่ `จำนวน` เป็น **หลา/เมตร/กิโล** (ตามใบเบิก)
แต่ `ราคาคิดCOST` ที่คัดมาจากชีตที่ 2 เป็น **ราคาต่อตารางฟุต** (หรือต่อขีด)

`รวม = จำนวน × ราคา` จึง **ขาดตัวคูณ `AREA` ไป** ทุกบรรทัดที่ `AREA ≠ 1`

- บรรทัดที่ `AREA = 1` (เช่น SPUNBOND 100g หน้ากว้าง 1 ม.) **ถูกต้องอยู่แล้ว** → ยืนยันว่าเป็นเรื่องหน่วย ไม่ใช่ราคาผิด
- บรรทัด `ใยปั่น` หนักสุด: `AREA = 10` (ขีด/กก.) → ต่ำกว่าจริง 10 เท่า

### 5.2 ฟองน้ำทั้ง 8 บรรทัด ช่อง `ราคาคิดCOST` ว่าง → รวมเป็น 0

`ราคาต้นทุน` กรอกครบ (= ราคาต่อแผ่นเต็ม ตรงกับชีตที่ 2 ทุกตัว) แต่ `ราคาคิดCOST` ไม่ได้กรอก
→ **ฟองน้ำทั้งตัวไม่ถูกนับในยอดรวมเลย** ทั้งที่เป็นหมวดที่แพงเป็นอันดับต้น ๆ

### 5.3 ผ้าหุ้มไม่มีราคาเลย · และตารางราคาวัตถุดิบไม่มีผ้าหุ้มสักแถว

บรรทัดแรกของใบคือ `ผ้า` 15 เมตร — ไม่มีทั้ง `ราคาต้นทุน` และ `ราคาคิดCOST`
ไล่ทั้ง 429 รายการในชีตที่ 2 แล้ว **ไม่มีผ้าหุ้ม / หนัง / PVC สักรายการ** (มีแต่ผ้าซับ ผ้ารอง ผ้าใย)

→ นี่คือ `PRQ21` เดิมที่ยังไม่ได้คำตอบ · **ผ้าหุ้มอยู่คนละที่ และยังไม่เคยเห็น**

**รวมสามข้อ: ยอดค่าวัสดุในใบนี้ต่ำกว่าความเป็นจริงราวครึ่งหนึ่ง ก่อนบวกผ้าหุ้มด้วยซ้ำ**

| `PRQ40` | **ขาเหล็ก TAKA ไม่มีราคา เขียนว่า “จากนอก”** · นำเข้าใช่ไหม ราคาอยู่ที่ไหน | TAKA เป็นรุ่นที่กำลังทำอยู่ |
