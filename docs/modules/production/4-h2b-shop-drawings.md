## 5 · ข้อสังเกตเชิงระบบ (ยังไม่ตัดสิน)

- ข้อมูลงานโครงการอยู่ใน **รูป + Freeform** · แก้ทีต้องแก้หลายที่ → ตารางกับแบบไม่ตรงกันแล้วอย่างน้อย 7 จุด
- 1 รหัส = แบบ (rev) + ผลตอบ + รายการแก้ + ขั้น P1 + lot ส่ง · ตรงกับของที่ระบบโรงงาน (CostPrg) ไม่มี: ไม่มี revision ไม่มีสถานะอนุมัติ
- งานแบบนี้ "สูตรวัสดุ" เปลี่ยนตามคอมเมนต์ (ฟองน้ำ → สปริง · ยาวขึ้น 20%) → กระทบต้นทุนโดยตรง แต่ไม่เห็นว่ามีจุดไหนผูกกลับไปที่ราคา
