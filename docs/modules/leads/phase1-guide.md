# คู่มือตามลูกค้าจากแชท · ระยะ 1 (เริ่มได้เลย ไม่ต้องสร้างอะไร)

**2026-11-16** · สำหรับทีมที่ตอบแชท LINE @chawcher · Facebook Messenger · Instagram

> ⚠️ **คู่มือนี้ยังไม่ได้ทดสอบบนบัญชีจริงของ Chaw Cher แม้แต่ขั้นเดียว**
> เขียนจากหน้าช่วยเหลือของ LINE และ Meta ที่ค้นได้ (ค้นได้แค่ข้อความสรุป เปิดหน้าเต็มจากเครื่องนี้ไม่ได้)
> ขั้นไหนที่ยืนยันจากหน้าทางการไม่ได้ จะเขียนกำกับว่า **ยังไม่ได้ยืนยันกับหน้าจอจริง**
> ชื่อเมนูบนจอไม่ตรงกับที่เขียน → ถ่ายหน้าจอส่ง Bay ไม่ต้องเดา

**ทำไมต้องทำ:** วันนี้ไม่มีใครติดป้ายแชท · โน้ตว่าง · ลูกค้ากด "ขอ Brochure" แล้วไม่ได้โบรชัวร์ · ถามราคาตอนเย็นได้คำตอบบ่ายวันถัดไป · ตอบราคาแล้วไม่มีใครถามต่อ

**ทำงาน 5 ขั้น:** รับ → จัดกลุ่ม (ติดป้าย) → ตอบ → ตามงาน → สรุปทุกวันศุกร์

**ทางเข้า 3 หน้า**

- [LINE Official Account Manager (ตั้งค่า)](https://manager.line.biz/)
- [LINE Chat (หน้าตอบแชท)](https://chat.line.biz/)
- [กล่องข้อความ Meta Business Suite (Messenger + Instagram)](https://business.facebook.com/latest/inbox)

## 1 · ตั้งป้าย 4 ชุด · ใช้สถานะแชท · เขียนโน้ต

### ป้ายที่ใช้ (พิมพ์ชื่อตามนี้เป๊ะ ทั้ง LINE และ Meta จะได้นับรวมกันได้)

| ชุด | ป้าย |
|---|---|
| เรื่อง | `ถามราคา` · `ขอโบรชัวร์` · `นัดโชว์รูม` · `หลังการขาย` · `งานโครงการ` |
| สินค้า | `โซฟา` · `เตียง` · `เก้าอี้` · `ตู้และโต๊ะ` · `สั่งทำพิเศษ` |
| ความพร้อม | `ร้อน` · `อุ่น` · `เย็น` |
| ขั้น | `ใหม่` · `ตอบแล้ว` · `เสนอราคาแล้ว` · `นัดแล้ว` · `ซื้อ` · `หาย` |

**ความพร้อม ดูจากคำตอบของคำถาม "ต้องการใช้ช่วงไหนครับ"**

| ป้าย | ใช้เมื่อ |
|---|---|
| ร้อน | ลูกค้าบอกวันที่ต้องใช้ชัดเจน หรือขอนัดโชว์รูม |
| อุ่น | กำลังเลือก ยังไม่มีวันที่ชัด |
| เย็น | ดูไว้ก่อน หรือยังไม่ตอบคำถามนี้ |

แชทหนึ่งมีป้าย "ขั้น" ได้ **ป้ายเดียว** · เปลี่ยนขั้นเมื่อไหร่ ถอดป้ายเก่าออกด้วย

### 1.1 สร้างป้ายใน LINE (Bay หรือแอดมินทำครั้งเดียว)

1. เปิด [LINE Chat](https://chat.line.biz/) → เลือกบัญชี @chawcher
2. กดไอคอน **ตั้งค่าแชท** (Chat settings) → เมนู **แท็ก** (Tags) → กด **สร้าง** → พิมพ์ชื่อป้ายตามตารางข้างบน ทีละป้าย จนครบ 19 ป้าย
   - ที่มา: หน้าช่วยเหลือ LINE เขียนว่า "Chats tab → Chat settings → Tags → create" · ตำแหน่งไอคอนบนจอ **ยังไม่ได้ยืนยันกับหน้าจอจริง**
3. **ถ้าสร้างได้แค่ 5 ป้าย หรือติดได้แชทละ 1 ป้าย** → บัญชียังไม่มีแพ็กเกจแชท ให้ใช้แบบย่อข้างล่างแทน แล้วบอก Bay
   - หน้าช่วยเหลือ LINE (ฉบับไต้หวัน) เขียนว่า ไม่มีแพ็กเกจแชท = สร้างได้ 5 ป้าย ติดได้แชทละ 1 ป้าย โน้ตแชทละ 1 อัน · มีแพ็กเกจ = 300 ป้าย ติดได้แชทละ 30 ป้าย · ตัวเลขของประเทศไทย **ยังไม่ได้ยืนยันกับหน้าจอจริง**

**แบบย่อ (เมื่อติดได้แค่ 5 ป้าย)**

- สร้างแค่ชุด **เรื่อง** 5 ป้าย · ติดแชทละ 1 ป้าย
- สินค้า · ความพร้อม · ขั้น → เขียนในโน้ตบรรทัดแรก ตามแบบในข้อ 4

### 1.2 ติดป้ายให้แชทใน LINE (ทุกคน ทุกแชท)

1. เปิดแชทของลูกค้าใน [LINE Chat](https://chat.line.biz/)
2. ที่แผงข้อมูลลูกค้าด้านขวา กด **เพิ่มแท็ก** → เลือกป้ายให้ครบ 4 ชุด (เรื่อง · สินค้า · ความพร้อม · ขั้น) → บันทึก
   - ตำแหน่งปุ่ม **ยังไม่ได้ยืนยันกับหน้าจอจริง**
3. ที่แผงเดียวกัน กด **โน้ต** (Notes) → เขียนตามกฎบรรทัดเดียวในข้อ 4 → บันทึก
4. ตั้งสถานะของแชท
   - ยังมีเรื่องต้องทำต่อ → **ต้องติดตาม** (Follow up)
   - จบเรื่องแล้ว (ซื้อแล้ว หรือปิดเป็น "หาย" แล้ว) → **ดำเนินการเสร็จแล้ว** (Resolve)
   - ชื่อปุ่มสองปุ่มนี้ **ยังไม่ได้ยืนยันกับหน้าจอจริง** (คู่มือ LINE ฉบับเก่าเรียกว่า "Need to Proceed" กับ "Proceeded" · ชื่อปัจจุบันอาจต่าง)
5. ตอนเช้า กดตัวกรองรายการแชทให้เหลือเฉพาะ **ต้องติดตาม** จะเห็นงานค้างทั้งหมด

### 1.3 สร้างป้ายและติดป้ายใน Meta Business Suite

1. เปิด [กล่องข้อความ Meta Business Suite](https://business.facebook.com/latest/inbox) → เลือกเพจ Chaw Cher
2. เปิดแชทของลูกค้าคนไหนก็ได้ → ที่แผงรายละเอียดลูกค้าด้านขวา หาช่อง **ป้ายกำกับ** (Labels) → พิมพ์ชื่อป้ายใหม่ตามตาราง 4 ชุด → บันทึก · ป้ายที่สร้างแล้วเลือกใช้กับแชทอื่นได้
   - หน้าช่วยเหลือ Meta เขียนว่า เพิ่มป้ายกำกับได้ที่โปรไฟล์ลูกค้าในแผงรายละเอียด และค้นกล่องข้อความด้วยป้ายได้ · ขั้นกดทีละปุ่ม **ยังไม่ได้ยืนยันกับหน้าจอจริง**
   - แชท Instagram ใช้ป้ายชุดเดียวกันได้หรือไม่ **ยังไม่ได้ยืนยันกับหน้าจอจริง**
3. ที่แผงเดียวกัน เขียน **โน้ต** ตามกฎบรรทัดเดียวในข้อ 4
   - ช่องโน้ตในแผงรายละเอียด **ยังไม่ได้ยืนยันกับหน้าจอจริง**
4. ตั้งสถานะของแชท
   - ยังมีเรื่องต้องทำต่อ → **ทำเครื่องหมายว่าติดตามผล** (Mark as Follow Up)
   - จบเรื่องแล้ว → **ย้ายไปที่เสร็จสิ้น** (Move to Done) ที่มุมขวาบนของแชท
   - Meta ยืนยันว่ามีทั้งสองอย่างและกรองตาม "ติดตามผล" ได้ · ชื่อปุ่มภาษาไทย **ยังไม่ได้ยืนยันกับหน้าจอจริง**

## 2 · ให้คำว่า "ขอ Brochure" ได้โบรชัวร์ทันที + ข้อความนอกเวลาทำการ

ทั้งสองอย่างเป็น **ข้อความตายตัวที่ Bay อนุมัติ** ระบบของ LINE/Meta ส่งเอง ไม่ใช่ AI แต่ง

### 2.1 LINE · ตอบอัตโนมัติเมื่อลูกค้าพิมพ์ "ขอ Brochure"

1. เปิด [LINE Official Account Manager](https://manager.line.biz/) → เลือกบัญชี @chawcher
2. กด **ตั้งค่า** (มุมขวาบน) → **ตั้งค่าการตอบกลับ** (Response settings) → ดูว่า **แชท** เปิดอยู่ และ **ข้อความตอบกลับอัตโนมัติ** เปิดอยู่
   - LINE ยืนยันว่าเปิดแชทกับข้อความตอบกลับอัตโนมัติพร้อมกันได้
3. กลับหน้าหลัก → เมนูซ้าย **ข้อความตอบกลับอัตโนมัติ** (Auto-response messages) → กด **สร้างใหม่**
4. ช่อง **ชื่อ** พิมพ์ `ขอโบรชัวร์` (ลูกค้าไม่เห็นชื่อนี้)
5. เลือกแบบ **ตอบตามคีย์เวิร์ด** → พิมพ์คีย์เวิร์ดทีละคำแล้วกด Enter: `ขอ Brochure` · `ขอโบรชัวร์` · `brochure` · `โบรชัวร์`
   - LINE เขียนว่าคีย์เวิร์ดต้อง **ตรงทั้งข้อความ** ที่ลูกค้าส่ง · ลูกค้าพิมพ์ "ขอโบรชัวร์หน่อยครับ" จะไม่ติด ต้องตอบเอง
   - ตัวพิมพ์เล็ก-ใหญ่ภาษาอังกฤษถือว่าต่างกันหรือไม่ **ยังไม่ได้ยืนยันกับหน้าจอจริง** → ใส่ทั้ง `ขอ Brochure` และ `ขอ brochure`
6. ช่องข้อความ วางข้อความ "หลังส่งโบรชัวร์" จากข้อ 3.1 → แทน `<ลิงก์โบรชัวร์>` ด้วยลิงก์ไฟล์โบรชัวร์ฉบับล่าสุด (ขอจาก Bay)
   - ข้อความตอบกลับอัตโนมัติแนบไฟล์ PDF ตรงๆ ได้หรือไม่ **ยังไม่ได้ยืนยันกับหน้าจอจริง** → ใช้ลิงก์ไว้ก่อน
7. กด **บันทึก** แล้วเปิดสถานะเป็น **ใช้งาน**
8. ทดสอบ: ใช้มือถือของตัวเอง เปิดแชท @chawcher → กดปุ่ม "ขอ Brochure" ในข้อความ rich message → ต้องได้ลิงก์โบรชัวร์ภายในไม่กี่วินาที
   - ปุ่มใน rich message ส่งคำว่า "ขอ Brochure" เป๊ะตามนี้หรือไม่ **ยังไม่ได้ยืนยันกับหน้าจอจริง** · ถ้ากดแล้วไม่ได้โบรชัวร์ ให้ดูว่าแชทขึ้นข้อความอะไรหลังกดปุ่ม แล้วเอาข้อความนั้นไปเพิ่มเป็นคีย์เวิร์ดในขั้น 5

### 2.2 LINE · ข้อความรับเรื่องนอกเวลาทำการ

1. เปิด [LINE Chat](https://chat.line.biz/) → **ตั้งค่าแชท** → **เวลาตอบข้อความ** (Response hours) → เปิดใช้ → ใส่วันและเวลาทำการจริงของทีม
2. เปิด [LINE Official Account Manager](https://manager.line.biz/) → **ตั้งค่า** → **ตั้งค่าการตอบกลับ** → วิธีตอบ **ในเวลาทำการ** = แชท (คนตอบ) · **นอกเวลาทำการ** = ข้อความตอบกลับอัตโนมัติ
   - LINE ยืนยันว่าเลือกวิธีตอบในเวลาและนอกเวลาแยกกันได้ที่หน้านี้
3. เมนูซ้าย **ข้อความตอบกลับอัตโนมัติ** → **สร้างใหม่** → ชื่อ `นอกเวลาทำการ` → **ไม่ใส่คีย์เวิร์ด** → วางข้อความข้างล่าง → บันทึก → เปิดใช้งาน
   - ข้อความที่ไม่มีคีย์เวิร์ดจะถูกส่งเฉพาะนอกเวลาทำการตามที่ตั้งในขั้น 2 จริงหรือไม่ **ยังไม่ได้ยืนยันกับหน้าจอจริง** · ทดสอบโดยส่งข้อความเข้าไปนอกเวลา 1 ครั้ง และในเวลา 1 ครั้ง
   - LINE ยืนยันว่า ข้อความที่ตรงคีย์เวิร์ด (เช่น ขอ Brochure) ถูกส่งก่อนเสมอ ลูกค้ากดขอโบรชัวร์ตอนกลางคืนก็ยังได้โบรชัวร์

```
สวัสดีครับ ขอบคุณที่ทักมาที่ Chaw Cher
ตอนนี้อยู่นอกเวลาทำการ ทีมงานได้รับข้อความแล้ว และจะตอบกลับในวันทำการถัดไปครับ
ระหว่างนี้พิมพ์สิ่งที่อยากทราบทิ้งไว้ได้เลยครับ
```

### 2.3 Meta · ข้อความนอกเวลาทำการ (Messenger + Instagram)

1. เปิด [กล่องข้อความ Meta Business Suite](https://business.facebook.com/latest/inbox) → กด **ระบบอัตโนมัติ** (Automations)
   - Meta ยืนยันทางเข้านี้: Inbox → Automations
2. เลือก **ข้อความแจ้งไม่อยู่** (Away message) → เปิดใช้ → เลือกช่องทาง Messenger และ Instagram → ตั้งวันและเวลาที่ **ไม่อยู่** → วางข้อความเดียวกับข้อ 2.2 → บันทึก
   - ขั้นกดทีละปุ่มของ Away message **ยังไม่ได้ยืนยันกับหน้าจอจริง**
3. **ตอบกลับทันที** (Instant reply) ไม่ต้องเปิด เว้นแต่ Bay สั่ง · ข้อความนี้ส่งให้ทุกคนที่ทักครั้งแรก ไม่เกี่ยวกับเวลาทำการ

## 3 · ข้อความสำเร็จรูป 8 ข้อ (คัดลอกไปใช้ได้เลย)

**กฎก่อนใช้**

- ข้อความในวงเล็บแหลม `<...>` คือช่องที่ต้องเติมเอง ก่อนกดส่งทุกครั้ง
- **ราคา** ห้ามพิมพ์เอง ห้ามคิดเอง · ถามบอทในกลุ่ม LINE ของทีม แล้วคัดลอกประโยคที่บอทให้มาทั้งประโยค
- **โปรฯ** ใช้เฉพาะที่บอทบอกว่าใช้อยู่วันนั้น
- ไม่พูดเรื่องต้นทุน · ไม่รับปากเรื่องรับประกันหรือวันส่งที่ไม่มีในระบบ
- ลงท้าย "ครับ" เปลี่ยนเป็น "ค่ะ" ได้ตามคนตอบ

**เก็บไว้ที่ไหน**

- LINE: หน้า [LINE Chat](https://chat.line.biz/) → ตั้งค่าแชท → ข้อความที่บันทึกไว้ (Saved replies) → สร้าง 8 ข้อตามชื่อข้างล่าง · ชื่อเมนูและตำแหน่ง **ยังไม่ได้ยืนยันกับหน้าจอจริง**
- Meta: [กล่องข้อความ Meta Business Suite](https://business.facebook.com/latest/inbox) → ข้อความตอบกลับที่บันทึกไว้ (Saved replies) · Meta ยืนยันว่ามีฟีเจอร์นี้ · ขั้นกดสร้าง **ยังไม่ได้ยืนยันกับหน้าจอจริง**
- หาเมนูไม่เจอ → เปิดไฟล์นี้ค้างไว้แล้วคัดลอกจากตรงนี้

### 3.1 หลังส่งโบรชัวร์

```

ดูแล้วสนใจรุ่นไหน หรืออยากทราบขนาด ผ้า และราคา พิมพ์บอกได้เลยครับ
```


```
@Team Bay ราคา <ชื่อรุ่น>
```

บอทตอบราคาเฉพาะในกลุ่มที่ Bay เปิดสิทธิ์ "เห็นราคา" ไว้ · ถามแล้วไม่ตอบ ให้แจ้ง Bay · ระหว่างรอ ห้ามคิดราคาเอง

### 3.3 ชวนมาโชว์รูม

```
ถ้าสะดวก ขอชวนมาลองนั่งของจริงที่โชว์รูมครับ จะได้เห็นขนาด สัมผัสผ้า และเทียบรุ่นได้ในครั้งเดียว
ตอนนี้มีโปรฯ <โปรฯ ที่ใช้อยู่วันนี้ ตามที่บอทบอก> ดูรายละเอียดได้ที่ <ลิงก์หน้าโปรฯ>
สะดวกวันไหน ช่วงเวลาไหน บอกได้เลยครับ ผมจะจองเวลาไว้ให้
```

`<ลิงก์หน้าโปรฯ>` ใช้ลิงก์นี้: [หน้าโปรโมชันของ Chaw Cher](https://chawcher.com/category/promotion/)

### 3.4 ยืนยันนัด (ส่งก่อนวันนัด 1 วัน)

```
สวัสดีครับ ขอยืนยันนัดเข้าชมโชว์รูม Chaw Cher วัน<วันที่> เวลา <เวลา> ครับ
ถ้าต้องการเปลี่ยนวันหรือเวลา แจ้งได้เลยครับ
แนะนำให้นำขนาดห้องหรือรูปมุมที่จะวางมาด้วย จะช่วยเลือกขนาดได้ตรงขึ้นครับ
```

### 3.5 ทักตาม · ส่งโบรชัวร์แล้วเงียบ 2 วัน

```
สวัสดีครับ ไม่ทราบว่าได้ดูโบรชัวร์ที่ส่งไปแล้วหรือยังครับ
ถ้ามีรุ่นที่สนใจ หรืออยากให้ช่วยเลือกตามขนาดห้อง บอกได้เลยครับ
```

### 3.6 ทักตาม · ตอบราคาแล้วเงียบ 3 วัน

```
สวัสดีครับ เรื่อง <ชื่อรุ่น> ที่สอบถามไว้ ไม่ทราบว่ามีข้อสงสัยเพิ่มเติมไหมครับ
ถ้าอยากเห็นของจริงก่อนตัดสินใจ มาลองนั่งที่โชว์รูมได้ครับ ตอนนี้มีโปรฯ <โปรฯ ที่ใช้อยู่วันนี้ ตามที่บอทบอก>
สะดวกวันไหนบอกได้เลยครับ
```

### 3.7 ดูแลหลังการขาย (ส่งหลังส่งของ 7 วัน)

```
สวัสดีครับ <ชื่อรุ่น> ใช้งานมาได้ประมาณหนึ่งสัปดาห์แล้ว เป็นอย่างไรบ้างครับ
ถ้ามีจุดไหนไม่เรียบร้อย หรืออยากได้คำแนะนำการดูแลผ้าและไม้ บอกได้เลยครับ ยินดีดูแลครับ
```

คำแนะนำการดูแล ให้ตอบจากหน้า [คำถามที่พบบ่อย](https://chawcher-os.vercel.app/faq) เท่านั้น ไม่แต่งเอง

### 3.8 ปิดเรื่อง (ทักตาม 2 ครั้งแล้วไม่ตอบ)

```
สวัสดีครับ ผมขอไม่รบกวนเพิ่มแล้วนะครับ
ถ้าวันไหนพร้อม หรืออยากได้ข้อมูลเพิ่ม ทักมาที่นี่ได้ทุกเมื่อ ยินดีดูแลครับ
ขอบคุณที่สนใจ Chaw Cher ครับ
```

ส่งแล้ว เปลี่ยนป้ายขั้นเป็น `หาย` · เขียนเหตุผลในโน้ต · ตั้งสถานะแชทเป็นเสร็จแล้ว

**หลังส่งของ 30 วัน** (ขอรูปบ้านและคำอนุญาต) ยังไม่มีข้อความสำเร็จรูปในคู่มือนี้ · ใช้ข้อความและถ้อยคำยินยอมในข้อ 3 ของ [แผน sprint พ.ย. 2569](https://github.com/baysireekahnokrath/Chawcheros/blob/ccr-ea409c75-vpgkyx/docs/marketing/sprint-2569-11.md)

## 4 · กิจวัตรตอนเช้า 10 นาที + กฎของโน้ต

### ทุกเช้า ก่อนตอบแชทใหม่

1. เปิด [LINE Chat](https://chat.line.biz/) → ตอบแชทที่ยังไม่ได้อ่านจากเมื่อคืนก่อน เรียงจากเก่าสุด (3 นาที)
2. เปิด [กล่องข้อความ Meta Business Suite](https://business.facebook.com/latest/inbox) → ทำแบบเดียวกันกับ Messenger และ Instagram (2 นาที)
3. กรองแชท **ต้องติดตาม** ทั้งสองที่ → อ่านโน้ตของแต่ละแชท → ใครถึง "วันทำต่อ" วันนี้ ส่งข้อความตามตารางข้างล่าง (4 นาที)
4. แชทที่ตอบแล้วทุกแชท: ป้ายครบ 4 ชุด · โน้ตมีวันทำต่อ · สถานะถูก (1 นาที)

| เหตุการณ์ | ทำอะไร | ใช้ข้อความ |
|---|---|---|
| ลูกค้าทักในเวลาทำการ | ตอบภายใน 1 ชั่วโมง | — |
| ลูกค้าทักนอกเวลา | ระบบส่งข้อความรับเรื่องเอง · คนตอบตอนเช้า | ข้อ 2.2 |
| ส่งโบรชัวร์แล้ว เงียบ 2 วัน | ทักตาม | 3.5 |
| ตอบราคาแล้ว เงียบ 3 วัน | ชวนมาโชว์รูม พร้อมโปรฯ ที่ใช้อยู่ | 3.6 |
| ก่อนวันนัด 1 วัน | ยืนยันนัด | 3.4 |
| ทักตาม 2 ครั้งแล้วไม่ตอบ | ปิดเรื่อง · ป้าย `หาย` + เหตุผล | 3.8 |
| หลังส่งของ 7 วัน | ถามการใช้งาน เสนอคำแนะนำการดูแล | 3.7 |
| หลังส่งของ 30 วัน | ขอรูปบ้านและคำอนุญาต | แผน sprint ข้อ 3 |

### กฎของโน้ต · บรรทัดเดียว เรียงตามนี้ทุกครั้ง

```
ใช้ <วันที่ต้องการใช้> | ห้อง <กว้าง x ยาว> | <สินค้า/รุ่น> | ทำต่อ <วันที่> <จะทำอะไร>
```

- ไม่รู้ช่องไหน ใส่ `?` ไว้ อย่าเว้นว่าง · จะได้รู้ว่าต้องถามเพิ่ม
- ทุกแชทที่ยังไม่จบ **ต้องมี "ทำต่อ <วันที่>"** เสมอ
- ปิดเป็น `หาย` → ต่อท้ายด้วยเหตุผล: `ราคา` · `ขนาดไม่ลง` · `ซื้อที่อื่น` · `เลื่อนโครงการ` · `ไม่ตอบ` · `อื่นๆ`
- ไม่เขียนเลขบัตร เลขบัญชี หรือเรื่องส่วนตัวที่ไม่เกี่ยวกับการขายลงโน้ต
- ถ้าใช้แบบย่อ (ติดป้ายได้ป้ายเดียว) ให้ขึ้นต้นโน้ตด้วย `<ความพร้อม> | <ขั้น> |` เช่น `อุ่น | เสนอราคาแล้ว | ใช้ ...`

## 5 · ทุกวันศุกร์ นับมือ 4 อย่าง (จนกว่าระบบระยะ 2 จะนับให้)

ใช้เวลาประมาณ 15 นาที · นับเฉพาะแชทที่เข้ามาใหม่ตั้งแต่วันเสาร์ก่อนหน้าถึงวันศุกร์ · ส่งตัวเลขให้ Bay ในกลุ่ม LINE ของทีม · **ส่งแต่ตัวเลข ไม่ส่งชื่อลูกค้า**

1. **แชทใหม่ แยกช่องทาง**

| LINE | Messenger | Instagram | รวม |
|---|---|---|---|
| | | | |

2. **แชทใหม่ แยกตามเรื่อง** (กรองด้วยป้ายชุด "เรื่อง")

| ถามราคา | ขอโบรชัวร์ | นัดโชว์รูม | หลังการขาย | งานโครงการ |
|---|---|---|---|---|
| | | | | |

3. **ตอนนี้อยู่ขั้นไหน กี่คน** (กรองด้วยป้ายชุด "ขั้น")

| ใหม่ | ตอบแล้ว | เสนอราคาแล้ว | นัดแล้ว | ซื้อ | หาย |
|---|---|---|---|---|---|
| | | | | | |

4. **คำถามที่ลูกค้าถามซ้ำมากที่สุด 3 ข้อ** ของสัปดาห์นี้ (เขียนเป็นประโยคสั้นๆ)

- การกรองรายการแชทด้วยป้ายเพื่อดูจำนวน ทั้งใน LINE และ Meta **ยังไม่ได้ยืนยันกับหน้าจอจริง** · ถ้ากรองแล้วไม่ขึ้นจำนวน ให้นับจากรายการที่กรองได้
- คน "หาย" ให้เขียนเหตุผลที่เจอมากที่สุดของสัปดาห์มาด้วย 1 บรรทัด
