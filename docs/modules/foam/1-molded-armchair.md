# Armchair โฟมหล่อหุ้มโครงไม้ · แนวคิด

บันทึก 2026-11-21 · Bay ถามแนวทาง · **ยังเป็นแนวคิด ยังไม่ได้ทดลองจริง** · ตัวเลขทั้งหมดเป็นค่าเริ่มต้นทั่วไปของอุตสาหกรรม ต้องให้วิศวกรยืนยัน
mockup: `docs/molded-armchair/mockup.html`

## แนวคิดของ Bay

โครงไม้ CNC + แม่พิมพ์จาก 3D printing + กรอกโฟมให้ขึ้นรูปตามแบบ (ปรึกษาวิศวกรวัสดุ / พอลิเมอร์ / เคมี เรื่องสูตร) → pattern พิมพ์จากไฟล์ → เย็บ → หุ้มให้ง่าย เสร็จใน 5 นาที

วิธีนี้คือ cold-cure molded PU foam หุ้มโครง (แบบเบาะรถยนต์ และเก้าอี้ทรงโค้งของอิตาลี)

## ลำดับงาน 7 ขั้น

จุดที่ต่างจากลำดับเดิมของ Bay: **ออกแบบวิธีหุ้ม (ขั้น 2) ก่อนทำแม่พิมพ์** เพราะร่องยึดผ้าต้องหล่อติดมากับโฟม

| # | ขั้น | รายละเอียด | ใครทำ |
|---|---|---|---|
| 1 | Technical drawing → โมเดล 3D ตัวเดียว | ต้นทางของโครง แม่พิมพ์ pattern | ออกแบบ |
| 2 | วางแนวตะเข็บ ร่องดึงผ้า ซิป ในโมเดล | แบ่งผ้ากี่แผ่น ตะเข็บไหนลงร่อง ซิปตรงไหน ชายล่างเกี่ยวอะไร | ออกแบบ + ช่างเย็บ + ช่างหุ้ม |
| 3 | CNC โครงไม้ | ไม้อัดเข้าลิ่ม · T-nut ยึดขา · ร่องรอบฐานไว้เกี่ยวชายผ้า | โครงไม้ |
| 4 | แม่พิมพ์ | 3D print ตัวต้นแบบ → หล่อแม่พิมพ์ไฟเบอร์กลาส · หมุดล็อกโครง · รูระบายอากาศที่จุดสูงสุด · สันสำหรับร่องดึงผ้า | 3D print + ร้านไฟเบอร์กลาส |
| 5 | เลือก/ปรับสูตรโฟม แล้วเท | ระบบ polyol + MDI จาก system house | วิศวกร + แผนกฟองน้ำ |
| 6 | คลี่ผิว 3D เป็น pattern 2D → พิมพ์ | ซอฟต์แวร์คลี่ผิว (เช่น ExactFlat, Rhino) · ย่อ 2–4% ให้ผ้าตึง | วางแบบ |
| 7 | เย็บ → หุ้ม → ปิดใต้ฐาน → ใส่ขา | | เย็บ + หุ้ม + QC |

## 3 เรื่องที่ต้องรู้ก่อนลงทุน

1. **แม่พิมพ์ 3D print ล้วนรับแรงไม่ไหว** · โฟมฟูดันราว 0.5–1 bar (1 ตร.ม. = แรงหลายตัน) · PLA นิ่มที่ราว 55–60°C → พิมพ์ตัวต้นแบบแล้วหล่อแม่พิมพ์ไฟเบอร์กลาส หรือพิมพ์เปลือก PETG/ABS เสริมโครงไม้อัดด้านหลัง · ต้องเคลือบผิว + น้ำยาถอดแบบ
2. **สูตรโฟมไม่ต้องคิดจากศูนย์** · ซื้อระบบ 2 ส่วนจาก system house · วิศวกรกำหนด: ความแน่น (โฟมหล่อปกติ 40–60 kg/m³ · ฟองน้ำแผ่นที่ใช้อยู่ 20–37 ดู `0-data.md`) · ความแข็ง · การคืนตัว · น้ำหนักเทต่อชิ้น · อุณหภูมิพิมพ์ · เวลาถอด
3. **ไม้ต้องแห้ง** (ความชื้นไม่เกินราว 10–12%) ไม่งั้นเกิดโพรงรอบโครง · isocyanate เป็นสารก่อภูมิแพ้ทางเดินหายใจ ต้องมีระบบดูดอากาศ + PPE

## วิธีหุ้ม · เป้า 5 นาที

- **หุ้ม 1 ชิ้น** เย็บจาก 6 แผ่น: พนักใน+แขนใน 1 · ที่นั่ง 1 · ขอบหน้า 1 · หน้าแขน 2 · พนักนอก+แขนนอก 1 · สวมจากบนลงล่างแบบถุง · เบาะนั่งลอย (ถ้ามี) = ชิ้นที่ 2 มีซิปของตัวเอง
- **ร่องดึงผ้า** หล่อร่องลึกในโฟมตรงรอยต่อที่นั่ง–พนัก–แขน · ก้นร่องฝังตีนตุ๊กแกด้านหนาม · ตะเข็บผ้าเย็บด้านขน · กดลงร่องก็ยึด ไม่ต้องยิงแม็ก
- **ซิป 2 เส้น** แนวตั้งที่มุมหลังซ้าย–ขวา ซ่อนในตะเข็บ
- **ชายล่าง** แถบพลาสติกรูปตัว J เกี่ยวร่องรอบฐาน → ปิดแผ่นใต้ฐาน → ขันขาทับ
- **Pattern เล็กกว่าผิวจริง 2–4%** ขึ้นกับผ้า ต้องลองต้นแบบ 2–3 รอบ · ผ้ายืดง่ายกว่าหนังมาก

## คำแนะนำ

- คุ้มกับทรงโค้งที่ตัดแปะฟองน้ำยากและขายได้หลายตัวต่อแบบ · ทรงเหลี่ยมใช้วิธีเดิมถูกกว่า
- เริ่มจากชิ้นเล็ก (สตูล / ที่นั่งเก้าอี้) เพื่อทดลองสูตรโฟม แม่พิมพ์ ร่องดึงผ้า ก่อนขึ้น armchair

## ยังไม่รู้ · ต้องหา

- system house ในไทยที่ขายระบบโฟมหล่อปริมาณน้อย และซัพพลายเออร์ฟองน้ำเดิม (กรุงเทพโฟม ฯลฯ) ทำโฟมหล่อได้ไหม
- ราคาแม่พิมพ์ไฟเบอร์กลาสขนาด armchair และจำนวนตัวที่คุ้มทุน
- รุ่นไหนจะใช้เป็นตัวทดลอง
