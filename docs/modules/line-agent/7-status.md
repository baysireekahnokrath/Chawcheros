(ต่อจาก: ลูกค้าทัก LINE OA → AI อ่าน → แสดงคำตอบแนะนำ → คนกดส่ง)

| ช่องทาง | ต่อได้ไหม (ยังไม่ได้ตรวจเอกสารล่าสุด) |
|---|---|
| LINE OA ลูกค้า (@Chawcher?) | ได้ · Messaging API แบบเดียวกับ Team Bay · ส่งจากระบบน่าจะนับโควตา |
