## แผนสร้างรอบถัดไป · 3 ชุด

### ชุด A · แต่ละกลุ่มเห็นไม่เหมือนกัน + ข้อความพร้อมส่งลูกค้า
| อะไร | รายละเอียด |
|---|---|
| สิทธิ์รายกลุ่ม | ตั้งในหน้า `/line` ต่อกลุ่ม: ราคา · ชื่อลูกค้า · ยอดเงิน · ที่อยู่/เบอร์ · ตั้งค่าเริ่มต้นตามตารางด้านบน · กลุ่มใหม่ปิดหมด |
| ดึงจากชีตเพิ่ม | ชื่อลูกค้า · ยอดขาย · ยอดค้าง (Order Tracking) · ที่อยู่/เบอร์ ยังไม่ดึง (ยังไม่มีงานไหนใช้) · ต้นทุนไม่ดึงตลอดไป |
| ข้อความพร้อมส่งลูกค้า | กลุ่ม Check progress: ถามสถานะ/วันส่ง → บอทตอบทีม + กล่อง "ก็อปส่งลูกค้า" · **โค้ดเขียนตัวเลขและวันที่** (LR-24) · คำสุภาพตามแบบที่ตั้งได้ · คนก๊อปไปส่งเอง บอทไม่ส่งลูกค้าเอง (กฎ AI 1) |

### ชุด B · รูป: สลิป + งานเสร็จ
| อะไร | รายละเอียด |
|---|---|
| ที่เก็บรูป | ที่เก็บไฟล์ส่วนตัวของระบบ (ไม่ใช่ลิงก์สาธารณะ) · บอทคัดลอกรูปจาก LINE ทันทีที่ถูกสั่ง |
| สลิป (กลุ่ม PO) | Reply รูป → `@Team Bay สลิป` → AI อ่าน ยอด · วันที่ · ธนาคาร · เลขอ้างอิง → จับคู่ BLS จากชื่อ+ยอดค้าง → ถามยืนยันในกลุ่ม → หน้า **"สลิปรอยืนยัน"** ให้พี่ษา ✅ / ✏️ / ❌ → "ลงชีตแล้ว" · กันสลิปซ้ำจากเลขอ้างอิง |
| งานเสร็จ (กลุ่มเช็คงาน) | Reply รูป → `@Team Bay งานเสร็จ BLS3230` → เก็บรูปผูกกับ BLS · ถามสถานะ BLS นั้นทีหลัง บอทบอกได้ว่า "มีรูปงานเสร็จแล้ว" |

### ชุด C · บอทพูดเอง + จดคำขอ
| อะไร | รายละเอียด |
|---|---|
| ใบงานผลิต | BLS ใหม่ขึ้นในชีต (มีแท็บใน PO template) → บอทส่งใบงานเข้ากลุ่ม PO เอง 1 ครั้ง · กันส่งซ้ำ |
| คำขอเปลี่ยน | "ขอเลื่อน/เปลี่ยน" → นอกจากส่งต่อทีม จดเป็นคำขอค้างในหน้า `/line` จนกว่าคน CC กดปิด |
