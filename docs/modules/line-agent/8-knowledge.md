## ความเป็นส่วนตัว (ที่ Bay ควรรู้)

- ข้อความที่ส่งให้ Claude สรุป **ไม่มีชื่อผู้พูด** (ใช้ "คน1" "คน2") · เบอร์โทรในผลถูกปิดทับ · เรื่องที่มี ต้นทุน/กำไร ถูกทิ้งทั้งข้อ
- แต่ **เนื้อข้อความ** ถูกส่งไปที่ Anthropic (ผู้ให้บริการ Claude) จึงเติมประโยค "ใช้ระบบ AI ช่วยอ่านและสรุป" ในประกาศแจ้งทีม (`kb-notice.ts`) · ร่างเดิมของ Bay ไม่มีประโยคนี้
- ทุกข้อที่ AI ร่างต้องแนบ**หลักฐานต้นทาง** (ข้อความจริง) · ไม่มีหลักฐาน = โค้ดทิ้ง
- ไม่เก็บรูป/ไฟล์/สติกเกอร์ · ไม่เก็บข้อความที่ทักบอท (อยู่ใน `requests` อยู่แล้ว) · ห้อง "Check progress" ยังไม่เปิดเก็บ (Bay ตอบเฉพาะ PO + เช็คงาน)

## วิธีใช้ในกลุ่ม LINE

| พิมพ์ | ผล |
|---|---|
| `@Team Bay จดเรื่องนี้ ผ้ากันน้ำซักมือเท่านั้น` | จดเป็นร่างเข้าคลัง (ใช้ได้ทุกห้องที่อนุมัติ) |
| Reply ข้อความ → `@Team Bay จดเรื่องนี้` | จดข้อความที่ Reply (ต้องเป็นข้อความที่ห้องเปิดเก็บไว้แล้ว ไม่งั้นบอทบอกให้พิมพ์เอง) |
| `@Team Bay ผ้ากันน้ำซักเครื่องได้ไหม` | ตอบจากคลังที่ยืนยันแล้ว + "ดูจาก: คลังความรู้ · Bay ยืนยัน วันที่…" · ไม่มี = "ยังไม่มีเรื่องนี้ในคลัง ผมไม่เดา" · กลุ่มที่ปิดสิทธิ์ = บอกว่ายังไม่เปิดใช้ |

กลุ่มที่เปิด "แนบข้อความพร้อมส่งลูกค้า" (Check progress) จะได้กล่อง "ก็อปส่งลูกค้า" จาก `public_body` ด้วย ถ้าข้อนั้นเขียนไว้

## ค่าใช้จ่าย

รอบสรุปใช้ Sonnet 5.5 · ก้อนละ ~24,000 ตัวอักษร · ไม่เกิน 4 ก้อน/รอบ · นับรวมงบผู้ช่วย ฿500/เดือนเดิม (`v_budget`) · งบไม่พอหรือพักบอท = ไม่รัน · ข้อความที่ยังไม่ได้อ่านรอรอบหน้า

## ที่ยังไม่ได้ทำ / ยังไม่ได้ตรวจ

- รอบสรุป AI **ยังไม่เคยรันกับ Claude จริง** (ไม่มี key ในเครื่องทดสอบ) · ตรวจ SQL + โค้ด + typecheck + build แล้ว
- ชุดทดสอบความเข้าใจคำถาม `web/scripts/line-eval.mts` เพิ่ม 4 ข้อ (รวม 40) **ยังไม่ได้รัน** (ต้องใช้ key · ~฿10) · ต้องรันก่อนขึ้นของจริง (LR-26)
- ยังไม่ผูกคลังความรู้กับหน้าลูกค้าใน CRM (KB-B ส่วน "คุยอะไรกับลูกค้า") · ชุดต่อไป
- ค้นหาแบบนับคำตรงกัน (ยังไม่ใช้ vector/ฟัซซี่) · ถ้าข้อมูลโตจนค้นไม่เจอค่อยปรับ
