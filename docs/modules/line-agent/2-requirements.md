# LINE Agent ห้อง CC · ด่าน 2 Requirement

**2026-10-31** · ต่อจาก `0-idea.md` · **ไม่มีคำถามค้าง** — ข้อที่ Bay ยังไม่ตอบ ผมตัดสินด้วยค่าที่ปลอดภัยที่สุดแล้ว (หมวด ก)
Bay อ่านแล้วตอบแค่ *"ข้อ X ตัด / ข้อ Y เปลี่ยนเป็น..."* · ไม่ตอบ = ผ่าน

---

## ก · ค่าที่ผมตัดสินแทน (แก้ได้ทุกข้อ)

| # | เรื่อง | ผมตั้งเป็น | ทำไม |
|---|---|---|---|
| D1 | ตอบเมื่อไหร่ | **เฉพาะตอนถูก @ทัก** · ไม่พูดเอง | ใช้ reply ≈ ไม่เสียค่า LINE · ไม่ต้องรู้จำนวนคนในห้อง |
| D2 | LINE OA | **เปิด OA ใหม่ แพ็กเกจฟรี** แยกจาก OA ที่คุยลูกค้า | ไม่ปนกับลูกค้า · ฟรีพอเพราะ D1 |
| D3 | เก็บข้อความในห้อง | **ไม่เก็บ**ข้อความที่ไม่ได้ทักบอท · เก็บเฉพาะคำถามที่ทัก + คำตอบ | ในห้องมีพนักงานบริษัทอื่น |
| D4 | แจ้งทีม ASE | Bay โพสต์ 1 ข้อความตอนเชิญบอท (ร่างไว้ท้ายไฟล์) | ตรงไปตรงมา |
| D5 | ชื่อบอท | **"CC ผู้ช่วย"** · พูดสุภาพ ลงท้าย "ครับ" | เปลี่ยนชื่อ/รูปในหน้า LINE OA ได้เองทุกเมื่อ ไม่ต้องแก้โค้ด |
| D6 | งบ Claude | **฿500/เดือน** แยกจากงบคอนเทนต์ · ใช้ระบบเพดานงบเดิม | ปรับได้ในหน้าตั้งค่า |
| D7 | ราคาขาย · ชื่อคนยืม (LQ9) | **ซ่อน** | Bay ยังไม่ตัดสิน · เปิดทีหลังง่าย ลบข้อความที่ส่งไปแล้วไม่ได้ |
| D8 | ออเดอร์ที่ยังไม่อยู่ในระบบ (LQ14) | บอทตอบจาก**ที่ระบบมีเท่านั้น** · ไม่เจอ = "ยังไม่มี BLS นี้ในระบบ" | ตรวจแล้ว: ยังไม่เคยนำเข้าออเดอร์จากชีต · ออเดอร์ที่ลงผ่านเว็บจากนี้ไปจะตอบได้เอง |
| D9 | เลขงาน (LQ12) | รู้จัก**เลข BLS** + เลข w/o | ทั้งสองมีในโมดูลออเดอร์แล้ว |

## ข · ต้องทำอะไรได้

### รับข้อความ

| # | ข้อกำหนด |
|---|---|
| LR-1 | รับ webhook จาก LINE ที่เว็บเดิมบน Vercel · **ตรวจลายเซ็นทุกครั้ง** ไม่ผ่าน = ทิ้ง |
| LR-2 | ตอบเฉพาะข้อความที่ **@ทักบอท** ในห้องที่ลงทะเบียนไว้ (ห้อง CC) · ห้องอื่น/แชทส่วนตัว = เงียบ |
| LR-3 | ลงทะเบียนห้อง: บอทเข้าห้องใหม่ → ขึ้นในหน้าตั้งค่าเป็น "รออนุมัติ" → Bay กดอนุมัติ ถึงเริ่มตอบ |
| LR-4 | LINE ส่งข้อความเดิมซ้ำ → ตอบครั้งเดียว |

### ตอบอะไรได้ (อ่านอย่างเดียว)

| # | คนพิมพ์ประมาณ | บอทตอบจาก |
|---|---|---|
| LR-5 | "BLS1234 รายละเอียด" | รายการในออเดอร์: รุ่น · ขนาด · วัสดุ/สี · จำนวน · w/o |
| LR-6 | "BLS1234 ต้องเสร็จ/ส่งวันไหน" | วันต้องผลิตเสร็จ · กำหนดส่ง |
| LR-7 | "สัปดาห์นี้/เดือนนี้ต้องเสร็จอะไรบ้าง" · "งานไหนเลยกำหนด" | รายการ BLS เรียงตามวัน |
| LR-8 | "Emu 3 ที่นั่ง ผ้าเทา มีในสต็อกไหม" · "ผ้า X ยังมีไหม" | สต็อกสินค้า (จำนวน · อยู่ที่ไหน · สถานะ) · สถานะผ้า มี/หมด |
| LR-9 | "BLS1234 ถึงไหนแล้ว" | ตอบตรงๆ: **"ระบบยังไม่มีสถานะผลิต"** + บอกวันต้องเสร็จที่มี |
| LR-10 | อะไรที่อยู่นอก LR-5 ถึง LR-8 | "เรื่องนี้ผมยังตอบไม่ได้ครับ" · ไม่เดา |

### กำแพงข้อมูล

| # | ข้อกำหนด |
|---|---|
| LR-11 | บอทอ่านได้จาก**มุมมองสำหรับห้อง CC** เท่านั้น · มุมมองนี้**ไม่มีคอลัมน์**: ต้นทุน · กำไร · ราคาขาย · ยอดเงิน/สถานะการเงิน · ชื่อ เบอร์ ที่อยู่ลูกค้า · ช่องทางขาย · ชื่อคนยืม |
| LR-12 | ใครถามก็ได้ข้อมูลชุดเดียวกัน (Bay ถามก็ไม่เห็นต้นทุนในห้องนี้) |
| LR-13 | ทดสอบอัตโนมัติ: สั่งให้บอทบอกต้นทุน/ชื่อลูกค้าหลายแบบ → ต้องไม่ได้ข้อมูล เพราะไม่มีในมือ |

### ห้ามตัดสินแทน CC

| # | ข้อกำหนด |
|---|---|
| LR-14 | คำขอเลื่อน · เปลี่ยนสเปก · ยกเลิก · ถามราคา → ตอบ "รับเรื่องครับ ขอให้ทีม CC ตอบ" · ไม่พูดว่าได้หรือไม่ได้ |
| LR-15 | ไม่มีปุ่ม/คำสั่งที่เขียนข้อมูลลงระบบในเฟส 1 |

### ทุกคำตอบ

| # | ข้อกำหนด |
|---|---|
| LR-16 | ห้ามแต่งข้อมูล · ทุกตัวเลข/วันที่มาจากระบบ · ท้ายคำตอบบอกว่าดูจากอะไร |
| LR-17 | ตอบสั้น ภาษาไทย อ่านบนมือถือ · ไม่เกิน ~10 บรรทัด · ยาวกว่านั้นตัดแล้วบอกว่ามีอีกกี่รายการ |
| LR-18 | ช้าเกินเวลาที่ LINE ให้ตอบ → ไม่ตอบเลยดีกว่าเสียเงิน push · บันทึกว่าตอบไม่ทัน |

### หลังบ้าน (หน้าตั้งค่าในเว็บ · Bay เท่านั้น)

| # | ข้อกำหนด |
|---|---|
| LR-19 | บันทึกทุกครั้ง: เวลา · ห้อง · ชื่อ LINE คนถาม · คำถาม · ข้อมูลที่บอทดึง · คำตอบ · ค่า Claude (ตามกฎ AI 3) |
| LR-20 | หน้าดูบันทึก + ยอดใช้เดือนนี้เทียบงบ |
| LR-21 | ปุ่ม **พักบอท** · พักแล้วบอทเงียบทันที |
| LR-22 | งบหมด → ตอบในห้องครั้งเดียว "งบเดือนนี้หมดแล้วครับ" แล้วเงียบ |
| LR-23 | สถานะการเชื่อมต่อ LINE: ใช้ได้ / token ผิด / บอทถูกเตะออกจากห้อง |

## ค · ไม่ทำในเฟส 1

แชทส่วนตัวกับบอท (ข้อมูลภายใน CC) · สรุปเช้า/เตือนเอง · จับสถานะจากแชทมาบันทึก · รูปเช็คงาน · บันทึกคำขอเปลี่ยนแปลงเป็นรายการ · ระบบของ ASE (backlog B5)

## ง · Bay ต้องทำเอง (ตอนด่าน 4 · ผมทำแทนไม่ได้)

1. สร้าง LINE OA ใหม่ + เปิด Messaging API + เปิด "อนุญาตเข้าห้องกลุ่ม" (ผมเขียนขั้นตอนทีละคลิกให้ตอนนั้น)
2. ใส่ `LINE_CHANNEL_SECRET` กับ `LINE_CHANNEL_ACCESS_TOKEN` ใน Vercel
3. เชิญบอทเข้าห้อง CC · กดอนุมัติห้องในเว็บ · โพสต์ข้อความแจ้งทีม

**ร่างข้อความแจ้งทีม (D4)**

> แจ้งทุกคนครับ ห้องนี้มีผู้ช่วย "CC ผู้ช่วย" เข้ามาแล้ว
> พิมพ์ @CC ผู้ช่วย ตามด้วยเลข BLS หรือชื่อสินค้า เพื่อถามรายละเอียดงาน วันส่ง และสต็อก
> ผู้ช่วยตอบจากระบบเท่านั้น ไม่ตัดสินแทนทีม และจะเก็บเฉพาะข้อความที่ทักผู้ช่วยครับ
