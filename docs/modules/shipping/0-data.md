## สถานะการเข้าถึงเว็บ RTT

**เข้าไม่ได้จาก session นี้** — ชื่อโฮสต์ `www.rttexpress.co.th` ไม่อยู่ในรายชื่อโดเมน
ที่สภาพแวดล้อมนี้อนุญาต · ค้นเว็บทั่วไปก็ไม่เจอตารางราคาของ RTT เลย

ยังไม่รู้จึงยังตอบไม่ได้ว่า
- เว็บมีเครื่องคิดค่าส่งให้กรอกขนาด/น้ำหนักเองไหม หรือต้องโทรถาม
- คิดตามน้ำหนัก (กก.) หรือตามปริมาตร (คิว) — **สำคัญมากกับเฟอร์นิเจอร์**
- ครอบคลุมพื้นที่ไหน ต่างจังหวัดคิดเพิ่มยังไง
- มี API ให้ดึงราคาอัตโนมัติไหม (น่าจะไม่มี แต่ยังไม่ได้ตรวจ)

## สิ่งที่ทำได้ · เรียงตามความแน่นอน

| ชั้น | ทำอะไร | ประเมิน |
|---|---|---|
| **1** | โชว์ **คิว** ของสินค้าทุกตัวในระบบ (คำนวณสดจากขนาด ไม่เก็บเป็นช่องให้แก้) · เซลส์ไม่ต้องวัดหรือเดา | ✅ ทำได้เลย ข้อมูลครบแล้ว |
| **2** | ใส่**ตารางราคา RTT** เข้าระบบ แล้วคิดค่าส่งให้อัตโนมัติจากคิว + ปลายทาง + มี/ไม่มียก | ✅ ทำได้ ถ้าได้ตารางราคามา |
| **3** | ดึงราคาจากเว็บ RTT สดๆ | ⚠️ ยังตอบไม่ได้ ต้องเข้าเว็บก่อน · ถ้าไม่มี API ก็ไม่ควรทำ จะพังเมื่อเว็บเปลี่ยน |

**ชั้น 2 คือตัวที่คุ้มที่สุด** — ตารางราคาขนส่งไม่ค่อยเปลี่ยน ปีละครั้งสองครั้ง
ใส่เข้าระบบครั้งเดียวแล้วเซลส์ตอบลูกค้าได้ทันทีโดยไม่ต้องเปิดเว็บ RTT ทุกครั้ง

## เกี่ยวกับงานอื่นยังไง

- **B1 (ลิงก์สถานะสินค้าให้ลูกค้า)** — ถ้าส่งด้วย RTT ต้องรู้ว่า RTT มีเลข tracking
  ให้ดึงมาโชว์ไหม ไม่งั้นลิงก์สถานะจะจบแค่ "ออกจากโกดังแล้ว"
- **โมดูลออเดอร์ (ยังไม่สร้าง)** — ค่าส่งเป็นบรรทัดหนึ่งในใบเสนอราคา/ออเดอร์
  ควรออกแบบไปพร้อมกัน ไม่ใช่แปะทีหลัง
- **B3 (ขายออนไลน์)** — ถ้าจะขายออนไลน์ ต้องคิดค่าส่งอัตโนมัติตอน checkout
  ซึ่งต้องมีชั้น 2 ก่อน
