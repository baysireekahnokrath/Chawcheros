**ต่างจาก requirement (ตั้งใจ):**
- W-07 เช็ก Publish **ตอนเปิดหน้าการ์ด/หน้าแรก** (ไม่ถี่กว่า 10 นาที) + ปุ่ม "เช็กตอนนี้" แทน cron รายชั่วโมง · เพราะยังไม่มี service key ให้งานเบื้องหลังเขียนฐานข้อมูล · cron จะมาพร้อม R9
- S-04 บทความบนเว็บเองไม่ติด UTM · ลิงก์ภายในเว็บติด UTM ทำให้ GA4 นับ session ใหม่ ยอดเพี้ยน
- W-02 ช่อง Yoast (meta description · คำค้นหลัก) ต้องเปิดด้วย snippet 1 ชิ้น (`wordpress-yoast.md`) · ยังไม่เปิด = ระบบเตือนให้วางเอง
- W-03 ภาพที่อัปได้: ลิงก์ไฟล์ภาพตรง หรือ Google Drive ที่แชร์ "ทุกคนที่มีลิงก์" · Figma อัปไม่ได้ ระบบเตือนให้ใส่ภาพปกเอง
