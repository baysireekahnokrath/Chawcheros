## ข. Line OA · สิ่งที่ต้องรู้ก่อนตัดสินใจ

| เรื่อง | ความจริง |
|---|---|
| ส่งข้อความจากระบบเราได้ไหม | **ได้** ผ่าน LINE Messaging API · ข้อความ · รูป · การ์ดหลายใบ (carousel) · ปุ่มลิงก์ |
| โพสต์ลง LINE VOOM (ไทม์ไลน์) ได้ไหม | **ไม่ได้** · LINE ไม่เปิด API · ต้องโพสต์เองในแอป |
| ค่าส่ง | นับตามจำนวนข้อความ × จำนวนเพื่อน · แพ็กเกจ OA ไทยมีโควตาฟรีรายเดือนจำกัด · **ส่งทีเดียวถึงเพื่อนทุกคน = กินโควตาเท่าจำนวนเพื่อน** |
| ยอดที่ดึงได้ | จำนวนเพื่อน · คนเปิดอ่าน · คนกดลิงก์ · **เฉพาะข้อความที่ส่งผ่าน API** (ส่งจากแอปเองระบบดึงยอดรายชิ้นไม่ได้) |

> ⚠️ กฎเดิม "AI ร่าง คนเป็นคนส่ง" ยังอยู่ · ถ้าส่งจากระบบ คนต้องกดส่งเองเสมอ AI ไม่ส่ง

## ค. ยอดโพสต์อัตโนมัติ · ดึงอะไรได้จากไหน

| ช่องทาง | ดึงได้ | ต้องมีอะไร |
|---|---|---|
| Facebook Page | เข้าถึง · ปฏิสัมพันธ์ · คลิก · แชร์ ต่อโพสต์ | Meta app ของบริษัท + สิทธิ์ admin เพจ |
| Instagram | เข้าถึง · ไลก์ · คอมเมนต์ · เซฟ · แชร์ ต่อโพสต์ | IG ต้องเป็นบัญชี Business ที่ผูกกับเพจ FB |
| บล็อก SEO | คนเข้าบทความ · คำค้นที่ติด · อันดับ | Google Analytics 4 + Search Console ของเว็บ |
| Line OA | เพื่อน · เปิดอ่าน · กดลิงก์ | Channel access token ของ OA |

ระบบจับคู่ยอดกับชิ้นงานจาก **ลิงก์โพสต์ที่แปะตอนกด "โพสต์แล้ว"** (มีอยู่แล้วตั้งแต่เฟส 1)
