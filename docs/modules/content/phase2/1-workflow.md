## ข. Line OA · สิ่งที่ต้องรู้ก่อนตัดสินใจ

| เรื่อง | ความจริง |
|---|---|
| ส่งข้อความจากระบบเราได้ไหม | **ได้** ผ่าน LINE Messaging API · ข้อความ · รูป · การ์ดหลายใบ (carousel) · ปุ่มลิงก์ |
| โพสต์ลง LINE VOOM (ไทม์ไลน์) ได้ไหม | **ไม่ได้** · LINE ไม่เปิด API · ต้องโพสต์เองในแอป |
| ค่าส่ง | นับตามจำนวนข้อความ × จำนวนเพื่อน · แพ็กเกจ OA ไทยมีโควตาฟรีรายเดือนจำกัด · **ส่งทีเดียวถึงเพื่อนทุกคน = กินโควตาเท่าจำนวนเพื่อน** |
| ยอดที่ดึงได้ | จำนวนเพื่อน · คนเปิดอ่าน · คนกดลิงก์ · **เฉพาะข้อความที่ส่งผ่าน API** (ส่งจากแอปเองระบบดึงยอดรายชิ้นไม่ได้) |

> ⚠️ กฎเดิม "AI ร่าง คนเป็นคนส่ง" ยังอยู่ · ถ้าส่งจากระบบ คนต้องกดส่งเองเสมอ AI ไม่ส่ง

## ฉ. Conversion rate · ต้องตกลงกันว่า "conversion" คืออะไร

เว็บ chawcher.com เป็นแคตตาล็อก ปุ่มหลักคือ **"นัดวันเข้าชม" ทาง Line** (ไม่มีตะกร้า · backlog B2)
ระบบจะนับได้ก็ต่อเมื่อทุกลิงก์ในโพสต์ติด **UTM** (ป้ายบอกว่ามาจากโพสต์ไหน) · agent ใส่ให้เองตอนเขียน

```
โพสต์ FB/IG/Line/บล็อก ──(ลิงก์ติด UTM)──▶ เว็บ chawcher.com ──▶ กด "นัดวันเข้าชม" (Line) ──▶ conversion
        เข้าถึง                              GA4 นับคนเข้า                GA4 นับ key event
```

| # | คำถาม | ตัวเลือก | ผมเสนอ |
|---|---|---|---|
| C1 | conversion คืออะไร | ก. กด "นัดวันเข้าชม" · ข. เพิ่มเพื่อน Line OA · ค. ทักแชท · ง. หลายอย่าง นับแยก | **ง** · ตัวหลัก = ก |
| C2 | conversion rate คิดจากอะไร | ก. conversion ÷ คนเข้าถึงโพสต์ · ข. conversion ÷ คนกดลิงก์ | **ข** แม่นกว่า · โชว์ ก ประกอบ |
| C3 | ใน GA4 ตั้ง key event "นัดวันเข้าชม" ไว้แล้วหรือยัง | ใช่ / ยัง / ไม่แน่ใจ | ถ้ายัง ผมเขียนขั้นตอนให้ |

## ช. ต่อหน้าแอดมินเว็บ (WordPress) · *จาก "link to our website administration page"*

ผมเข้าใจว่าพี่อยากให้ **บล็อก SEO ที่ agent เขียน ส่งเข้า WordPress ได้เลย** ไม่ต้องคัดลอกเอง
หน้าแอดมินเว็บคือ **https://chawcher.com/wp-admin/**

```
agent เขียนบล็อก → Bay ตรวจผ่าน → กด "ส่งเข้า WordPress" → เป็น Draft ใน wp-admin
                                                          → คนเปิดดูหน้าตา กด Publish เอง
                                                          → ลิงก์โพสต์กลับมาที่การ์ดเอง → เริ่มดึงยอด
```

| # | คำถาม | ตัวเลือก | ผมเสนอ |
|---|---|---|---|
| W1 | ส่งเข้า WordPress แบบไหน | ก. **Draft** แล้วคน Publish เองใน wp-admin · ข. Publish เลยตอนกด | **ก** (กฎ: คนเป็นคนส่ง · ได้ดูหน้าตาจริงก่อน) |
| W2 | เว็บใช้ปลั๊กอิน SEO ตัวไหน | Yoast · Rank Math · All in One SEO · ไม่แน่ใจ | ต้องรู้เพื่อใส่ meta title / meta description ให้ตรงช่อง |
| W3 | ภาพปก/ภาพในบทความ | ก. ใช้ key visual ของการ์ดเป็นภาพปก · ข. คนใส่เองใน wp-admin | **ก** |
| W4 | หมวดบทความ (category) | ก. agent เลือกจากหมวดที่มีในเว็บ · ข. หมวดเดียวตายตัว | **ก** |
| W5 | ใครเป็นผู้เขียนบน WordPress | บัญชี WordPress ที่ใช้ส่ง | สร้างผู้ใช้ "Content agent" สิทธิ์ Author (ส่ง Draft ได้ Publish ไม่ได้) |

**สิ่งที่ต้องเตรียม (ผมเขียนขั้นตอนให้ทีละคลิก):**
- P5 · ใน wp-admin สร้างผู้ใช้สิทธิ์ **Author** + **Application Password** → ใส่เป็น env var ใน Vercel (ไม่ส่งในแชท)
- ⚠️ ถ้าเว็บมีปลั๊กอินความปลอดภัยที่ปิด REST API ต้องเปิดให้ผู้ใช้นี้

> ถ้าพี่หมายถึงแค่ **ปุ่มลิงก์ไปหน้า wp-admin** ในระบบ ก็ทำได้ทันที บอกได้เลย
