| L-06 | ปุ่ม **"ส่ง Line"** กดได้เฉพาะคนที่มีสิทธิ์ส่ง · ต้องกดยืนยันอีกครั้ง · AI ส่งเองไม่ได้ | กฎ |

| L-11 | ลิงก์ทุกตัวในข้อความ Line ติด UTM เอง (ดู S-04) | C2 |

## ข. ส่งบล็อกเข้า WordPress *(W1–W5)*

| # | ต้องทำอะไรได้ | ที่มา |
|---|---|---|
| W-01 | การ์ดบล็อกที่ตรวจผ่านแล้ว มีปุ่ม **"ส่งเข้า WordPress"** → สร้างเป็น **Draft** ใน chawcher.com | W1 |
| W-02 | ส่งไปครบ: หัวเรื่อง · เนื้อหา (หัวข้อย่อย · ลิงก์สินค้า) · **Yoast** meta title · meta description · คำค้นหลัก · slug | W2 |
| W-03 | **ภาพปก** = key visual ของการ์ด · ภาพอื่นในการ์ดอัปขึ้น Media ของเว็บ ใส่ alt ให้ | W3 |
| W-04 | **หมวด** agent เลือกจากหมวดที่มีอยู่บนเว็บ (ดึงรายการจากเว็บ) · ไม่สร้างหมวดใหม่เอง · คนเปลี่ยนก่อนส่งได้ | W4 |
| W-05 | ส่งด้วยผู้ใช้ WordPress สิทธิ์ **Author** ชื่อ "Content agent" · Publish ไม่ได้โดยสิทธิ์ (กันพลาดอีกชั้น) | W5 |
| W-06 | ส่งแล้ว การ์ดมีลิงก์ **"เปิดใน wp-admin"** ไปหน้าแก้ Draft นั้นตรงๆ | S6 Bay |
| W-07 | ระบบเช็กทุกชั่วโมงว่า Draft ถูก **Publish** แล้วหรือยัง → ถ้าแล้ว ใส่ลิงก์โพสต์จริงในการ์ด + เปลี่ยนเป็น "โพสต์แล้ว" + เริ่มดึงยอดเอง | W1 |
| W-08 | แก้บทความในระบบหลังส่งแล้ว → กด "ส่งซ้ำ" อัปเดต Draft เดิม (ไม่สร้างซ้ำ) · ถ้า Publish ไปแล้ว ไม่ทับ แจ้งให้แก้ในเว็บ | กันซ้ำ |
| W-09 | เมนูข้าง (ทุกหน้า) มีลิงก์ **"แอดมินเว็บ"** ไป https://chawcher.com/wp-admin/ | S6 Bay |

## ค. ยอดโพสต์อัตโนมัติ *(S1–S6 · C1–C3)*

| # | ต้องทำอะไรได้ | ที่มา |
|---|---|---|
| S-01 | ดึงยอดเองจากลิงก์โพสต์ในการ์ด · **ทุกชั่วโมงใน 48 ชม.แรก** แล้ววันละครั้ง จนครบ **30 วัน** | S1 S2 |
| S-02 | ยอดต่อช่องทาง: **FB** เข้าถึง · ปฏิสัมพันธ์ · คลิก · แชร์ · **IG** เข้าถึง · ไลก์ · คอมเมนต์ · เซฟ · แชร์ · **Line** ส่งถึง · เปิดอ่าน · กดลิงก์ · **บล็อก** คนเข้า · เวลาอ่าน · คำค้นที่ติด · อันดับเฉลี่ย (Search Console) | ค |
| S-03 | **Conversion** = กด "นัดวันเข้าชม" (key event `book_showroom` ใน GA4) | C1 |
| S-04 | agent ใส่ **UTM** ทุกลิงก์ที่ชี้ไปเว็บเอง: `utm_source`=ช่องทาง · `utm_medium`=social/line/blog · `utm_campaign`=แคมเปญ · `utm_content`=รหัสการ์ด · คนแก้ลิงก์เองแล้ว UTM ยังอยู่ | C2 |
| S-05 | **Conversion rate ต่อโพสต์ = conversion ÷ คนกดลิงก์** (ตัวหลัก) · โชว์ conversion ÷ เข้าถึง ประกอบ · คำนวณตอนแสดง ไม่เก็บ | C2 · A10 |
| S-06 | การ์ดแต่ละใบมีแท็บ **"ยอด"**: ตัวเลขล่าสุด · กราฟ 30 วัน · เวลาที่ดึงล่าสุด | S3 |
| S-07 | หน้าแรก: **โพสต์ดีสุดสัปดาห์** (เรียงตาม conversion rate · ต้องมีคนกดลิงก์ ≥ 20 ถึงจะจัดอันดับ กันตัวเลขหลอก) | S4 |
| S-08 | หน้าแรก: **pillar / ช่องทาง / รูปแบบ ไหนได้ผล** เดือนนี้เทียบเดือนก่อน | S4 |
| S-09 | **agent เรียนจากยอด** สัปดาห์ละครั้ง: สรุปว่า hook/pillar/รูปแบบไหนเวิร์ก → เสนอเข้าสมุดความคิดเป็น "รอยืนยัน" · Bay ยืนยันเหมือนเดิม · ใช้งบ AI เดิม | S5 |
| S-10 | ตอน agent ร่างแผนเดือน ใช้สมุดที่ยืนยันแล้วจากยอดด้วย | S5 |
| S-11 | ดึงยอดไม่ได้ (token หมดอายุ · โพสต์ถูกลบ · ลิงก์ผิด) → การ์ดขึ้นป้ายเตือน + หน้าแรกบอกว่าการเชื่อมต่อไหนเสีย | กันเงียบ |
| S-12 | ยอดเก็บเป็นรายการต่อครั้งที่ดึง (append-only) · ไม่เขียนทับ | A7 |
