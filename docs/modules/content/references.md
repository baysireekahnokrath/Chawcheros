# โมดูลคอนเทนต์ · ของเจ้าอื่นที่ไปส่องมา

เขียน 2026-09-23 · **ใช้ประกอบการเขียนด่าน 2 (requirement)**

ไม่ได้จะซื้อ แค่ไปดูว่าเจ้าใหญ่เขาออกแบบวิธีใช้งานไว้ยังไง แล้วเลือกมาบางส่วน
ทุกข้อมีเลขกำกับ `R-xx` พี่ตอบกลับเป็นข้อได้เลย เช่น *"R-01 เอา · R-05 ไม่เอา"*

อ่านตารางแบบนี้

- **เขาทำอะไร** คือวิธีใช้งานของเจ้านั้น
- **ของเราตอนนี้** คือสิ่งที่ระบบเรามีอยู่แล้ว
- **ถ้าเอามา** คือหน้าตาที่ผมคิดว่าจะเป็นในระบบเรา
- **ติดข้อ** คือข้อในไฟล์ `1-workflow.md` ที่เรื่องนี้ไปแตะ
- ⭐ = ผมแนะนำให้เอา · ⛔ = ขัดกับที่พี่ตอบไว้แล้ว
