## ก2. เส้นทางตามประเภท และ agent *(จาก Q1)*

**แนวคิด:** เลือกประเภท + ช่องทาง → ระบบส่งงานต่อให้ agent ที่เกี่ยวข้อง · 1 งานส่งได้หลาย agent พร้อมกัน · เส้นทางตั้งค่าได้ ไม่ต้องแก้โค้ด

**เส้นทางเริ่มต้นเฟส 1** *(ปรับตาม W1-W3)*

```
ตั้งงาน (ประเภท + ช่องทาง + brief)
        │
        ├─► 🤖 Content agent ตัวเดียว ─ เขียนทุกช่องที่ติ๊กในรอบเดียว
        │      FB ข้อความโพสต์ · IG แคปชัน · เว็บ บทความบล็อก SEO
        │      แต่ละช่องคิดตามคู่มือของแพลตฟอร์มนั้น
        │
        └─► 👤 กราฟิกทำภาพ (งานของคนทำ ไม่ใช่ agent) ← เฉพาะภาพเดี่ยว / อัลบั้ม
        │
        ▼  ครบทั้งสองฝั่ง
   รอตรวจ (Bay) ── ไม่มีขั้นคนเกลา (W2)
```

## ก4. ไอเดียด่วน — พิมพ์ประโยคเดียว ที่เหลือ agent ทำ *(Bay ขอเพิ่มหลังดู mockup 2026-09-23)*

> *"ถ้าผมมี idea ใหม่วันนี้ ไม่เกี่ยวกับ campaign หรือ pillar อะไรเลย เช่น อยากเล่นเรื่อง mid century มีภาพโซฟาให้ 1 รุ่น
> ผมต้องใส่ idea เข้าไปที่ไหน แล้วทุกอย่าง automate ออกมาปรากฏที่ตรงนี้เลย"*

```
หน้าปฏิทิน ─ ช่อง "มีไอเดียอะไร พิมพ์เลย" + ลิงก์ภาพ (ถ้ามี)
      │
      ▼  🤖 agent อ่าน
   เข้าใจว่า: หัวข้อ · สินค้า (หาจากแคตตาล็อก) · ช่องทาง · วันลง · pillar (เดา หรือไม่ผูก)
      │
      ├─ ข้อมูลไม่พอ → ถาม Bay 1 ข้อ ตอบด้วยการแตะ (ห้ามเดาสเปก)
      ▼
   เขียนข้อความทุกช่องทาง → การ์ดโผล่ในปฏิทินเอง ป้าย "นอกแผน"
      │  มีภาพแล้ว = ไม่ต้องรอกราฟิก
      ▼
```
