## ก2. เส้นทางตามประเภท และ agent *(จาก Q1)*

**แนวคิด:** เลือกประเภท + ช่องทาง → ระบบส่งงานต่อให้ agent ที่เกี่ยวข้อง · 1 งานส่งได้หลาย agent พร้อมกัน · เส้นทางตั้งค่าได้ ไม่ต้องแก้โค้ด

**เส้นทางเริ่มต้นที่ผมเสนอสำหรับเฟส 1**

```
ภาพเดี่ยว / อัลบั้ม ─┬─► 🤖 agent Facebook   (ถ้าติ๊ก FB)   ─┐
                    ├─► 🤖 agent Instagram  (ถ้าติ๊ก IG)   ─┤
                    ├─► 🤖 agent บล็อก SEO   (ถ้าติ๊กเว็บ)  ─┼─► 👤 คนเกลา ─► รอตรวจ (Bay)
                    └─► 👤 กราฟิก ทำภาพ                      ─┘
ข้อความล้วน ────────┬─► 🤖 agent Facebook                   ─┐
                    └─► 🤖 agent บล็อก SEO                   ─┴─► 👤 คนเกลา ─► รอตรวจ (Bay)
```
