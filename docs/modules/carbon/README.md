# หน่วยคาร์บอน ฌ เฌอ (Chawcher Carbon Unit)

ตัวคำนวณคาร์บอนจากต้นไม้ที่ปลูกให้ลูกค้า + ตัวออกใบรับรองการปลูกต้นไม้ (A4 แนวนอน)

- `carbon-unit.html` — หน้าเครื่องมือ (เปิดในเบราว์เซอร์ได้เลย ไม่ต้องใช้ฐานข้อมูล)
- `certificate-CCU-sample.pdf` — ใบรับรองตัวอย่าง

## วิธีคำนวณ
- อัตราดูดซับต่อต้นต่อปี (กก. CO₂e) ต่อพันธุ์เป็นช่วงต่ำ–สูง · ค่าตั้งต้นโดยประมาณ ต้องแทนด้วยค่าวัดจริงในแปลง
- ปีที่ 1–5 คิดไล่ขึ้น `min(1, y/5)` · คูณจำนวนต้น × อัตรารอด (ค่าเริ่ม 80%)
- ใบรับรองแสดงค่าต่ำของช่วงเสมอ

## ข้อจำกัด (สำคัญ)
ใบนี้ **ไม่ใช่คาร์บอนเครดิต** · คาร์บอนเครดิตที่ซื้อขาย/ชดเชยได้ต้องขึ้นทะเบียนและทวนสอบตาม T-VER ของ อบก.
สอดคล้องกับ R1 ใน `docs/modules/tree-campaign/0-idea.md` (ห้ามเคลม carbon neutral / ชดเชยหมด)

## ขั้นต่อไป (ยังไม่ทำ)
- ทะเบียนใบรับรองในฐานข้อมูล + หน้าตรวจสอบเลขที่ใบรับรอง (QR)
- ผูกเลขต้นไม้กับ `stock.units` ของโซฟา
