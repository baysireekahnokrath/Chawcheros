# จัดโครง Order Tracking ใหม่ · ให้ตรงกับระบบ

**2026-11-01** · Bay บอกว่ากำลังจัด `Chaw Cher Order Tracking` ให้ถูกหลัก data structure
ไฟล์นี้คือข้อแนะนำ **ไม่ใช่การแก้ไฟล์ของ Bay** (B40 · ไฟล์ที่ Bay ส่งให้ ห้ามแก้ อ่านอย่างเดียว)

ถ้าจัดตามนี้ วันหนึ่งจะย้ายเข้าระบบ **ได้แบบนำเข้าทีเดียว** ไม่ต้องคีย์ใหม่ทีละใบ
เพราะหน้าตาจะเหมือนตารางในโมดูลออเดอร์ (`supabase/migrations/0033_sales.sql`) เป๊ะ

## หลัก 4 ข้อ · แก้ปัญหา O1-O4 ที่เจอ

| # | หลัก | แก้ปัญหาไหน |
|---|---|---|
| 1 | **1 แถว = 1 เรื่อง** · ห้ามให้ออเดอร์เดียวกินหลายแถวแบบเว้นว่าง · ห้ามรวมช่อง (merge) | O4 · BLS3167 กิน 3 แถว ข้อมูลกระจาย |
| 2 | **ช่องที่คำนวณได้ ห้ามพิมพ์** · Balance ใช้สูตร = ยอดรวม − ผลรวมที่จ่าย | O3 |
| 3 | **ต้นทุนแยกไฟล์** · คนละสิทธิ์การแชร์ | O2 |
| 4 | **ช่องเดียว เก็บเรื่องเดียว** · ห้ามปน เช่น ช่อง 3 ตอนนี้มีทั้งใบชมพู · PO ลูกค้า · หมายเหตุ | S5 |

## แท็บที่แนะนำ · ตรงกับตารางในระบบ

### แท็บ `ออเดอร์` · 1 แถว = 1 BLS → `sales.orders`

| ช่อง | รูปแบบ | ตัวอย่าง |
|---|---|---|
| BLS | `BLS` + เลข ติดกัน · ไม่มีช่องว่าง/สระนำหน้า (S3) | BLS3230 · BLS3181A |
| วันที่สั่ง | **วันที่จริง** ไม่ใช่ข้อความ | 31/10/2026 |
| รหัสลูกค้า | ชี้ไปแท็บ `ลูกค้า` | C0123 |
| ช่องทาง | เลือกจากรายการ: ขายตรง · NocNoc · ASE · อื่นๆ | ขายตรง |
| เลข PO ฝั่งลูกค้า | เฉพาะเลข | PO8200005767 |
| w/o | `NN/YY` แบบเดียว (S2) · ยังไม่ออก = **เว้นว่าง** ไม่พิมพ์ "รอ" | 83/26 |
| ใบกำกับ/ใบชมพู | เฉพาะเลข | 3201 |
| ต้องผลิตเสร็จ | วันที่จริง | 03/11/2026 |
| กำหนดส่ง | วันที่จริง · "ทันที" = ใส่วันที่ของวันนั้น | 10/11/2026 |
| ค่าขนส่ง | ตัวเลข | 365 |
| สถานะเอกสาร | เลือกจากรายการ: ร่าง · ยืนยันแล้ว · ยกเลิก | ยืนยันแล้ว |
| หมายเหตุ | ข้อความอิสระ · **ที่เดียวที่เขียนอะไรก็ได้** | รอ PO ลูกค้า |

### แท็บ `รายการ` · 1 แถว = 1 สินค้าในออเดอร์ → `sales.order_lines`

| ช่อง | ตัวอย่าง |
|---|---|
| BLS | BLS3230 (ซ้ำได้ทุกแถวของออเดอร์เดียวกัน · **ห้ามเว้นว่าง**) |
| ลำดับ | 1 · 2 · 3 |
| SKU (ถ้ามี) | ว่างได้ |
| รายการ | ฌ เฌอ \| สตูล ขมิ้น (Kamin Stool) · หนังแท้ W70 D50 H44 |
| หมายเหตุ | หนัง SM-Wheat ขาวอลนัท · สินค้าตัวโชว์ |
| จำนวน | 1 |
| ราคาต่อหน่วย (รวม VAT) | 14,775 |

### แท็บ `รับชำระ` · 1 แถว = 1 ครั้งที่ลูกค้าจ่าย → `sales.order_payments`

BLS · วันที่ · ยอด · ช่องทาง (เลือกจากรายการ) · เลขอ้างอิง

### แท็บ `ลูกค้า` · 1 แถว = 1 ลูกค้า → `crm.customers`

รหัสลูกค้า · ชื่อ · โทร · LINE · FB · IG · อีเมล · ที่อยู่ใบกำกับ · ที่อยู่ส่ง
→ ลูกค้าซื้อซ้ำ ไม่ต้องพิมพ์ที่อยู่ใหม่ · แก้ที่เดียวถูกทุกออเดอร์

### ❌ ไม่ต้องมีช่องเหล่านี้

| ช่อง | เพราะ |
|---|---|
| Balance · Total Sales · รายได้ without VAT | คำนวณจากแท็บ `รายการ` และ `รับชำระ` ได้ |
| สถานะผลิต/ส่ง แบบพิมพ์เอง | ระบบคำนวณจากของที่เกิดขึ้นจริง (O1) |
| ต้นทุน · commission | แยกไฟล์ (O2) |
