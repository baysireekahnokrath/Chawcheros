## 3 · ปัญหาที่แท้จริง ไม่ใช่ "ยังไม่มีแอป"

**ความจริงของออเดอร์หนึ่งใบ กระจายอยู่ 5 ที่**

```
กลุ่ม PO ──┐
กลุ่ม เช็คงาน ──┤
กลุ่ม Check progress ──┼──> ไม่มีที่ไหนเป็นต้นฉบับ
Google Sheet ──┤
LINE Official ──┘
```

ทุกการส่งต่อระหว่าง 5 ที่นี้ **เป็นคนก๊อปด้วยมือ** และทุกจุดที่ก๊อปคือจุดที่ข้อมูลหายหรือเพี้ยนได้

ตัวอย่างชัดที่สุดคือขั้นที่ 7: **ลูกค้าถาม → ฝ่ายขาย capture หน้าจอ → แปะในกลุ่ม → รอคนตอบ**
ขั้นนี้ไม่ได้สร้างคุณค่าอะไรเลย มีเพราะไม่มีที่ให้ดูสถานะ

### ใครเห็นอะไร ทำอะไรได้

ตอบคำถามที่ค้างมานานว่า "ใครได้สิทธิ์อะไร" — อย่างน้อยสำหรับ 3 คนนี้

| **พี่ษา** | บันทึกการรับชำระ · เห็นยอดค้าง | ❌ (เห็นราคาขาย ไม่เห็นต้นทุน) |

### 📌 สถานะต้อง "คำนวณ" ไม่ใช่ "พิมพ์"

นี่คือข้อเสนอที่ผมคิดว่าสำคัญที่สุดในเอกสารนี้

ถ้าสถานะเป็นช่องที่คนพิมพ์ **มันจะเพี้ยนจากความจริงวันแรกที่มีคนลืมอัปเดต**
ซึ่งก็คือสิ่งที่เกิดขึ้นอยู่ตอนนี้ (O1 — ไม่มีช่องสถานะ เลยไม่มีใครรู้)

แทนที่จะพิมพ์ ให้ระบบ**อ่านจากสิ่งที่เกิดขึ้นจริง**

| สถานะที่แสดง | คำนวณจาก |
|---|---|
| รอผลิต | ยังไม่มีตัวสินค้าผูกกับออเดอร์นี้ |
| ผลิตเสร็จ รอ QC | มีตัวสินค้าแล้ว แต่ยังไม่มีผล QC |
| **ผ่าน QC แล้ว** | มีผล QC ว่าผ่าน + มีรูป |
| **รอชำระส่วนที่เหลือ** | ยอดรับชำระ < ยอดขาย |
| **ชำระครบ รอนัดส่ง** | ยอดรับชำระ ≥ ยอดขาย แต่ยังไม่มีวันนัด |
| นัดส่งแล้ว | มีวันนัด |
| ส่งแล้ว | มีบันทึกการส่งถึง |

**สถานะแบบนี้โกหกไม่ได้** เพราะไม่มีใครพิมพ์มันได้ · ตรงกับกฎที่พี่ตั้งไว้ว่า
*"ตัวเลขที่คำนวณได้ ห้ามเก็บเป็นช่องที่คนแก้ได้ ต้องคำนวณสดเสมอ"*

> นี่เป็นการตีความกฎของพี่มาใช้กับสถานะ ไม่ใช่กฎที่พี่สั่งไว้ตรงๆ — ถ้าไม่เห็นด้วยบอกได้ครับ

### 8.4 เลข 11 ใบที่ผิด · ผิดตรงไหน

```
ที่ถูก   BLS3175     7 ตัวอักษร
ที่พิมพ์  ิBLS3175    8 ตัวอักษร   ← มีสระอิ ◌ิ เกินมาข้างหน้า
```

ตัวที่เกินคือ **◌ิ (สระอิ) รหัส U+0E34** · เกิดจากแป้นพิมพ์ยังเป็นภาษาไทย
สระอิไม่มีพยัญชนะเกาะ เลยลอยเป็นจุดเล็กๆ **ตาคนมองแทบไม่เห็น แต่คอมพิวเตอร์เห็นเป็นคนละคำ**

| ผลที่เกิด | |
|---|---|
| ค้นหา `BLS3175` | ❌ ไม่เจอใบนี้ |
| เรียงลำดับ | ❌ ไปกองท้ายสุด หลัง BLS3229 ทั้งหมด |
| จับคู่กับใบกำกับ / ใบส่งของ | ❌ ไม่ตรง |
| ย้ายเข้าระบบ | ❌ กลายเป็นออเดอร์คนละใบ |

11 ใบที่เป็นแบบนี้: `3175` `3179` `3180` `3181` `3186` `3189` `3198` `3204` `3208` `3218` `3219`

**แนะนำ:** ตอนย้ายเข้าระบบให้**ตัดสระอิออกอัตโนมัติ** แล้วบันทึกไว้ว่าต้นฉบับเขียนผิด
ไม่ต้องให้คนไล่แก้ทีละใบ และไม่ทิ้งหลักฐานว่าเคยผิด
