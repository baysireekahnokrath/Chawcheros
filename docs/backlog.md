## B1 · ลิงก์เช็กสถานะออเดอร์ให้ลูกค้าดูเอง

**บันทึก 2026-09-23 · ยังไม่สร้าง · อยู่ในโมดูลจัดส่ง/ออเดอร์ ซึ่งยังไม่มี**

### Bay สั่งว่าอะไร

> อยากส่ง link ให้ลูกค้าสามารถดูได้ว่า สถานะสินค้าของลูกค้าอยู่ไหนแล้ว
> โดยเฉพาะ เมื่อต้องส่งต่างจังหวัด ลูกค้าจะได้รู้ว่าสินค้าอยู่ไหนแล้ว
> ถ้ามี delivery tracking ของ 3rd party ก็ไปดึงมาโชว์
> เราแค่ส่ง link order status (Chaw Cher website) ให้ลูกค้าพอ

### สรุปเป็นข้อ

| # | ข้อกำหนด |
|---|---|
| B1.1 | ลูกค้าเปิดลิงก์แล้วเห็นสถานะออเดอร์ตัวเอง **โดยไม่ต้องล็อกอิน** |
| B1.2 | ปัญหาที่แก้คือ **ส่งต่างจังหวัด** ลูกค้าไม่รู้ว่าของไปถึงไหนแล้ว |
| B1.3 | ถ้าขนส่งเจ้าอื่นมี tracking ให้**ดึงมาแสดงในหน้าเดียวกัน** ลูกค้าไม่ต้องไปเปิดหลายเว็บ |
| B1.4 | เราทำแค่ส่งลิงก์ให้ **ไม่ต้องมีระบบแจ้งเตือน ไม่ต้องมีแอป ไม่ต้องให้ลูกค้าสมัคร** |
| B1.5 | หน้านี้อยู่บน **เว็บไซต์ Chaw Cher** ไม่ใช่ในระบบภายใน |

### ⚠️ เรื่องที่ต้องคิดให้ดีตอนทำจริง

**นี่จะเป็นหน้าแรกของทั้งระบบที่คนไม่ได้ล็อกอินเปิดได้**

ทุกอย่างที่สร้างมาจนถึงตอนนี้ คนที่ยังไม่ล็อกอินแตะอะไรไม่ได้เลยสักตาราง
(ตรวจแล้วหลายรอบ · migration 0015 ปิดฟังก์ชันตัวสุดท้ายไปแล้ว)

หน้านี้จะเจาะกำแพงนั้นเป็นครั้งแรก จึงต้อง

- ลิงก์ต้อง **เดาไม่ได้** — ห้ามใช้เลขออเดอร์เรียงกัน ไม่งั้นลูกค้า A เปลี่ยนเลขแล้วเห็นออเดอร์ลูกค้า B
- เปิดให้เห็น **เฉพาะที่ลูกค้าควรเห็น** — ห้ามหลุดต้นทุน กำไร ราคาที่ลูกค้าอื่นได้ เบอร์โทรคนอื่น
- ลิงก์ควร **หมดอายุ** หลังส่งของเสร็จสักพัก

### ❓ คำถามที่ต้องถาม Bay ตอนเริ่มด่าน 1 (ยังไม่ต้องตอบตอนนี้)

| # | คำถาม |
|---|---|
| Q1 | ใช้ขนส่งเจ้าไหนบ้าง (ส่งเองด้วยรถตัวเอง / Kerry / Flash / ขนส่งเฉพาะเฟอร์นิเจอร์?) |
| Q2 | ลูกค้าควรเห็นสถานะอะไรบ้าง — แค่ "กำลังผลิต / ส่งแล้ว / ถึงแล้ว" หรือละเอียดกว่านั้น |
| Q3 | ให้เห็นราคาที่จ่ายไปไหม หรือแค่สถานะพอ |
| Q4 | ส่งลิงก์ทางไหน — Line / SMS / อีเมล |
| Q5 | ของสั่งทำที่ใช้เวลาหลายสัปดาห์ ลูกค้าควรเห็นความคืบหน้าการผลิตด้วยไหม |

### ต้องมีอะไรก่อนถึงทำได้

โมดูลนี้ต้องรอ **ออเดอร์** กับ **จัดส่ง** ซึ่งอยู่ช่วง 7-8 และ 9-10 ในลำดับของ Bay เอง
ทำก่อนไม่ได้ เพราะยังไม่มีออเดอร์ให้ติดตาม

## B2 · ซิงก์สินค้าและราคา จากระบบเรา → เว็บ WooCommerce

**บันทึก 2026-09-23 · ยังไม่สร้าง · ทำได้เลยโดยไม่ต้องรอโมดูลอื่น**

### ที่มา

Bay ถามว่า integrate กับ WooCommerce ได้ไหม · ตรวจเว็บแล้วพบว่า

- chawcher.com เป็น **WordPress + WooCommerce จริง**
- แต่ใช้เป็น**แคตตาล็อก** ไม่มีปุ่มใส่ตะกร้า ปุ่มหลักคือ "นัดวันเข้าชม" ทาง Line
- Bay ยืนยัน: **"ผมแก้เอง อยากแก้จากในระบบ แล้ว link ไป"**

### ปัญหาที่แก้

ตอนนี้ระบบเรารู้ราคาจริงของทุกตัว พร้อมส่วนลดที่คำนวณสด **แต่เว็บไม่รู้**
ตั้งโปร 20% ในโมดูลการตลาด เว็บยังโชว์ราคาเดิมจนกว่า Bay จะไปแก้มือ
ยิ่งมี 751 ตัว ยิ่งไม่มีทางแก้มือให้ทัน

### ข้อกำหนด

| # | ข้อกำหนด |
|---|---|
| B2.1 | แก้ราคาในระบบเราที่เดียว เว็บเปลี่ยนตามเอง |
| B2.2 | ตั้งโปรในโมดูลการตลาด ราคาบนเว็บลดตามเอง และกลับเป็นราคาเดิมเองเมื่อโปรหมด |
| B2.3 | สินค้าที่เพิ่งอนุมัติในหน้าตรวจ ขึ้นเว็บเองได้ |
| B2.4 | สินค้าที่เปลี่ยนสถานะเป็นเลิกขาย หายจากเว็บเอง |
| B2.5 | **ทางเดียว** ระบบเรา → เว็บ · ห้ามแก้ราคาในหน้า WordPress เด็ดขาด |

### ★ กฎที่ห้ามพัง

**ระบบเราเป็นเจ้าของความจริง · Woo เป็นแค่หน้าร้าน**

ถ้าปล่อยให้แก้ได้สองที่ วันหนึ่งจะมีราคาสองชุดแล้วไม่มีใครรู้ว่าอันไหนถูก
ซึ่งเป็นปัญหาเดียวกับที่ระบบนี้ตั้งใจแก้ตั้งแต่แรก

### ทำอย่างไร

WooCommerce มี REST API มาตรฐาน (`/wp-json/wc/v3/products`) เขียนขึ้นไปได้ตรงๆ
ไม่ต้องลงปลั๊กอินเพิ่ม ต้องการแค่ API key จากหน้า WooCommerce settings

### ❓ ต้องถามตอนเริ่มด่าน 1

| # | คำถาม |
|---|---|
| Q1 | สินค้าบนเว็บตอนนี้กับใน 751 ตัวของเรา จับคู่กันยังไง (ใช้ SKU? ชื่อ?) |
| Q2 | เอาขึ้นเว็บทุกตัว หรือเลือกเฉพาะบางตัว |
| Q3 | รูปสินค้าอยู่ที่ไหน — ในเว็บอยู่แล้ว หรือต้องอัปใหม่ |
| Q4 | ราคาบนเว็บโชว์ราคาเต็มหรือราคาหลังลด |

## B3 · เปิดขายออนไลน์จริงผ่านเว็บ

**บันทึก 2026-09-23 · ยังไม่สร้าง · ต้องรอโมดูลออเดอร์ก่อน**

### ที่มา

Bay: **"เอาจริงก็อยากให้ขายออนไลน์ได้เลย"**

### โครงที่เสนอ

```
ออเดอร์เกิดได้ 2 ทาง แต่ไปรวมที่เดียว

   โชว์รูม ──────┐
                 ├──► ออเดอร์ในระบบเรา ──► คลัง · ผลิต · จัดส่ง
   เว็บ (Woo) ───┘         (เจ้าของความจริง)
```

- **สินค้า/ราคา** ไหลออก: ระบบเรา → Woo (คือ B2)
- **ออเดอร์** ไหลเข้า: Woo → ระบบเรา
- สองทิศทางไม่ทับกัน จึงไม่ตีกัน

### ⚠️ เรื่องยากที่ต้องแก้ก่อนเปิดขายจริง — ไม่ใช่แค่เปิดปุ่มตะกร้า

| # | เรื่อง | ทำไมถึงยาก |
|---|---|---|
| H1 | **ค่าส่งต่างจังหวัด** | โซฟาตัวใหญ่ ค่าส่งต่างกันมากตามปลายทางและจำนวนคนยก · ตะกร้าต้องคิดค่าส่งให้ถูกก่อนลูกค้าจ่าย |
| H2 | **ลูกค้าเลือกสีผ้า** | เราออกแบบไว้ว่า "เกรดผ้า" เป็นตัวสินค้า แต่ "สี" เลือกตอนสั่ง · ตะกร้าต้องมีที่ให้เลือกสี ไม่งั้นได้ออเดอร์ที่ไม่รู้ว่าลูกค้าเอาสีอะไร |
| H3 | **สต็อกนับเป็นตัว** | ขายออนไลน์ต้องจองตัวจริงทันทีที่จ่ายเงิน ไม่งั้นขายซ้ำตัวเดียวกันสองคน |
| H4 | **ของสั่งทำ** | ไม่มีของในสต็อก ต้องบอกลูกค้าว่ารออีกกี่สัปดาห์ · ตะกร้าต้องแยกของพร้อมส่งกับของสั่งทำ |
| H5 | **รับเงิน** | ต้องมี payment gateway · มัดจำหรือเต็มจำนวน · ใบกำกับภาษี |

### ลำดับที่แนะนำ

1. **B2 ก่อน** — ซิงก์สินค้า/ราคา ทำได้เลย ไม่ต้องรออะไร แก้ปัญหาที่ Bay เจออยู่ทุกวัน
2. **โมดูลออเดอร์** — รองรับออเดอร์จากโชว์รูมก่อน (ช่วง 7-8 ตามแผนของ Bay เอง)
3. **B3** — พอมีออเดอร์กับจัดส่งแล้ว ค่อยเปิดช่องทางเว็บ

เหตุผล: ออเดอร์จากโชว์รูมคือรายได้หลักตอนนี้ และการทำออเดอร์ให้ดีก่อน
จะทำให้ออเดอร์จากเว็บไหลเข้าท่อเดิมได้เลย ไม่ต้องสร้างสองท่อ

## B4 · เทียบราคาฟองน้ำกับตลาด แล้วเตือน

**บันทึก 2026-10-20 · ยังไม่สร้าง**

และแก้ข้อมูลให้ว่า **QUICKDRY เป็น spec สำหรับงาน outdoor** (จึงแพงกว่าตัวอื่นโดยธรรมชาติ)

### ⚠️ ความจริงที่ต้องบอกก่อน · ฟองน้ำไม่มีราคาตลาดสาธารณะ

ต่างจากเหล็กหรือน้ำมันที่มีดัชนีราคาเปิด **ฟองน้ำอุตสาหกรรมเป็นของที่ต้องขอใบเสนอราคา**

| แหล่ง | ใช้ได้จริงไหม |
|---|---|
| เว็บซัพพลายเออร์ไทย | ❌ ไม่ประกาศราคา ต้องโทรขอ |
| Alibaba / Made-in-China | ⚠️ มีราคา แต่เป็น FOB ส่งออกยกคอนเทนเนอร์ · เทียบกับซื้อแผ่นในไทยไม่ได้ จะหลงทาง |
| ดัชนีราคา TDI / Polyol | ✅ มีจริง แต่ตัวดีเป็นระบบเสียเงิน (ICIS, Tecnon OrbiChem) |
| ราคา spot TDI จีน | ⚠️ กึ่งเปิด (Sunsirs ฯลฯ) ดึงได้แต่เปราะ เว็บเปลี่ยนเมื่อไหร่พัง |

**ยิ่งฟองน้ำกันไฟยิ่งหายาก** เพราะเป็นของเฉพาะทางกว่า ซัพพลายเออร์น้อยราย ไม่มีใครประกาศราคาเลย

> **สรุป: "ดึงราคาตลาดมาเทียบอัตโนมัติ" แบบที่หวังไว้ ทำไม่ได้จริงสำหรับวัสดุนี้**
> ถ้าผมรับปากแล้วไปสร้าง จะได้ตัวเลขที่ดูน่าเชื่อแต่เทียบไม่ได้ ซึ่งอันตรายกว่าไม่มี

### ✅ แต่มี 3 ชั้นที่ทำได้จริง · เรียงตามความแน่นอน

#### ชั้น 1 · ข้อมูลตัวเองเทียบกันเอง — ทำได้เลย ไม่ต้องพึ่งใคร

**ของที่มีอยู่แล้วและยังไม่ได้ใช้: ช่อง "แทน"**

ตารางบอกเองว่าตัวไหนแทนตัวไหนได้ — `HR36 แทน CHXA` · `FFC แทน CHFF` · `SQ แทน CH4S` · `HR3 แทน CH3/LK7`
**นั่นคือตารางเทียบข้ามซัพพลายเออร์ที่ทำไว้แล้ว** แค่ยังไม่มีใครเอามาคิดเป็นตัวเลข

ลองคำนวณ **ดัชนีคุ้มค่า** = ราคา ÷ พื้นที่ ÷ ความแน่น (100 = คุ้มสุดในกลุ่มไม่กันไฟ)

| รหัส | ซัพพลายเออร์ | แน่น | ราคา/นิ้ว | บ./ตร.ซม. | ดัชนี |
|---|---|---|---|---|---|
| **HR3** | กรุงเทพโฟม | 26 | 220 | 0.0550 | **100** ← คุ้มสุด |
| HR36 | กรุงเทพโฟม | 33 | 310 | 0.0775 | 111 |
| CHXA | อีสเทอร์นโฟม | 32 | 312.90 | 0.0782 | 116 |
| FFC | อีสเทอร์นโฟม | 26 | 255.15 | 0.0638 | 116 |
| SQ | กรุงเทพโฟม | 20 | 220 | 0.0550 | 130 |
| **BZ5** | อีสเทอร์นโฟม | 35 | 462 | 0.0963 | **130** ← แพง |
| AM7 | กรุงเทพโฟม | 10 | 116 | 0.0290 | 137 |
| ER51 W1 | เฉียวฟู | 40 | 492 | 0.1230 | 145 |
| 🔥 **LGX** | ดูราโฟม | 37 | 385 | 0.0963 | **123** ← กันไฟที่คุ้มสุด |
| 🔥 DGU | ดูราโฟม | 28 | 368 | 0.0920 | 155 |
| 🔥 DM2 | ดูราโฟม | 26 | 350 | 0.0875 | 159 |

**สิ่งที่เห็นทันทีโดยไม่ต้องมีข้อมูลตลาดเลย**

| # | เจออะไร |
|---|---|
| V1 | **HR36 (กรุงเทพโฟม) คุ้มกว่า CHXA (อีสเทอร์นโฟม)** ทั้งที่ตารางบอกว่าแทนกันได้ · ความแน่นใกล้กัน (33 vs 32) แต่ HR36 ถูกกว่าต่อพื้นที่ |
| V2 | **BZ5 แพงผิดกลุ่ม** · ความแน่น 35 ใกล้ HR36 ที่ 33 แต่แพงกว่าต่อพื้นที่ **24%** — ซื้อไปทำไม มีเหตุผลทางเทคนิคหรือแค่เคยสั่งมา |
| V3 | **LGX เป็นกันไฟที่คุ้มสุด** และแน่นที่สุดด้วย (37) · DM2 แน่นน้อยสุด (26) แต่ดัชนีแย่สุด |
| V4 | 🔥 กันไฟแพงกว่าไม่กันไฟ **23-59%** — เป็นตัวเลขที่ควรรู้ตอนตั้งราคาสินค้า outdoor/โรงแรม |

#### ชั้น 2 · เก็บใบเสนอราคาทุกใบ — สร้างราคาตลาดของตัวเอง

ไม่มีใครประกาศราคา **แต่ทุกครั้งที่จัดซื้อขอใบเสนอราคา นั่นคือราคาตลาดจริง**

ถ้าบันทึกทุกใบเสนอราคาเข้าระบบ (ไม่ใช่แค่ใบที่สั่งจริง) ภายใน 6-12 เดือนจะมี
ฐานข้อมูลราคาตลาดที่**แม่นกว่าดัชนีสาธารณะใดๆ** เพราะเป็นราคาที่เสนอให้เราจริง
ในปริมาณจริง เงื่อนไขจริง

เตือนได้ว่า
- ซัพพลายเออร์ขึ้นราคาเมื่อไหร่ ขึ้นกี่ %
- เจ้าไหนเสนอถูกกว่าสำหรับเกรดที่แทนกันได้
- ราคาเจ้าไหนนิ่งผิดปกติในขณะที่เจ้าอื่นขยับ (= อาจขอต่อรองได้)

#### ชั้น 3 · ดัชนีวัตถุดิบตั้งต้น — เป็นสัญญาณเตือนล่วงหน้า ไม่ใช่ราคาเทียบ

ฟองน้ำ PU ทำจาก **TDI + Polyol** ซึ่งเป็นเคมีภัณฑ์ที่มีดัชนีราคา
ถ้า TDI ลง 15% แล้วซัพพลายเออร์ไม่ลดราคาให้ **นั่นคือไพ่ในมือตอนเจรจา**

> ⚠️ แต่ดึงอัตโนมัติได้ไม่แน่นอน · แหล่งดีเสียเงิน แหล่งฟรีเปราะ
> **ไม่ควรให้ระบบพึ่งพา** ใช้เป็นข้อมูลเสริมที่คนไปดูเองเป็นรายไตรมาสพอ
