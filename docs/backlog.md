## B1 · ลิงก์เช็กสถานะออเดอร์ให้ลูกค้าดูเอง

**บันทึก 2026-09-23 · ยังไม่สร้าง · อยู่ในโมดูลจัดส่ง/ออเดอร์ ซึ่งยังไม่มี**

### Bay สั่งว่าอะไร

> อยากส่ง link ให้ลูกค้าสามารถดูได้ว่า สถานะสินค้าของลูกค้าอยู่ไหนแล้ว
> โดยเฉพาะ เมื่อต้องส่งต่างจังหวัด ลูกค้าจะได้รู้ว่าสินค้าอยู่ไหนแล้ว
> ถ้ามี delivery tracking ของ 3rd party ก็ไปดึงมาโชว์
> เราแค่ส่ง link order status (Chaw Cher website) ให้ลูกค้าพอ

### สรุปเป็นข้อ

| # | ข้อกำหนด |
|---|---|
| B1.1 | ลูกค้าเปิดลิงก์แล้วเห็นสถานะออเดอร์ตัวเอง **โดยไม่ต้องล็อกอิน** |
| B1.2 | ปัญหาที่แก้คือ **ส่งต่างจังหวัด** ลูกค้าไม่รู้ว่าของไปถึงไหนแล้ว |
| B1.3 | ถ้าขนส่งเจ้าอื่นมี tracking ให้**ดึงมาแสดงในหน้าเดียวกัน** ลูกค้าไม่ต้องไปเปิดหลายเว็บ |
| B1.4 | เราทำแค่ส่งลิงก์ให้ **ไม่ต้องมีระบบแจ้งเตือน ไม่ต้องมีแอป ไม่ต้องให้ลูกค้าสมัคร** |
| B1.5 | หน้านี้อยู่บน **เว็บไซต์ Chaw Cher** ไม่ใช่ในระบบภายใน |

### ⚠️ เรื่องที่ต้องคิดให้ดีตอนทำจริง

**นี่จะเป็นหน้าแรกของทั้งระบบที่คนไม่ได้ล็อกอินเปิดได้**

ทุกอย่างที่สร้างมาจนถึงตอนนี้ คนที่ยังไม่ล็อกอินแตะอะไรไม่ได้เลยสักตาราง
(ตรวจแล้วหลายรอบ · migration 0015 ปิดฟังก์ชันตัวสุดท้ายไปแล้ว)

หน้านี้จะเจาะกำแพงนั้นเป็นครั้งแรก จึงต้อง

- ลิงก์ต้อง **เดาไม่ได้** — ห้ามใช้เลขออเดอร์เรียงกัน ไม่งั้นลูกค้า A เปลี่ยนเลขแล้วเห็นออเดอร์ลูกค้า B
- เปิดให้เห็น **เฉพาะที่ลูกค้าควรเห็น** — ห้ามหลุดต้นทุน กำไร ราคาที่ลูกค้าอื่นได้ เบอร์โทรคนอื่น
- ลิงก์ควร **หมดอายุ** หลังส่งของเสร็จสักพัก

### ❓ คำถามที่ต้องถาม Bay ตอนเริ่มด่าน 1 (ยังไม่ต้องตอบตอนนี้)

| # | คำถาม |
|---|---|
| Q1 | ใช้ขนส่งเจ้าไหนบ้าง (ส่งเองด้วยรถตัวเอง / Kerry / Flash / ขนส่งเฉพาะเฟอร์นิเจอร์?) |
| Q2 | ลูกค้าควรเห็นสถานะอะไรบ้าง — แค่ "กำลังผลิต / ส่งแล้ว / ถึงแล้ว" หรือละเอียดกว่านั้น |
| Q3 | ให้เห็นราคาที่จ่ายไปไหม หรือแค่สถานะพอ |
| Q4 | ส่งลิงก์ทางไหน — Line / SMS / อีเมล |
| Q5 | ของสั่งทำที่ใช้เวลาหลายสัปดาห์ ลูกค้าควรเห็นความคืบหน้าการผลิตด้วยไหม |

### ต้องมีอะไรก่อนถึงทำได้

โมดูลนี้ต้องรอ **ออเดอร์** กับ **จัดส่ง** ซึ่งอยู่ช่วง 7-8 และ 9-10 ในลำดับของ Bay เอง
ทำก่อนไม่ได้ เพราะยังไม่มีออเดอร์ให้ติดตาม
