## ชิ้นส่วน (Kit)

`PageHeader` · `Button` (หลัก / รอง / อันตราย) · `Field` (ช่องกรอก + ป้ายชื่อ + ข้อความผิด) · `Card` ·
`ListRow` (แถวในรายการ) · `StatTile` (ตัวเลขสรุป) · `Badge` (สถานะ) · `EmptyState` (ยังไม่มีข้อมูล + ปุ่มเริ่ม) · `BottomBar` (ปุ่มยืนยันติดล่างจอ)

อยู่ที่ `web/src/components/ui/` ที่เดียว

## หน้า 5 แบบ

| แบบ | ใช้กับ | หน้าตา |
|---|---|---|
| **A · หน้าแรก** | `/` | ปุ่มใช้ทุกวัน 4 ปุ่มบนสุด → แอปแยกเป็นหมวด (ขาย · สินค้า · คลัง · การตลาด · หลังบ้าน) |
| **B · รายการ** | ลูกค้า ออเดอร์ สินค้า คลัง | ช่องค้นหา → ตัวกรองเป็นปุ่มกลม → แถวรายการ → ปุ่ม "+ เพิ่ม" มุมล่าง |
| **C · รายละเอียด** | ลูกค้า/ออเดอร์รายตัว | หัว (ชื่อ + ป้ายสถานะ) → การ์ดข้อมูลทีละกลุ่ม → ปุ่มทำงานติดล่าง |
| **D · ฟอร์ม** | เพิ่มลูกค้า ใบเสนอราคา ออเดอร์ใหม่ | ช่องกรอกเรียงลงทีละช่อง → ปุ่มบันทึกติดล่างจอ |
| **E · รายงาน** | ยอดขาย ใบราคา Data Sheet | เลือกช่วงวัน → ตัวเลขสรุป 3-4 ช่อง → ตาราง/รายการละเอียด |

`/pos` กับ `/phoenix` (หน้าใช้ PIN) ใช้ชุดสีและชิ้นส่วนเดียวกัน แค่ไม่มีแถบบนของระบบ
