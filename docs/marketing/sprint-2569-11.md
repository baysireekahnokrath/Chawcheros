### ข้อความ LINE (คัดลอกแล้วแก้ในวงเล็บเหลี่ยม)

```
สวัสดีครับคุณ[ชื่อลูกค้า] [ชื่อผู้ส่ง] จาก ฌ เฌอ ครับ
ขออนุญาตรบกวนสักเรื่องครับ

ทางเราอยากขอ[ไปถ่ายภาพโซฟาที่บ้านคุณ / ใช้ภาพโซฟาที่บ้านคุณที่เคยถ่ายไว้] เพื่อลงในเพจ เว็บไซต์ และโฆษณาของ ฌ เฌอ ครับ

สิ่งที่จะใช้มีเท่านี้ครับ
1. ภาพโซฟาและมุมห้องที่วางโซฟา (ไม่ถ่ายเลขห้อง บ้านเลขที่ หรือของส่วนตัว)
2. ชื่อต้นหรืออักษรย่อ ตามที่คุณ[ชื่อลูกค้า]สะดวก
3. ชื่อย่านหรือเขต เช่น "คอนโดย่าน[ย่าน]" ไม่ระบุชื่อโครงการ

ภาพทุกภาพจะส่งให้ดูก่อนลงครับ และถ้าวันไหนอยากให้เอาออก แจ้งได้ทุกเมื่อ เราจะหยุดใช้และลบออกจากช่องทางของเราให้ครับ

ไม่สะดวกก็ไม่เป็นไรเลยนะครับ ขอบคุณมากครับ
```

## 4 · ซ่อมตัววัดผล

> ⚠️ **ขั้นตอนข้างล่างเขียนจากเอกสารของ Google ยังไม่ได้ทดสอบบนบัญชีจริงของ ฌ เฌอ** · ชื่อเมนูอาจต่างจากที่เห็นบนจอเล็กน้อย (Google เปลี่ยนหน้าตาบ่อย และภาษาเมนูขึ้นกับที่ตั้งไว้) · ติดขั้นไหนให้ถ่ายหน้าจอส่งมา

**สภาพตอนนี้:** เว็บ chawcher.com ติด GA4 (ผ่าน Site Kit) · GTM · Google Ads tag · Meta Pixel แล้ว · ปุ่ม "นัดวันเข้าชม" ลิงก์ไป LINE (`lin.ee`) แต่ event `showroom_appointment_click` ยิงแค่บางหน้า (หน้าแรกไม่ยิง)

**สิ่งที่จะได้:** event 1 ตัว
- `book_showroom` — กดลิงก์ไป LINE จากหน้าไหนก็ได้ รวมหน้า "นัดลองนั่งที่โชว์รูม"

(event สำหรับหน้าขอชุดผ้าถูกตัดออกตาม O1 · ไม่ต้องสร้าง)

event นี้วัด **"การกดปุ่ม"** ไม่ใช่จำนวนคนที่ทักเข้ามาจริง และไม่ใช่จำนวนคนที่มาถึงโชว์รูม · ตัวเลขนัดและคนมาจริงยังต้องนับจาก LINE OA และหน้าร้าน

### ก · GTM (สร้าง 1 trigger + 1 tag)

1. เปิด [Google Tag Manager](https://tagmanager.google.com/) → เลือก container ของ chawcher.com
2. เมนูซ้าย **Variables** → กล่อง Built-In Variables กด **Configure** → ติ๊ก **Click URL** → ปิดแผง
3. เมนูซ้าย **Triggers** → **New** → ตั้งชื่อตามกล่องข้างล่าง

```
Click - LINE - ทุกหน้า
```

4. กดกล่อง Trigger Configuration → เลือก **Click - Just Links** → เลือก **Some Link Clicks** → ตั้ง 1 เงื่อนไข → **Save**
   - `Click URL` · `contains` · `lin.ee`
5. เมนูซ้าย **Tags** → **New** → ตั้งชื่อ `GA4 - book_showroom` → กดกล่อง Tag Configuration → **Google Analytics** → **Google Analytics: GA4 Event**
6. ช่อง **Measurement ID** ใส่รหัส `G-…` ของ GA4 (ดูได้ใน GA4 → Admin → Data streams → กดชื่อ stream ของเว็บ) · ช่อง **Event Name** ใส่ตามกล่องข้างล่าง

```
book_showroom
```

7. กดกล่อง Triggering → เลือก `Click - LINE - ทุกหน้า` → **Save**
8. มุมขวาบนกด **Preview** → ใส่ `https://chawcher.com` → **Connect** → ในหน้าเว็บที่เปิดขึ้น กดปุ่ม "นัดวันเข้าชม" **ที่หน้าแรก**
9. กลับมาแท็บ Tag Assistant → ต้องเห็น `GA4 - book_showroom` อยู่ใต้ **Tags Fired** · ไม่เห็น = หยุดตรงนี้ ถ่ายหน้าจอส่งมา (ยังไม่ต้อง Publish)
10. ผ่านแล้วกด **Submit** มุมขวาบน → ใส่ชื่อเวอร์ชัน `book_showroom` → **Publish**

หมายเหตุ:
- เงื่อนไข `lin.ee` จับ**ทุกลิงก์ไป LINE** บนเว็บ ไม่ใช่เฉพาะปุ่ม "นัดวันเข้าชม" · ถ้าเว็บมีปุ่ม LINE อื่น (เช่น ปุ่มเพิ่มเพื่อนท้ายหน้า) จะถูกนับรวมใน `book_showroom` ด้วย
- หน้า "นัดลองนั่งที่โชว์รูม" ทดสอบได้หลังเผยแพร่แล้วเท่านั้น · เผยแพร่แล้วให้ทำขั้น 8–9 ซ้ำกับหน้านั้น
- **ไม่ต้องลบ** `showroom_appointment_click` ตัวเดิม ปล่อยไว้ก่อน แต่ตั้งเป็น key event แค่ `book_showroom` ตัวเดียว จะได้ไม่นับซ้ำ

### ข · GA4 (ตั้งเป็น key event)

11. เปิด [Google Analytics](https://analytics.google.com/) → เลือก property ของ chawcher.com → มุมซ้ายล่างกด **Admin** (รูปเฟือง)
12. ใต้หัวข้อ **Data display** กด **Key events** → **New key event** → พิมพ์ชื่อตามกล่องในขั้น 6 (`book_showroom`) → **Save**
13. เช็กว่ามาจริง: เมนูซ้าย **Reports** → **Realtime** → กดปุ่มบนเว็บอีกครั้ง → ภายในไม่กี่นาทีต้องเห็นชื่อ event ในการ์ด Event count · รายงานปกติจะขึ้นช้ากว่า (อาจถึง 24 ชั่วโมง)

### ค · Google Ads (นำเข้าเป็น conversion)

14. เช็กว่า GA4 ผูกกับ Google Ads แล้ว: ใน GA4 → **Admin** → ใต้ **Product links** กด **Google Ads links** → ต้องเห็นบัญชี Ads ของ ฌ เฌอ · ไม่เห็นให้กด **Link** แล้วเลือกบัญชี
15. เปิด [Google Ads](https://ads.google.com/) → เมนูซ้าย **Goals** → **Conversions** → **Summary** → **New conversion action** (หรือ **Create conversion action**)
16. เลือก **Import** → **Google Analytics 4 properties** → **Web** → **Continue**
17. ติ๊ก `book_showroom` → **Import and continue** → **Done**
   - ยังไม่เห็นชื่อ event ในรายการ = GA4 ยังไม่ส่งมา ให้รอ 1 วันแล้วทำขั้น 15–17 ใหม่
18. อีก 1–2 วันกลับมาดูหน้า **Conversions** → **Summary** → สถานะไม่ควรเป็น Inactive หลังมีคนกดปุ่มจริง

**ยังไม่ได้ทำใน sprint นี้:** event ฝั่ง Meta Pixel สำหรับปุ่มเดียวกัน (ทำต่อเมื่อ GTM ชุดนี้ทดสอบผ่าน)
