# ข้อเสนอวิธีออก SKU — รอ Bay คอนเฟิร์ม (OPEN-1)

พี่บอกว่า *"ควรจะเป็น template ที่มีการคิดมาแล้วว่าออกมาจากอะไรบ้าง หาวิธีมาแล้วคอนเฟิร์มกับผมก่อน"*
นี่คือวิธีที่ผมเสนอ

---

## ก่อนอื่น: เคลียร์เรื่อง "8 หลัก" กับ "xxx.xxx.xxx แบบ IKEA"

พี่ล็อกไว้ว่า **8 หลัก** แต่เขียนว่าอยากได้ `xxx.xxx.xxx` แบบ IKEA ซึ่งนับได้ 9 ตัว

**ไม่ได้ขัดกันครับ — พี่จำถูกแล้ว แค่จุดวางผิดตำแหน่ง**
เลขสินค้า IKEA จริงๆ คือ **8 หลัก** แสดงผลเป็น `XXX.XXX.XX`

```
IKEA จริง:   703.622.25   ←  8 ตัวเลข   (3 + 3 + 2)
ที่พี่เขียน:  xxx.xxx.xxx  ←  9 ตัวเลข
```

**ข้อเสนอ: 8 หลักตามที่ล็อกไว้ แสดงเป็น `XXX.XXX.XX`** — ตรงทั้งกฎเดิมและความตั้งใจของพี่

## วิธีออกเลข

```
       4  8  2  9  1  7  3     5
       └──────┬──────┘        └┬┘
        7 หลักสุ่ม          เลขตรวจสอบ
                              (ระบบคิดเอง)

       เก็บในฐานข้อมูล:  48291735
       แสดงบนจอ/ป้าย:    482.917.35
```

### 1. 7 หลักแรก = สุ่ม ไม่มีความหมายใดๆ

ตรงตามกฎที่ล็อกไว้: *"ไม่มีความหมายในตัวเอง ความหมายอยู่ในคอลัมน์"*

**ทำไมสุ่ม ไม่ใช่เรียง 1, 2, 3:**
- เลขเรียงบอกความลับโดยไม่ตั้งใจ — คู่แข่งเห็น `00001042` ก็รู้ว่าเรามีสินค้าพันกว่าตัว
- เลขเรียงชวนให้คนเดาความหมาย เดี๋ยวก็จะมีคนพูดว่า "เลข 3 ขึ้นต้นคือโซฟาใช่ไหม" แล้วมันจะไม่จริง
- **เริ่มที่ 1 ไม่เอา 0 นำหน้า** — เพราะพอ export ลง Google Sheets เลข 0 ข้างหน้าจะหายทันที

พื้นที่ทั้งหมด **9 ล้านเลข** ใช้จริงหลักพัน — ไม่มีวันหมด

### 2. หลักที่ 8 = เลขตรวจสอบ (แนะนำ แต่ไม่บังคับ)

เลขตัวสุดท้ายระบบคำนวณจาก 7 ตัวแรก ทำให้**พิมพ์ผิดแล้วระบบรู้ทันที**

```
พิมพ์  48291735  →  ✅ ถูก
พิมพ์  48291732  →  ❌ ระบบเตือนทันที "เลขนี้ไม่มีอยู่จริง"
พิมพ์  48219735  →  ❌ สลับเลข ระบบก็จับได้
```

**ทำไมถึงคุ้ม:** คนที่พิมพ์ SKU บ่อยที่สุดคือคลัง ยืนอยู่หน้ากองของ ถือมือถือ
พิมพ์ผิดตัวเดียวแล้วไม่มีใครรู้ = ตัดสต็อกผิดตัว ซึ่งกว่าจะเจอก็อีกหลายเดือน

ถ้าพี่ไม่เอา ก็ใช้สุ่ม 8 หลักเต็มได้ครับ **แต่ผมแนะนำให้เอา** — ได้มาฟรี ไม่มีข้อเสีย

---

## กฎที่ห้ามผิดเด็ดขาด

| กฎ | ทำไม |
|---|---|
| **ระบบออกให้เท่านั้น ห้ามคนพิมพ์เอง** | คนจะเผลอใส่ความหมาย แล้วกฎ "ไม่มีความหมาย" จะพังภายในเดือนเดียว |
| **ออกแล้วออกเลย ห้ามใช้ซ้ำ** | แม้สินค้าเลิกขายไป 10 ปี ออเดอร์เก่ายังต้องอ่านออก ถ้าเอาเลขไปใช้ใหม่ ประวัติจะชี้ผิดตัว |
| **ห้ามเปลี่ยนตลอดชีวิตสินค้า** | เปลี่ยนสี เปลี่ยนชื่อ ขึ้นราคา — SKU เดิมเสมอ |
| **เก็บเป็นข้อความ ไม่ใช่ตัวเลข** | ถ้าเก็บเป็นตัวเลข Excel/Sheets จะกินเลข 0 นำหน้าและทำเป็น `4.83E+07` |
| **จุดเป็นแค่การแสดงผล** | ในฐานข้อมูลคือ `48291735` ล้วนๆ ค้นหาได้ทั้งมีจุดและไม่มีจุด |

## ⚠️ ก่อนออก SKU ตัวแรก ต้องปิดคำถามนี้ก่อน (OPEN-2)

**ตารางข้างบนนี้ผมใช้สมมติฐานว่า SKU อยู่ที่ `รุ่น + ขนาด + เกรดวัสดุ`**
สีผ้าที่ลูกค้าเลือกไปบันทึกที่ออเดอร์และที่ตัวสินค้าจริง ไม่ได้แยก SKU

เพราะถ้าแยก SKU ทุกสีผ้า:

| | SKU ทั้งหมด | งานที่ต้องทำ |
|---|---|---|
| **แบบที่ผมเสนอ** (รุ่น+ขนาด+เกรด) | Emu Sofa = **12** | ไหว |
| แบบแยกทุกสีผ้า | Emu Sofa = **135** | คูณ 50 รุ่น = **6,000+ SKU** |

เหตุผลที่ผมเสนอแบบแรก:
1. **ราคาเท่ากันทั้งเกรดอยู่แล้ว** ผ้าเกรด A สีเขียวกับสีน้ำเงินราคาเดียวกัน
2. **ของจริงบันทึกผ้าจริงอยู่แล้ว** ที่ตาราง `stock_units`
3. **มีผ้าสีใหม่เข้ามา = เพิ่ม 1 แถวในตารางวัสดุ** ไม่ต้องสร้าง SKU ใหม่อีก 50 ตัว

**แต่นี่เป็นเรื่องโครงสร้างธุรกิจ ผมไม่ตัดสินใจเอง — รอพี่ยืนยันครับ**
