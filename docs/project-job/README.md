## 2 · ผลจำลอง (ฐานข้อมูลในเครื่อง · ไม่ได้แตะของจริง)

| รอบ | ทำอะไร | ผล |
|---|---|---|
| A | ใส่ MF-06A เป็นงานสั่งทำ ไม่ใส่ราคา | ระบบปฏิเสธ "ต้องใส่ราคามาเอง" |
| B | พิมพ์ราคาเอง | ออกใบได้ แต่ต้นทุน กำไร พื้นส่วนลด ว่างหมด · ธง `ยังไม่มีสูตรวัสดุ` |
| C | ลงทะเบียน + สูตร 5 บรรทัด + ราคาวัสดุ + กำไร 30% | **ได้ราคา** · ต้นทุน → ราคาตามนโยบาย → ใบเสนอราคา · ส่งไม่ได้จนกว่าตอบเรื่องค่าส่ง |
| D | ลูกค้าสั่งเพิ่มสปริง → สูตร REV.02 | ต้นทุนขึ้น 14.6% · ใบเสนอราคาที่ส่งแล้วโชว์กำไรเหลือ 19.8% **แต่ไม่มีอะไรเตือน** |
| E | สูตรมีวัสดุที่ยังไม่มีราคา | ระบบตอบ "ยังตอบไม่ได้" ไม่เดาให้ |

สรุป: **เครื่องคิดเลขใช้ได้ · ที่ขาดคือของ 3 อย่างที่ต้องป้อน** (รายการ · สูตร · ราคาวัสดุ) และหน้าจอของงานโครงการ

ข้อสังเกตจากรอบ D: สูตร REV.01 ยังขึ้นสถานะ "ใช้อยู่" คู่กับ REV.02 · วิวเลือกตัวล่าสุดให้ แต่ควรปิดตัวเก่าเอง (ยังไม่ได้แก้)

## 3 · ใบงานแยกแผนก (แท็บ 3 ของ mockup)

1 รายการ = 6 ใบ ตามแผนกของโรงงาน: โครงไม้ · ฟองน้ำ · วางแบบ · เย็บ · หุ้ม · QC
แต่ละใบมี: หัวงาน + REV + ผลอนุมัติ → **"เปลี่ยนจากรอบก่อน"** → แบบที่เน้นเฉพาะส่วนของแผนก → ที่ต้องทำ → เบิกวัตถุดิบ (ตามสูตร / เบิกจริง / ผลต่าง) → ปุ่มส่งต่อ
ไม่มีตัวเลขเงินในใบงาน · จำนวนวัสดุใน mockup เป็นตัวอย่าง ไม่ใช่สูตรจริง

## 4 · ที่ต้องตัดสินก่อนสร้าง

1. เริ่มจากฝั่งไหนก่อน: ใบงานแยกแผนก (โรงงานใช้ได้เลย ไม่ต้องมีราคา) หรือ ใบเสนอราคางานโครงการ (ต้องมีสูตร + ราคาวัสดุก่อน)
2. ใครเป็นคนลงสูตรของงานสั่งทำ
