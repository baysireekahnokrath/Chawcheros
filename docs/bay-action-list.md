   ตรงนี้ยังไม่ใช่สินค้า ยังไม่มี SKU เซลส์ยังไม่เห็น

## ขั้นที่ 4 · ตรวจ 95 กลุ่ม (งานหลักของพี่)

เข้า **สินค้า** → **ตรวจและอนุมัติสินค้า**

1 การ์ด = 1 รุ่น (Collection + หมวด) ตอบ 3 คำถาม

| คำถาม | ดูจากอะไร |
|---|---|
| ยังขายอยู่ไหม | ชื่อรุ่น + ช่วงราคา |
| รุ่นเดียวกันจริงไหม | กดเปิดดูรายการวัสดุ/รูปทรง/ขนาดข้างใน |
| สเปกถูกไหม | ตารางขนาดและราคารายตัว |

- **อนุมัติ** → ออก SKU ให้ทั้งกลุ่มทันที **ออกแล้วออกเลย เอาคืนไม่ได้**
- **ไม่เอา** → เปลี่ยนสถานะเฉยๆ ไม่ได้ลบ ย้อนดูทีหลังได้

ไม่ต้องทำรวดเดียวจบ ทำค้างไว้ได้ มีแถบความคืบหน้าบอกว่าเหลือกี่กลุ่ม

## เรื่องที่ผมต้องรอคำตอบจากพี่

| เรื่อง | ทำไมต้องถาม |
|---|---|
| ชื่อผ้า/หนังจริง | ตอนนี้มีแต่เกรด (ผ้า A/B/C, หนังแท้) ยังไม่มีชื่อสีจริง — แบบฟอร์มอยู่ที่ `docs/templates/materials-fill-in.csv` |
| HOF เป็นแบรนด์ที่ขายเองหรือรับมาขาย | มีผลว่าจะนับต้นทุนยังไง |
| ใครได้สิทธิ์อะไรบ้าง | ตอนนี้มีแต่พี่คนเดียว ต้องรู้ว่าจะเปิดให้ใครเห็นอะไร |

## เรื่องที่ผมทำต่อได้เลย ไม่ต้องรอ

- โมดูลคลัง — นับเป็นตัว ไม่ใช่จำนวน · ยืมออกงานแฟร์แล้วมีกำหนดกลับ · พิมพ์สติกเกอร์
- ช่องเพิ่มเอง (Custom Fields) — เพิ่มช่องในสินค้า/ลูกค้า/ออเดอร์ได้เองโดยไม่ต้องรอผม
- หน้าจอสำหรับเครื่องยิงบาร์โค้ดในโรงงานและตอนส่งของ

### ส่วนที่ 2 · ให้ LINE @chawcher เข้าระบบเอง (ทำทีหลัง · ไม่บังคับ · ทำเมื่อส่วนที่ 1 ใช้ได้แล้ว)

> ⚠️ ส่วนนี้ **ยังไม่เคยทดสอบกับ LINE จริง** และมีจุดที่ต้องเช็กก่อน (T1 · T8) · ไม่แน่ใจขั้นไหนให้หยุดแล้วถาม Claude · ระบบไม่ตอบลูกค้าเอง ทีมยังตอบในหน้าแชทของ LINE ตามเดิม

1. เปิด [LINE Official Account Manager](https://manager.line.biz/) → เลือกบัญชี **@chawcher** → มุมขวาบนกด **Settings (ตั้งค่า)** → เมนูซ้าย **Messaging API**
   - ช่อง **Webhook URL** มีค่าอยู่แล้ว = มีโปรแกรมอื่นต่ออยู่ **หยุด** ถ่ายหน้าจอส่ง Claude (ใส่ของเราแทน ของเดิมจะหยุดทำงาน)
   - ยังไม่เปิด Messaging API = กด **Enable Messaging API** → เลือก Provider เดียวกับบอท Team Bay
2. เมนูซ้าย **Response settings (ตั้งค่าการตอบกลับ)** → **ถ่ายหน้าจอหน้านี้เก็บไว้ก่อนแก้อะไร** → ดูว่า **Chat** เปิดอยู่ · **Auto-response** และ **Greeting message** ตั้งไว้อย่างไร → เปิด **Webhooks** เป็น On โดย **ไม่ปิด** Chat
   - ถ้าหน้านี้บังคับให้เลือกอย่างใดอย่างหนึ่งระหว่าง Chat กับ Webhook = **หยุด ไม่ต้องเปิด** ใช้ส่วนที่ 1 ต่อไป แล้วบอก Claude
3. เปิด [LINE Developers Console](https://developers.line.biz/console/) → Provider ของ @chawcher → channel Messaging API ของ @chawcher → แท็บ **Basic settings** → คัดลอก **Channel secret**
4. เปิด Vercel → โปรเจกต์ **chawcher-os** → **Settings** → **Environment Variables** ([ลิงก์ตรง · ประกอบจากชื่อทีม ยังไม่ได้ลองเปิด](https://vercel.com/bay8/chawcher-os/settings/environment-variables)) → กด **Add** → Key พิมพ์ตามกล่องข้างล่าง · Value วาง Channel secret → ติ๊ก **Production** → **Save**

```
LINE_OA_CHANNEL_SECRET
```

5. (ไม่บังคับ · อยากเห็นชื่อลูกค้าแทนคำว่า "ลูกค้า LINE") ที่ LINE Developers แท็บ **Messaging API** → เลื่อนลงล่าง **Channel access token (long-lived)** → กด **Issue** → คัดลอก → เพิ่มใน Vercel แบบเดียวกับขั้น 4 ด้วย Key นี้

```
LINE_OA_CHANNEL_ACCESS_TOKEN
```

6. ใน Vercel แท็บ **Deployments** → รายการบนสุด กด **⋯** → **Redeploy** → รอจนขึ้น Ready (ค่าที่เพิ่มจะมีผลหลัง deploy ใหม่เท่านั้น)
7. กลับไป LINE Developers แท็บ **Messaging API** → **Webhook URL** กด **Edit** → วางค่าในกล่องข้างล่าง → **Update** → กด **Verify** ต้องขึ้น **Success** → เปิดสวิตช์ **Use webhook**

```
https://chawcher-os.vercel.app/api/line/oa/webhook
```

8. ใช้ LINE ส่วนตัว ส่งข้อความหา @chawcher ว่า `ทดสอบ โซฟาราคาเท่าไหร่` → เปิด [หน้ารายการคนสนใจ](https://chawcher-os.vercel.app/leads/list) → ต้องมีแถวใหม่ ช่องทาง LINE ขั้น "ใหม่" ป้าย ถามราคา · โซฟา เป็นเส้นประ (ระบบเสนอ)
   - Verify ขึ้น Success แต่ไม่มีแถวใหม่ = Channel secret ไม่ตรง หรือยังไม่ได้ Redeploy (ระบบตั้งใจตอบ Success เสมอ จึงดูจาก Verify อย่างเดียวไม่ได้)
9. เช็ก 3 อย่างว่ายังเหมือนเดิม: เปิด [LINE Chat](https://chat.line.biz/) เห็นข้อความทดสอบและพิมพ์ตอบได้ · ลูกค้าไม่ได้รับข้อความแปลกจากระบบ · กดปุ่ม "ขอ Brochure" แล้วยังได้โบรชัวร์ → อย่างใดอย่างหนึ่งหายไป = กลับไปขั้น 7 ปิดสวิตช์ **Use webhook** แล้วบอก Claude
10. แถวทดสอบของตัวเอง → เปิดแถว → กดบรรทัดล่างสุด **กดเพื่อไม่นับ**
