# Chaw Cher OS — สมุดบันทึกการตัดสินใจ

ไฟล์นี้คือ "ความจริงที่ตกลงกันแล้ว" ห้ามเปลี่ยนโดยไม่ถาม Bay
ทุกครั้งที่ออกแบบอะไร ต้องเช็คกับไฟล์นี้ก่อน

---

## A. ตัดสินใจไว้ตั้งแต่ต้น (ล็อก)

| # | เรื่อง | คำตอบ |
|---|---|---|
| A1 | ฐานข้อมูล | Supabase (Postgres) โปรเจกต์ `chawcher` region Singapore |
| A2 | เว็บแอป | Next.js deploy บน Vercel |
| A3 | SKU | 8 หลัก ไม่มีความหมายในตัว ห้ามซ้ำ ห้ามเปลี่ยนตลอดชีวิตสินค้า |
| A4 | โครงสินค้า | แยก "รุ่น" (products) ออกจาก "ตัวที่ขายจริง" (variants) — SKU อยู่ที่ variant |
| A5 | สต็อก | นับเป็นตัว (per unit) แต่ละตัวมีรหัสของตัวเอง |
| A6 | ต้นทุน/กำไร | ตารางแยกในฐานเดียวกัน จำกัดสิทธิ์เฉพาะเจ้าของ |
| A7 | การลบ | **ห้าม DELETE ข้อมูลใดๆ** เลิกขาย/ยกเลิก = เปลี่ยน status |
| A8 | Schema | แก้ผ่านไฟล์ migration ใน repo เท่านั้น ห้ามแก้ใน dashboard |
| A9 | UI | มือถือมาก่อน desktop เป็นรอง |
| A10 | ตัวเลขคำนวณ | ห้ามเก็บเป็นช่องที่คนแก้ได้ ต้องคำนวณสดเสมอ |
| A11 | ไฟล์ต้นฉบับ | ห้ามแตะ ทำสำเนาแล้วทำงานบนสำเนาเท่านั้น |

## B. คำตอบจาก Bay รอบที่ 1 (2026-09-20)

| # | เรื่อง | คำตอบ |
|---|---|---|
| B1 | นิยาม "รุ่น" | รุ่น = ชื่อ Collection (Emu Sofa, Koontong Sideboard) |
| B2 | ตัวเลือก | ซ้อนกันเป็นชั้น: ขนาด → ประเภทวัสดุ (ผ้า A/B/C หรือ หนัง) → ตัวเลือกย่อยในแต่ละประเภท |
| B3 | ตัวเลือกงานไม้ | ขนาด → สี |
| B4 | SKU เดิม | **ไม่เคยมีระบบ SKU ของตัวเอง** เลข SKU ที่มีมาจากระบบ gen อัตโนมัติของ NocNoc |
| B5 | รูปแบบ SKU | เคยคุยว่าจะเป็น `xxx.xxx.xxx` แบบ IKEA — **ยังต้องยืนยัน (ดู OPEN-1)** |
| B6 | รหัสเดิม | ไม่ใช้แล้ว เก็บไว้อย่างเดียวเพื่อ track back ว่าลูกค้าซื้อผ่าน NocNoc มา |
| B7 | ใครออก SKU | ระบบออกให้อัตโนมัติ ตาม template/วิธีที่ตกลงกันไว้ — ต้อง confirm วิธีกับ Bay ก่อน |
| B8 | HOF / Chaw Cher | เป็น Brand ทั้งคู่ |
| B9 | ฌ เฌอ โฮม | แบรนด์ย่อย ทำบ้านสำเร็จรูปขาย + มีบ้านให้เช่าพัก/เช่าถ่ายรูป |
| B10 | ASE | ชื่อ**บริษัท** ฌ เฌอ เป็นแบรนด์ที่อยู่ในบริษัท ASE — ถ้า ASE ออกแบรนด์ใหม่ ไม่เกี่ยวกับระบบนี้ |
| B11 | BLS | **เลข running PO** ไม่ใช่สถานที่ มาจากงาน BaanLaeSuan Fair ระบบหลังบ้านลิงก์กันด้วยเลขนี้ |
| B12 | ชอบใจ Studio | สตูดิโอที่เรา sponsor เฟอร์นิเจอร์ให้ **ไม่ใช่ธุรกิจของเรา** |
| B13 | ขอบเขต | ระบบนี้ใช้กับ **Chaw Cher อย่างเดียว** |
| B14 | สต็อกของเก่า | ทำทั้ง ก+ข — ออกรหัสรายตัวให้ของเดิม **และ** ต้องรู้ล็อต (FIFO) เพื่อให้ลูกค้าที่ซื้อหลายตัวได้สีไม้ใกล้เคียงกัน |
| B15 | ป้าย | ยังไม่มี — **ระบบต้องออกป้าย sticker ได้** |
| B16 | Serial Number | **โซฟาทุกตัวที่สั่งทำ ต้องมี Serial Number** จะซื้อเครื่องยิงเลเซอร์มาทำป้ายส่งลูกค้า |
| B17 | สถานที่ vs สภาพ | ASE / Showroom = **สถานที่** · ของเสีย / Defected = **สภาพ** และควรใช้คำเดียวกัน |
| B18 | ตำหนิ | บันทึกเป็นข้อความอิสระ |
| B19 | การส่ง | **1 ออเดอร์ ส่งได้มากกว่า 1 ครั้ง** |
| B20 | การจอง | **ออก PO แล้ว ของถูกจองทันที** |
| B21 | การชำระเงิน | มัดจำตอนสั่ง → จ่ายยอดค้างให้ครบ → เราถึงส่ง<br>ข้อยกเว้น: จ่าย 100% ตั้งแต่สั่ง / ส่งก่อนจ่ายทีหลัง (กรณีพิเศษเท่านั้น) |
| B22 | ประเภทสต็อก | 2 แบบ: (1) สินค้าใหม่ ซื้อมาขายไป (sideboard, tv cabinet, bed บางตัว) (2) สินค้าตัวโชว์/ผลิตแล้ว ที่ลูกค้ายอมเสียเงินจอง |
| B23 | ออเดอร์ผสม | **ออเดอร์เดียวปนทั้งของสต็อกและของสั่งผลิตได้** |
| B24 | NocNoc | ปิดกิจการแล้ว ไม่มีออเดอร์ใหม่อีก — แค่บันทึกว่าออเดอร์เก่ามาจาก NocNoc |
| B25 | Commission 10% | **ไม่ใช่ค่าคอมจริง** เป็นแค่ตัวเลขสมมติไว้คิด scenario ตั้งราคา |
| B26 | สถานะออเดอร์ | เปิดออเดอร์ → ชำระมัดจำแล้ว → ชำระครบแล้ว → สินค้าพร้อมส่ง → รอนัดวันส่ง → ติดตามเพื่อนัดส่ง ครั้งที่ xx → นัดวันส่งแล้ว → ส่งสำเร็จแล้ว / ยกเลิก<br>*(Bay ขอคำแนะนำเพิ่มเติม — ดู OPEN-5)* |
| B27 | คืน/เปลี่ยนของ | ทำได้ ของกลับไปอยู่ **พร้อมขาย ไม่มีตำหนิ** |
| B28 | เปลี่ยนสเปก | สินค้าสั่งผลิต เปลี่ยนผ้า/สเปกได้ **ก่อนเริ่มผลิต** |
| B29 | สิทธิ์ เซลส์ | price list, promotion, monthly reward |
| B30 | สิทธิ์ คลัง | เช็คสต็อก |
| B31 | สิทธิ์ บัญชี | ดูว่ามีการโอนก่อนส่งหรือยัง เช็คยอดเงินเข้าทั้งมัดจำและยอดคงเหลือ |
| B32 | สิทธิ์ การตลาด | content, performance ad, คิดราคาโปร, ดึง stock สินค้าได้ |
| B33 | สิทธิ์ เจ้าของ | เข้าได้หมด + dashboard ภาพรวมบริษัท (ยอดขาย, ยอด stock, sales performance) |
| B34 | ผู้ใช้ | **เริ่มคนเดียวก่อน** ล็อกอินด้วย email |
| B35 | Material Stock | **ยังไม่ต้องผูกกับ BOM** (เป็นหน้าที่ ASE) วางโครงเผื่อไว้เฉยๆ |
| B36 | Google Sheets | **ใช้คู่กันต่อไป เป็น backup ของบริษัท** auto sync ทุกตีสองได้ |
